    Chapter 34: AI에게 웹서버 코드 요청하기¶

    🎯 이 장의 학습 목표¶

    • [ ] AI에게 웹서버 코드를 요청하고, 피코2에서 실행할 수 있다
    • [ ] HTML의 기본 구조를 이해하고 간단히 수정할 수 있다

    예상 학습 시간: 약 40분

    📚 미리 알아야 할 것¶

    이전 장에서 피코2 W를 Wi-Fi에 연결하는 방법을 배웠어요. 피코2가 네트워크에 연결되어 IP 주소를 받은 상태라면 준비 완료입니다! 이번에는 그 연결을 활용해서 웹페이지를 띄우는 서버를 만들어 볼 거예요.

    📚 핵심 개념¶

    개념 1: 웹서버¶

    "웹서버는 마치 작은 음식점과 같아요."

    손님(브라우저)이 "메뉴판 보여주세요!" 하고 요청하면, 음식점(웹서버)이 메뉴판(웹페이지)을 건네주는 거예요. 피코2가 바로 이 작은 음식점 역할을 합니다.

    • 브라우저(크롬, 엣지 등)가 피코2의 IP 주소로 접속하면
    • 피코2 웹서버가 센서값이 담긴 웹페이지를 보내줍니다

    개념 2: HTML — 웹페이지의 뼈대¶

    "HTML은 웹페이지의 뼈대(골격)예요."

    우리가 보는 모든 웹페이지는 HTML이라는 언어로 구조가 잡혀 있어요. 살을 붙이고 옷을 입히는 건 나중 일이고, 일단 뼈대부터 세워야 합니다.

    HTML의 핵심 구조는 태그(tag) 로 이루어져 있어요. 태그는 꺾쇠 괄호(< >)로 감싸는 표시입니다.

    <h1>제목이에요</h1>
<p>문단 내용이에요</p>
    • <h1> ~ </h1> : 제목 (heading) — 크고 굵은 글씨
    • <p> ~ </p> : 문단 (paragraph) — 일반 텍스트
    • <html> : 전체 페이지의 시작과 끝
    • <body> : 눈에 보이는 내용이 들어가는 영역

    💡 기억 팁! 태그는 항상 여는 태그<p>와 닫는 태그</p>가 짝을 이뤄요. 마치 괄호처럼요!

    🔨 따라하기¶

    Step 1: AI에게 코드 요청하기¶

    ChatGPT, Claude 등 AI에게 다음과 같이 요청해 보세요.

    프롬프트 예시: "피코2 W (MicroPython)에서 온도 센서값을 읽어서 웹페이지로 보여주는 간단한 웹서버 코드를 만들어줘. 피코2 내장 온도센서를 사용하고, HTML 페이지에 온도를 표시해줘."

    AI가 생성해 주는 코드는 조금씩 다를 수 있지만, 핵심 구조는 아래와 비슷할 거예요.

    Step 2: AI가 생성한 코드 확인하기¶

    아래는 AI가 만들어 줄 법한 코드입니다. 이 코드를 Thonny에 복사하세요.

    import network
import socket
import machine
import time

# 1. Wi-Fi 연결
wlan = network.WLAN(network.STA_IF)
wlan.active(True)
wlan.connect("여러분의_WiFi이름", "WiFi비밀번호")

while not wlan.isconnected():
    time.sleep(1)

print("연결 완료! IP:", wlan.ifconfig()[0])

# 2. 온도 센서 설정
sensor = machine.ADC(4)  # 내장 온도센서

def read_temp():
    reading = sensor.read_u16()
    voltage = reading * 3.3 / 65535
    temperature = 27 - (voltage - 0.706) / 0.001721
    return round(temperature, 1)

# 3. HTML 페이지 만들기
def webpage(temp):
    html = f"""<!DOCTYPE html>
<html>
<body>
  <h1>피코2 온도 대시보드</h1>
  <p>현재 온도: <strong>{temp}°C</strong></p>
  <p>새로고침하면 값이 업데이트됩니다.</p>
</body>
</html>"""
    return html

# 4. 웹서버 시작
addr = socket.getaddrinfo("0.0.0.0", 80)[0][-1]
s = socket.socket()
s.bind(addr)
s.listen(1)
print("웹서버 시작! 브라우저에서 접속하세요.")

while True:
    cl, addr = s.accept()
    temp = read_temp()
    response = webpage(temp)
    cl.send("HTTP/1.0 200 OK\r\nContent-type: text/html\r\n\r\n")
    cl.send(response)
    cl.close()

    Step 3: Wi-Fi 정보 수정 후 실행하기¶

    1. 코드의 "여러분의_WiFi이름"과 "WiFi비밀번호"를 실제 값으로 바꿔주세요
    2. Thonny에서 실행(▶) 버튼을 클릭하세요
    3. 하단 Shell에 IP 주소가 출력되는지 확인하세요
    연결 완료! IP: 192.168.0.15
웹서버 시작! 브라우저에서 접속하세요.

    Step 4: 브라우저에서 접속하기¶

    같은 Wi-Fi에 연결된 컴퓨터나 스마트폰의 브라우저를 열고, Shell에 표시된 IP 주소를 입력하세요.

    예: http://192.168.0.15

    ✅ 체크포인트: 브라우저에 "피코2 온도 대시보드"라는 제목과 온도 값이 보이면 성공이에요! 🎉

    Step 5: HTML 수정해보기 — AI의 코드를 내 것으로!¶

    이제 코드의 webpage 함수 안 HTML을 직접 수정해 볼까요? 제목을 바꿔봅시다.

    def webpage(temp):
    html = f"""<!DOCTYPE html>
<html>
<body>
  <h1>🌡️ 내 방 온도 모니터</h1>
  <p>지금 온도는 <strong>{temp}°C</strong> 입니다!</p>
  <p>🕐 새로고침으로 업데이트하세요</p>
</body>
</html>"""
    return html

    수정 후 다시 실행하고, 브라우저를 새로고침 해보세요. 제목이 바뀌었나요?

    💡 잠깐! 여기까지 잘 따라오셨나요? AI가 만들어 준 코드를 그대로 쓰기만 하는 게 아니라, 직접 수정할 수 있다는 게 중요해요. 이것이 AI와 협업하는 방식이에요!

    📝 전체 코드¶

    import network
import socket
import machine
import time

# Wi-Fi 연결
wlan = network.WLAN(network.STA_IF)
wlan.active(True)
wlan.connect("여러분의_WiFi이름", "WiFi비밀번호")

while not wlan.isconnected():
    time.sleep(1)

print("연결 완료! IP:", wlan.ifconfig()[0])

# 내장 온도센서
sensor = machine.ADC(4)

def read_temp():
    reading = sensor.read_u16()
    voltage = reading * 3.3 / 65535
    temperature = 27 - (voltage - 0.706) / 0.001721
    return round(temperature, 1)

# HTML 웹페이지
def webpage(temp):
    html = f"""<!DOCTYPE html>
<html>
<body>
  <h1>🌡️ 내 방 온도 모니터</h1>
  <p>지금 온도는 <strong>{temp}°C</strong> 입니다!</p>
  <p>🕐 새로고침으로 업데이트하세요</p>
</body>
</html>"""
    return html

# 웹서버
addr = socket.getaddrinfo("0.0.0.0", 80)[0][-1]
s = socket.socket()
s.bind(addr)
s.listen(1)
print("웹서버 시작!")

while True:
    cl, addr = s.accept()
    temp = read_temp()
    response = webpage(temp)
    cl.send("HTTP/1.0 200 OK\r\nContent-type: text/html\r\n\r\n")
    cl.send(response)
    cl.close()

    ⚠️ 주의할 점¶

    • 같은 Wi-Fi 필수: 피코2와 브라우저가 사용하는 기기가 같은 Wi-Fi 네트워크에 연결되어 있어야 합니다. 모바일 데이터로는 접속할 수 없어요.

    • 포트 충돌 오류: OSError: [Errno 98] EADDRINUSE가 나오면 피코2를 리셋(보드의 리셋 버튼)한 뒤 다시 실행하세요. 이전 서버가 아직 포트를 잡고 있어서 생기는 문제예요.

    ✅ 점검하기¶

    1. 웹서버의 역할을 한 문장으로 설명할 수 있나요?

    정답 확인 웹서버는 브라우저의 요청을 받아 HTML 웹페이지를 보내주는 프로그램이에요.

    2. HTML에서 제목을 표시하는 태그는 무엇인가요?

    정답 확인 <h1> 태그입니다. <h1>제목</h1> 형식으로 사용해요.

    3. AI가 만들어 준 코드에서 온도 표시 문구를 "실내 온도:"로 바꾸려면 어디를 수정하면 될까요?

    정답 확인 webpage 함수 안의 HTML에서 <p> 태그 안 텍스트를 "실내 온도: {temp}°C"로 바꾸면 됩니다.
