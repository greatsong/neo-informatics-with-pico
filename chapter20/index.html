    Chapter 20: 반복문 마스터하기¶

    🎯 이 장의 학습 목표¶

    이 장을 마치면 다음을 할 수 있습니다: - [ ] for 반복문과 while 반복문의 차이를 설명할 수 있다 - [ ] break와 continue로 반복 흐름을 제어할 수 있다

    ⏱️ 예상 학습 시간: 약 40분

    📚 미리 알아야 할 것¶

    이전 장에서 배운 조건문(if)을 기억하시나요? "조건이 참이면 실행"하는 구조였죠. 이번 장의 반복문도 비슷합니다. 조건이 참인 동안 계속 실행하는 것이 핵심이에요!

    📚 핵심 개념¶

    개념 1: for 반복문 — "정해진 횟수만큼 반복"¶

    비유로 시작해요 🎒

    "출석부를 부르는 선생님"을 떠올려 보세요. 명단에 있는 학생 이름을 처음부터 끝까지 하나씩 부릅니다. 명단이 끝나면 자연스럽게 멈추죠.

    for 반복문이 바로 이것입니다. "이 목록의 항목을 하나씩 꺼내서 반복해!" 라는 뜻이에요.

    for name in ["민수", "지은", "하늘"]:
    print(name, "출석!")

    민수 출석!
지은 출석!
하늘 출석!

    여기서 range() 함수를 쓰면 원하는 횟수만큼 반복할 수 있어요:

    for i in range(5):
    print(i, "번째 반복")

    0 번째 반복
1 번째 반복
2 번째 반복
3 번째 반복
4 번째 반복

    💡 핵심! range(5)는 0부터 4까지 숫자 5개를 만들어주는 함수예요. "5개 줘!"라고 기억하세요.

    range()의 다양한 사용법:

    사용법 의미 결과
    range(5) 0부터 4까지 0, 1, 2, 3, 4
    range(1, 6) 1부터 5까지 1, 2, 3, 4, 5
    range(0, 10, 2) 0부터 9까지 2씩 증가 0, 2, 4, 6, 8

    개념 2: while 반복문 — "조건이 참인 동안 반복"¶

    비유로 시작해요 🎮

    게임에서 "체력이 남아있는 동안 계속 싸운다"를 생각해 보세요. 체력이 0이 되면 자동으로 멈추죠. while 반복문은 이렇게 "언제 끝날지 미리 모르지만, 조건이 맞는 동안 계속" 반복합니다.

    hp = 3

while hp > 0:
    print(f"체력 {hp} - 전투 중!")
    hp = hp - 1

print("게임 오버!")

    체력 3 - 전투 중!
체력 2 - 전투 중!
체력 1 - 전투 중!
게임 오버!
    flowchart TD A([시작]) --> B{조건 확인} B -- "참 ✅" --> C[코드 실행] C --> B B -- "거짓 ❌" --> D([반복 종료]) style B fill:#fff3e0,stroke:#f57c00 style C fill:#e3f2fd,stroke:#1976d2 style D fill:#e8f5e9,stroke:#388e3c

    ⚠️ 주의! while문에서 조건이 영원히 참이면 프로그램이 멈추지 않아요(무한 루프). 반드시 조건이 거짓이 되는 순간이 오도록 만들어야 합니다!

    for vs while 한눈에 비교:

    구분 for while
    언제 쓰나요? 반복 횟수를 아는 경우 반복 횟수를 모르는 경우
    예시 상황 "5번 출력해줘" "맞출 때까지 반복"
    종료 조건 목록이 끝나면 자동 종료 조건이 거짓이 되면 종료

    💡 잠깐! 여기까지 이해가 잘 되셨나요? for는 "정해진 만큼", while은 "조건이 참인 동안"이라는 핵심만 기억하면 돼요!

    🔨 따라하기: 숫자 맞히기 게임 만들기¶

    break와 continue를 활용한 미니 게임을 만들어 봅시다!

    Step 1: while로 기본 반복 만들기¶

    secret = 7  # 정답
guess = 0   # 사용자 입력을 저장할 변수

while guess != secret:
    guess = int(input("1~10 사이 숫자를 맞혀보세요: "))
    print(f"입력한 숫자: {guess}")

print("정답입니다! 🎉")

    ✅ 체크포인트: 7을 입력하면 "정답입니다!"가 나와야 해요.

    Step 2: break로 중간에 탈출하기¶

    break는 반복문을 즉시 탈출하는 명령어예요. "비상구 🚪"라고 생각하세요!

    secret = 7

while True:  # 무한 반복
    guess = int(input("숫자를 맞혀보세요 (0 입력시 포기): "))

    if guess == 0:
        print("포기하셨군요 😢")
        break  # 🚪 반복문 탈출!

    if guess == secret:
        print("정답! 🎉")
        break  # 🚪 반복문 탈출!

    print("틀렸어요. 다시 시도하세요!")

    Step 3: continue로 건너뛰기¶

    continue는 현재 반복을 건너뛰고 다음 반복으로 넘어가는 명령어예요. "이번 건 패스! ⏭️"

    for i in range(1, 6):
    if i == 3:
        print("3은 건너뜁니다! ⏭️")
        continue  # 아래 코드를 실행하지 않고 다음 반복으로
    print(f"{i}번 실행!")

    실행 결과: 

    1번 실행!
2번 실행!
3은 건너뜁니다! ⏭️
4번 실행!
5번 실행!

    flowchart LR A["break 🚪"] --> B["반복문 완전 탈출"] C["continue ⏭️"] --> D["이번만 건너뛰고 계속 반복"] style A fill:#ffcdd2,stroke:#d32f2f style C fill:#fff9c4,stroke:#f9a825

    Step 4: 완성! 힌트가 있는 숫자 맞히기 게임¶

    secret = 7
attempts = 0

print("=== 숫자 맞히기 게임 ===")
print("1~10 사이의 숫자를 맞혀보세요!")

while True:
    guess = int(input("숫자 입력: "))
    attempts = attempts + 1

    if guess == secret:
        print(f"🎉 정답! {attempts}번 만에 맞혔어요!")
        break
    elif guess < secret:
        print("📈 더 큰 수예요!")
    else:
        print("📉 더 작은 수예요!")

    ✅ 체크포인트: 실행 후 몇 번의 시도로 정답을 맞혔는지 표시되면 성공!

    📝 전체 코드¶

    # === 반복문 종합 실습 ===

# 1. for 반복문
print("--- for 반복문 ---")
for i in range(3):
    print(f"{i+1}번째 인사: 안녕하세요!")

# 2. while 반복문
print("\n--- while 반복문 ---")
count = 3
while count > 0:
    print(f"카운트다운: {count}")
    count -= 1
print("출발! 🚀")

# 3. break & continue
print("\n--- break & continue ---")
for num in range(1, 11):
    if num % 2 == 0:
        continue  # 짝수는 건너뛰기
    if num > 7:
        break     # 7 초과면 중단
    print(num, end=" ")
# 출력: 1 3 5 7

    ⚠️ 주의할 점¶

    1. while 무한 루프 조심! 

    # ❌ 위험한 코드 - 절대 끝나지 않아요!
# while True:
#     print("무한!")

# ✅ 안전한 코드 - 탈출 조건이 있어요
while True:
    answer = input("종료하려면 q 입력: ")
    if answer == "q":
        break  # 탈출구가 반드시 있어야 해요!

    2. for문의 range()는 마지막 숫자를 포함하지 않아요! 

    # range(5)는 0, 1, 2, 3, 4 → 5는 포함되지 않음!
# 1부터 5까지 원하면 range(1, 6) 으로 써야 해요

    ✅ 점검하기¶

    1. 다음 코드의 출력 결과는 무엇일까요? 

    for i in range(3):
    print(i * 2)

    정답 확인 
    0
2
4
    `range(3)`은 0, 1, 2를 만들고, 각각에 2를 곱하면 0, 2, 4가 됩니다.

    2. for와 while 중 어떤 것을 쓸까요? "사용자가 '그만'이라고 입력할 때까지 반복"

    정답 확인 **while**을 사용합니다! 사용자가 언제 "그만"을 입력할지 모르기 때문에, 반복 횟수가 정해져 있지 않습니다.

    3. break와 continue의 차이를 한 문장으로 설명해 보세요.

    정답 확인 **break**는 반복문을 **완전히 종료**하고, **continue**는 **현재 회차만 건너뛰고** 다음 반복을 계속합니다.
