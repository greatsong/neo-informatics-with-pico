    📊 데이터 수집과 저장의 기초¶

    🎯 이 장의 학습 목표¶

    이 장을 마치면 다음을 할 수 있습니다:

    • [ ] 여러 번 측정한 데이터를 리스트에 차곡차곡 저장할 수 있다
    • [ ] 반복문으로 일정 간격 자동 측정을 구현할 수 있다
    • [ ] 수집한 데이터를 CSV 파일로 저장할 수 있다

    예상 학습 시간: 약 50분

    📚 미리 알아야 할 것¶

    이전 장에서 우리는 센서로 온도 등의 값을 한 번 읽어오는 방법을 배웠어요. print()로 화면에 출력하는 것도 해봤고요. 이번에는 한 번이 아니라 여러 번 반복 측정하고, 그 결과를 파일로 저장하는 방법을 배웁니다.

    📚 핵심 개념¶

    개념 1: 리스트 — 데이터를 순서대로 담는 서랍장 🗄️¶

    측정을 여러 번 하면 값이 여러 개 생기겠죠? 이걸 어디에 보관할까요?

    리스트(list)는 마치 번호가 붙은 서랍장과 같아요. 첫 번째 서랍, 두 번째 서랍... 순서대로 데이터를 넣고 꺼낼 수 있습니다.

    # 빈 서랍장 만들기
data = []

# 서랍에 값 넣기 (append = 맨 뒤에 추가)
data.append(24.5)
data.append(25.1)
data.append(24.8)

print(data)  # [24.5, 25.1, 24.8]
    flowchart LR subgraph 리스트 data A["0번: 24.5"] --> B["1번: 25.1"] --> C["2번: 24.8"] end style A fill:#e3f2fd,stroke:#1976d2 style B fill:#e3f2fd,stroke:#1976d2 style C fill:#e3f2fd,stroke:#1976d2

    📌 핵심 정리: []로 빈 리스트를 만들고, .append(값)으로 데이터를 하나씩 추가합니다. 번호(인덱스)는 0부터 시작해요!

    개념 2: 반복문 + time.sleep() — 자동 측정의 비밀 ⏰¶

    10초마다 측정하려면 어떻게 할까요? for 반복문과 time.sleep()을 조합하면 됩니다.

    • for i in range(6): 0부터 5까지, 총 6번 반복
    • time.sleep(10): 10초 동안 기다리기
    import time

for i in range(6):
    print(f"{i+1}번째 측정 중...")
    time.sleep(10)  # 10초 대기

    이렇게 하면 10초 간격으로 6번, 총 1분간 자동 측정이 가능해요!

    💡 잠깐! time.sleep(초)는 프로그램을 지정한 시간만큼 "잠재우는" 함수예요. import time을 꼭 먼저 써줘야 합니다.

    🔨 따라하기¶

    실제 센서가 없어도 괜찮아요! random 모듈로 가상의 온도 데이터를 만들어 연습합니다.

    Step 1: 가상 센서 함수 만들기¶

    import random
import time

def read_temperature():
    """가상 온도 센서 (23~27도 사이 랜덤)"""
    return round(random.uniform(23.0, 27.0), 1)

    Step 2: 리스트에 반복 저장하기¶

    data = []  # 빈 서랍장 준비

for i in range(6):
    temp = read_temperature()
    data.append(temp)
    print(f"[{i+1}/6] 온도: {temp}°C")
    if i < 5:          # 마지막엔 안 기다림
        time.sleep(2)  # 연습용으로 2초 간격

print(f"\n수집 완료! 데이터: {data}")

    실행 결과 (값은 매번 달라요): 

    [1/6] 온도: 24.3°C
[2/6] 온도: 25.7°C
[3/6] 온도: 23.9°C
[4/6] 온도: 26.1°C
[5/6] 온도: 24.8°C
[6/6] 온도: 25.2°C

수집 완료! 데이터: [24.3, 25.7, 23.9, 26.1, 24.8, 25.2]

    ✅ 체크포인트: 6개의 온도 값이 리스트로 출력되면 성공!

    Step 3: CSV 파일로 저장하기¶

    CSV(Comma-Separated Values)는 쉼표로 값을 구분하는 텍스트 파일이에요. 엑셀에서도 바로 열 수 있어서 데이터 저장에 아주 많이 쓰입니다.

    import csv

with open("temperature_log.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["측정번호", "온도(°C)"])  # 헤더
    for i, temp in enumerate(data):
        writer.writerow([i + 1, temp])

print("temperature_log.csv 저장 완료! 📁")

    저장된 파일 내용: 

    측정번호,온도(°C)
1,24.3
2,25.7
3,23.9
4,26.1
5,24.8
6,25.2

    💡 잠깐! with open(...) as f:는 파일을 열고, 블록이 끝나면 자동으로 닫아주는 안전한 방법이에요. 파일 닫기를 깜빡할 걱정이 없답니다!

    📝 전체 코드¶

    아래 코드를 복사해서 바로 실행해 보세요!

    import random
import time
import csv

# 1. 가상 온도 센서
def read_temperature():
    return round(random.uniform(23.0, 27.0), 1)

# 2. 데이터 수집 (6회, 2초 간격)
data = []
for i in range(6):
    temp = read_temperature()
    data.append(temp)
    print(f"[{i+1}/6] 온도: {temp}°C")
    if i < 5:
        time.sleep(2)

print(f"\n수집 완료! 데이터: {data}")

# 3. CSV 파일로 저장
with open("temperature_log.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["측정번호", "온도(°C)"])
    for i, temp in enumerate(data):
        writer.writerow([i + 1, temp])

print("temperature_log.csv 저장 완료! 📁")

    ⚠️ 주의할 점¶

    1. time.sleep() 시간 단위는 "초"입니다
    2. time.sleep(10) → 10초 대기

    3. 실습할 때는 time.sleep(2) 정도로 짧게 해도 괜찮아요. 10초씩 기다리면 1분이 걸리니까요! 😅

    4. CSV 파일을 열 때 newline=""을 빠뜨리지 마세요

    5. Windows에서 이걸 빼면 빈 줄이 한 줄씩 끼어들어가요.
    6. 습관적으로 넣어주면 안전합니다.

    ✅ 점검하기¶

    1. 리스트에 값을 추가하는 메서드 이름은 무엇일까요?

    정답 확인 `.append()`입니다. `data.append(값)` 형태로 리스트 맨 뒤에 데이터를 추가합니다.

    2. 5초 간격으로 10번 측정하려면 코드를 어떻게 바꿔야 할까요?

    정답 확인 `for i in range(10):`으로 바꾸고, `time.sleep(5)`로 설정하면 됩니다. 총 소요 시간은 약 45초(마지막은 대기 없음)예요.

    3. CSV 파일이 유용한 이유는 무엇일까요?

    정답 확인 엑셀, 구글 스프레드시트 등에서 바로 열 수 있고, 다른 프로그램과 데이터를 쉽게 주고받을 수 있기 때문입니다. 데이터 분석의 표준 형식 중 하나예요!
