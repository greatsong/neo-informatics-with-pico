    Chapter 15. 이상값 탐지 - 데이터 속 특별한 순간 찾기¶

    Part 2: [1권] 센서로 세상을 측정하기

    🎯 이 장의 학습 목표¶

    이 장을 마치면 다음을 할 수 있습니다:

    • [ ] 정상 범위와 이상값의 개념을 설명할 수 있다
    • [ ] 평균과 표준편차를 활용하여 이상값을 탐지할 수 있다

    ⏱️ 예상 학습 시간: 약 50분 (15차시 / 전체 45차시)

    📚 미리 알아야 할 것¶

    이전 장에서 센서로 온도 데이터를 수집하고, 리스트에 저장하는 방법을 배웠어요. 이번 장에서는 그 데이터 속에서 "튀는 값"을 찾아내는 방법을 배웁니다.

    📚 핵심 개념¶

    개념 1: 이상값(Outlier)이란?¶

    비유로 시작할게요. 🏫

    교실에서 키를 쟀다고 생각해 보세요. 대부분의 학생이 160~175cm 사이인데, 한 명이 210cm라고 기록되어 있어요. 이건 실제로 키가 큰 걸까요, 아니면 측정 실수일까요? 어느 쪽이든, 이 값은 다른 값들과 확연히 다르죠. 이것이 바로 이상값입니다.

    📖 이상값(Outlier): 대부분의 데이터와 동떨어진, 유독 크거나 작은 값

    이상값은 꼭 "잘못된 값"만은 아니에요. 센서 고장일 수도 있지만, 정말로 특별한 일이 벌어진 순간일 수도 있습니다.

    이상값의 원인 예시
    센서 오류 온도 센서가 순간적으로 999도 기록
    실제 이벤트 창문을 열어서 온도가 갑자기 떨어짐
    입력 실수 25.0도를 250도로 잘못 입력

    개념 2: 평균과 표준편차 — "보통"과 "얼마나 떨어졌나"¶

    이상값을 찾으려면 먼저 "보통이 뭔지"를 알아야 해요.

    평균(Mean) 은 "보통 수준"을 나타냅니다.

    🍕 피자 8조각을 4명이 나누면, 평균적으로 1인당 2조각이에요.

    표준편차(Standard Deviation) 는 "값들이 평균에서 얼마나 퍼져 있는가"를 나타냅니다.

    🎯 과녁에 화살을 쏠 때, 화살이 중심 근처에 모여 있으면 표준편차가 작고, 여기저기 흩어져 있으면 표준편차가 커요.

    flowchart LR A["📊 데이터 모음"] --> B["📐 평균 계산<br/>'보통 값'"] B --> C["📏 표준편차 계산<br/>'퍼진 정도'"] C --> D["🔍 이상값 판별<br/>'평균 ± 2×표준편차'<br/>밖이면 이상값!"] style A fill:#e3f2fd,stroke:#1976d2 style B fill:#fff3e0,stroke:#f57c00 style C fill:#fff3e0,stroke:#f57c00 style D fill:#fce4ec,stroke:#c62828

    핵심 규칙은 간단해요:

    💡 평균에서 표준편차의 2배 이상 떨어진 값 → 이상값으로 의심!

    • 정상 범위: 평균 - 2×표준편차 ~ 평균 + 2×표준편차
    • 이 범위 밖의 값 → 이상값 🚨

    💡 잠깐! 여기까지 이해가 되셨나요? "평균 = 보통", "표준편차 = 퍼진 정도"만 기억하면 충분해요. 천천히 다시 읽어보셔도 괜찮습니다!

    🔨 따라하기¶

    온도 센서 데이터에서 이상값을 찾아봅시다!

    Step 1: 온도 데이터 준비하기¶

    하루 동안 1시간마다 측정한 교실 온도라고 상상해 보세요.

    # 24시간 교실 온도 데이터 (단위: °C)
temperatures = [
    22.1, 22.0, 21.8, 21.9, 22.0, 22.2,  # 0~5시
    22.5, 23.1, 24.0, 24.5, 24.8, 25.0,  # 6~11시
    25.2, 25.1, 30.7, 24.9, 24.5, 24.0,  # 12~17시 ← 14시에 30.7도!
    23.5, 23.0, 22.8, 22.5, 22.3, 22.1   # 18~23시
]
print(f"데이터 개수: {len(temperatures)}개")

    실행 결과: 

    데이터 개수: 24개

    눈으로 봐도 14시의 30.7도가 의심스럽죠? 이걸 코드로 찾아봅시다!

    Step 2: 평균과 표준편차 계산하기¶

    # 평균 계산
mean_temp = sum(temperatures) / len(temperatures)

# 표준편차 계산
squared_diff = [(t - mean_temp) ** 2 for t in temperatures]
std_temp = (sum(squared_diff) / len(temperatures)) ** 0.5

print(f"평균 온도: {mean_temp:.1f}°C")
print(f"표준편차:  {std_temp:.1f}°C")

    실행 결과: 

    평균 온도: 23.4°C
표준편차:  1.9°C

    Step 3: 정상 범위 정하기¶

    # 정상 범위 = 평균 ± 2 × 표준편차
lower_bound = mean_temp - 2 * std_temp
upper_bound = mean_temp + 2 * std_temp

print(f"정상 범위: {lower_bound:.1f}°C ~ {upper_bound:.1f}°C")

    실행 결과: 

    정상 범위: 19.6°C ~ 27.2°C

    Step 4: 이상값 찾기!¶

    # 정상 범위를 벗어난 값 찾기
for i, temp in enumerate(temperatures):
    if temp < lower_bound or temp > upper_bound:
        print(f"🚨 이상값 발견! {i}시: {temp}°C (정상 범위 밖)")

    실행 결과: 

    🚨 이상값 발견! 14시: 30.7°C (정상 범위 밖)

    ✅ 체크포인트: 14시의 30.7°C가 이상값으로 탐지되었나요? 그렇다면 성공입니다!

    Step 5: 원인 추론하기¶

    이상값을 찾았으면, "왜?"를 생각하는 게 중요해요.

    # 이상값의 의미를 해석해 봅시다
print("=" * 40)
print("📋 이상값 분석 보고서")
print("=" * 40)
print(f"  발생 시각: 14시")
print(f"  측정 온도: 30.7°C")
print(f"  정상 범위: {lower_bound:.1f} ~ {upper_bound:.1f}°C")
print(f"  평균 대비: +{30.7 - mean_temp:.1f}°C 높음")
print()
print("🔍 가능한 원인:")
print("  1. 직사광선이 센서에 닿았을 수 있음")
print("  2. 점심시간 후 많은 학생이 입실함")
print("  3. 센서 일시적 오작동")

    실행 결과: 

    ========================================
📋 이상값 분석 보고서
========================================
  발생 시각: 14시
  측정 온도: 30.7°C
  정상 범위: 19.6 ~ 27.2°C
  평균 대비: +7.3°C 높음

🔍 가능한 원인:
  1. 직사광선이 센서에 닿았을 수 있음
  2. 점심시간 후 많은 학생이 입실함
  3. 센서 일시적 오작동

    💡 이상값은 삭제하는 것이 아니라, 원인을 파악하는 것이 핵심이에요!

    📝 전체 코드¶

    # === 이상값 탐지 프로그램 ===

# 1. 데이터 준비
temperatures = [
    22.1, 22.0, 21.8, 21.9, 22.0, 22.2,
    22.5, 23.1, 24.0, 24.5, 24.8, 25.0,
    25.2, 25.1, 30.7, 24.9, 24.5, 24.0,
    23.5, 23.0, 22.8, 22.5, 22.3, 22.1
]

# 2. 평균 계산
mean_temp = sum(temperatures) / len(temperatures)

# 3. 표준편차 계산
squared_diff = [(t - mean_temp) ** 2 for t in temperatures]
std_temp = (sum(squared_diff) / len(temperatures)) ** 0.5

# 4. 정상 범위 설정
lower_bound = mean_temp - 2 * std_temp
upper_bound = mean_temp + 2 * std_temp

# 5. 결과 출력
print(f"평균: {mean_temp:.1f}°C | 표준편차: {std_temp:.1f}°C")
print(f"정상 범위: {lower_bound:.1f}°C ~ {upper_bound:.1f}°C")
print()

for i, temp in enumerate(temperatures):
    if temp < lower_bound or temp > upper_bound:
        print(f"🚨 {i}시: {temp}°C → 이상값!")

print("\n✅ 이상값 탐지 완료!")

    ⚠️ 주의할 점¶

    1. 이상값 ≠ 오류값: 이상값이라고 무조건 삭제하면 안 돼요. 정말 중요한 사건(화재 경보, 장비 고장)을 놓칠 수 있습니다.

    2. "2배"는 절대 법칙이 아니에요: 평균 ± 2×표준편차는 자주 쓰이는 기준이지만, 상황에 따라 1.5배나 3배로 조절할 수 있어요. 데이터가 적으면 기준을 느슨하게, 많으면 엄격하게 하는 게 좋습니다.

    ✅ 점검하기¶

    1. 이상값이란 무엇인가요?

    정답 확인 대부분의 데이터와 동떨어진, 유독 크거나 작은 값입니다. 센서 오류일 수도 있고, 실제로 특별한 사건이 발생한 것일 수도 있어요.

    2. 평균이 20, 표준편차가 3일 때, 정상 범위는?

    정답 확인 20 - 2×3 = 14, 20 + 2×3 = 26이므로, 정상 범위는 14 ~ 26입니다. 이 범위 밖의 값이 이상값이에요.

    3. 이상값을 발견했을 때 가장 먼저 해야 할 일은?

    정답 확인 바로 삭제하는 것이 아니라, 왜 이런 값이 나왔는지 원인을 파악하는 것입니다!
