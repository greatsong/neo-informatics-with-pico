    AI와 함께 코딩한다는 것¶

    🎯 이 장의 학습 목표¶

    • [ ] 바이브 코딩(AI 기반 코딩)의 개념과 장단점을 설명할 수 있다
    • [ ] AI를 도구로 활용하면서도 비판적으로 검증하는 태도를 갖출 수 있다

    예상 학습 시간: 약 30분

    📚 미리 알아야 할 것¶

    1권에서 파이썬 기초, 판다스, 시각화까지 배우며 직접 코드를 작성해 보셨죠? 이제 2권에서는 AI의 도움을 받아 더 큰 프로젝트를 만들어 볼 거예요. 그 첫걸음으로, AI와 함께 코딩한다는 것이 무엇인지 이해하는 시간을 갖겠습니다.

    📚 핵심 개념¶

    개념 1: 바이브 코딩(Vibe Coding)¶

    비유로 시작할게요. 🍳

    요리를 처음 배운다고 상상해 보세요. 혼자서 레시피를 검색하고, 재료를 준비하고, 하나하나 따라 해야 했죠. 그런데 옆에 경험 많은 요리 보조가 생겼다면 어떨까요?

    "된장찌개 끓여줘" 라고 말하면, 보조가 재료를 손질하고 냄비에 넣어주는 거예요. 여러분은 간을 보고, 맛을 조절하고, 최종 결정을 내리면 됩니다.

    바이브 코딩이 바로 이런 방식이에요.

    바이브 코딩(Vibe Coding): 프로그래머가 코드를 한 줄 한 줄 직접 작성하는 대신, AI에게 자연어(일상 언어)로 원하는 것을 설명하고, AI가 생성한 코드를 활용하는 프로그래밍 방식

    "바이브(vibe)"는 "분위기, 느낌"이라는 뜻이에요. 코드의 세부 문법을 일일이 신경 쓰기보다, "이런 느낌으로 만들어줘" 라고 방향을 잡아주는 코딩이라서 이런 이름이 붙었어요.

    예시를 볼까요?

    여러분이 AI에게 이렇게 요청한다고 해 봐요:

    "매출 데이터를 읽어서 월별 막대 그래프로 보여줘"

    그러면 AI가 이런 코드를 만들어 줍니다:

    import pandas as pd
import matplotlib.pyplot as plt

# 데이터 읽기
df = pd.read_csv("sales.csv")

# 월별 매출 합산
monthly = df.groupby("month")["amount"].sum()

# 막대 그래프 그리기
plt.figure(figsize=(10, 6))
monthly.plot(kind="bar")
plt.title("월별 매출")
plt.ylabel("매출액")
plt.show()

    1권에서 배운 코드들이 보이시죠? 판다스로 데이터를 읽고, 그룹화하고, 시각화하는 코드예요. AI가 이걸 몇 초 만에 만들어 줍니다.

    💡 잠깐! "그러면 코딩을 배울 필요가 없는 거 아닌가요?"라고 생각하실 수 있어요. 좋은 질문이에요! 바로 다음 개념에서 이 의문에 답해 드릴게요.

    개념 2: AI는 똑똑한 조수, 완벽한 해결사가 아니다¶

    비유를 하나 더 들어볼게요. 🔍

    AI는 자동 번역기와 비슷해요. 구글 번역기에 한국어를 넣으면 영어가 나오죠? 매우 편리하지만, 번역 결과를 그대로 믿으면 안 된다는 건 다들 아실 거예요. 어색한 표현, 문맥에 맞지 않는 단어가 종종 나오니까요.

    AI 코딩 도구도 마찬가지예요.

    AI가 잘하는 것 🟢

    • 반복적인 코드 빠르게 생성 — 데이터 읽기, 기본 그래프 그리기 같은 정형화된 작업
    • 문법 오류 줄이기 — 괄호, 콜론 같은 사소한 실수를 줄여줌
    • 다양한 방법 제안 — "이렇게도 할 수 있고, 저렇게도 할 수 있어요"

    AI가 못하는 것 🔴

    • 내 상황을 정확히 이해하기 — 데이터가 어떤 형태인지, 어떤 목적인지 완벽히 파악 못함
    • 논리적 오류 검증 — 코드가 실행은 되지만, 결과가 틀릴 수 있음
    • 최신 정보 반영 — 학습 시점 이후의 변경사항을 모를 수 있음
    flowchart LR A["🧑 사람\n방향 결정\n결과 검증"] --> B["🤖 AI\n코드 생성\n문법 처리"] B --> C["📊 결과물\n대시보드\n분석 보고서"] A --> C style A fill:#e3f2fd,stroke:#1976d2 style B fill:#fff3e0,stroke:#f57c00 style C fill:#e8f5e9,stroke:#388e3c

    핵심은 이거예요. 사람이 선장, AI가 항해사입니다. 어디로 갈지 결정하는 건 여러분이고, AI는 효율적인 경로를 제안해 주는 거예요.

    💡 그래서 1권에서 기초를 배운 거예요! 판다스가 뭔지, 시각화가 뭔지 아는 사람이 AI를 활용하면, AI가 만든 코드가 맞는지 틀렸는지 판단할 수 있어요. 기초 없이 AI만 쓰면, 틀린 결과를 맞다고 믿게 되는 위험이 있습니다.

    🔨 따라하기: AI에게 요청하고 검증하는 연습¶

    실제로 AI와 대화하며 코딩하는 흐름을 체험해 봅시다. 여기서는 AI가 만들어 준 코드를 직접 검증하는 과정을 연습해요.

    Step 1: AI에게 요청할 내용 정리하기¶

    AI에게 무작정 "코드 만들어줘"라고 하면 엉뚱한 결과가 나올 수 있어요. 요청을 구체적으로 만드는 게 중요해요.

    • 나쁜 요청: "그래프 그려줘"
    • 좋은 요청: "sales.csv 파일에서 'month' 열 기준으로 'amount' 열의 합계를 구해서 막대 그래프로 그려줘. 한글 제목 '월별 매출 현황'을 넣어줘."

    Step 2: AI가 생성한 코드 읽어보기¶

    AI가 아래 코드를 만들어 줬다고 가정해요:

    import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("sales.csv")
monthly = df.groupby("month")["amount"].sum()
plt.bar(monthly.index, monthly.values)
plt.title("월별 매출 현황")
plt.show()

    Step 3: 코드를 비판적으로 검토하기¶

    1권에서 배운 지식으로 질문해 봅시다:

    • ✅ pd.read_csv — 맞아요, CSV 파일 읽는 함수죠
    • ✅ groupby("month")["amount"].sum() — 월별로 묶어서 합산, 맞아요
    • ⚠️ 한글 깨짐 처리가 없네요! — plt.rcParams 설정이 빠졌어요
    • ⚠️ 월 순서가 보장될까요? — 1월~12월 순서대로 나올지 확인 필요

    Step 4: 부족한 부분 보완하기¶

    import pandas as pd
import matplotlib.pyplot as plt

# 한글 폰트 설정 (AI가 빠뜨린 부분!)
plt.rcParams['font.family'] = 'Malgun Gothic'
plt.rcParams['axes.unicode_minus'] = False

df = pd.read_csv("sales.csv")
monthly = df.groupby("month")["amount"].sum()

# 월 순서 정렬 추가
monthly = monthly.sort_index()

plt.bar(monthly.index, monthly.values)
plt.title("월별 매출 현황")
plt.show()

    Step 5: 결과 확인하기¶

    코드를 실행해서 그래프가 제대로 나오는지 확인하세요.

    ✅ 체크포인트: AI가 만든 코드에서 빠진 부분 2가지(한글 폰트, 정렬)를 찾아서 보완했다면 성공이에요!

    ⚠️ 주의할 점¶

    1. AI의 코드를 복사-붙여넣기만 하지 마세요

    AI가 만든 코드를 이해하지 않고 실행하면, 오류가 날 때 어디가 문제인지 찾을 수 없어요. 최소한 "이 줄은 뭘 하는 건지" 정도는 파악하세요. 1권에서 배운 기초가 여기서 빛을 발합니다!

    2. AI에게 같은 질문을 해도 매번 다른 답이 나올 수 있어요

    AI는 확률 기반으로 텍스트를 생성하기 때문에, 동일한 질문에도 조금씩 다른 코드를 만들어 줄 수 있어요. 이것도 여러분이 어떤 답이 더 나은지 판단해야 하는 이유예요.

    ✅ 점검하기¶

    1. 바이브 코딩이란 무엇인가요?

    정답 확인 코드를 한 줄 한 줄 직접 작성하는 대신, AI에게 자연어(일상 언어)로 원하는 것을 설명하고, AI가 생성한 코드를 활용하는 프로그래밍 방식이에요.

    2. AI가 만든 코드를 그대로 사용하면 안 되는 이유는?

    정답 확인 AI는 내 상황을 완벽히 이해하지 못하고, 논리적 오류가 있을 수 있으며, 한글 폰트 설정 같은 세부 사항을 빠뜨릴 수 있어요. 그래서 반드시 사람이 검증하고 보완해야 합니다.

    3. AI에게 좋은 요청을 하려면 어떻게 해야 하나요?

    정답 확인 "그래프 그려줘"처럼 막연하게 말하지 말고, 파일명, 열 이름, 원하는 그래프 종류, 제목 등을 구체적으로 설명해야 해요. 요청이 구체적일수록 AI의 응답도 정확해집니다.
