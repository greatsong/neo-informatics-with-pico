    Chapter 08: 1단원 마무리 - 나만의 반응형 장치 만들기¶

    🎯 이 장의 학습 목표¶

    이 장을 마치면 다음을 할 수 있습니다:

    • [ ] 1단원에서 배운 LED, 버튼, 부저를 하나의 프로젝트로 통합할 수 있다
    • [ ] 입력-처리-출력 구조로 간단한 시스템을 설계할 수 있다

    ⏱️ 예상 학습 시간: 약 50분

    📚 미리 알아야 할 것¶

    지금까지 1단원에서 배운 것들을 떠올려 볼까요?

    챕터 배운 내용
    Ch.03 LED 켜고 끄기 (Pin, value())
    Ch.04 버튼 입력 받기 (Pin.IN, if문)
    Ch.05~06 부저로 소리 내기 (PWM, 주파수)
    Ch.07 조건문과 반복문 (if, while, for)

    💡 기억이 잘 안 나도 괜찮아요! 이번 장에서 자연스럽게 복습하게 됩니다.

    📚 핵심 개념¶

    개념 1: 입력-처리-출력 구조¶

    "모든 장치는 세 단계로 동작해요"

    여러분이 자판기를 사용할 때를 생각해 보세요:

    1. 입력: 버튼을 누른다
    2. 처리: 어떤 음료인지 판단한다
    3. 출력: 해당 음료가 나온다

    우리가 만들 장치도 똑같아요!

    flowchart LR A["🔘 버튼\n(입력)"] --> B["🧠 피코\n(처리)"] B --> C["💡 LED\n(출력)"] B --> D["🔔 부저\n(출력)"] style A fill:#e3f2fd,stroke:#1976d2 style B fill:#fff3e0,stroke:#f57c00 style C fill:#e8f5e9,stroke:#388e3c style D fill:#fce4ec,stroke:#c62828

    📌 핵심 정리: 입력(센서/버튼) → 처리(코드/판단) → 출력(LED/부저) 이 구조를 이해하면, 앞으로 어떤 프로젝트든 설계할 수 있어요!

    개념 2: 통합 프로젝트 설계¶

    지금까지는 부품을 하나씩 다뤘어요. 이번에는 여러 부품을 동시에 제어합니다.

    핵심은 간단해요. 각 부품의 코드를 순서대로 조합하면 됩니다!

    버튼 코드 + LED 코드 + 부저 코드 = 반응형 장치 🎉

    🔨 따라하기: 나만의 반응형 장치 만들기¶

    🎯 목표: 버튼을 누르면 LED가 켜지고, 짧은 멜로디가 재생되는 장치

    Step 1: 회로 준비하기¶

    이전 챕터에서 사용한 부품을 모두 연결하세요:

    부품 연결 핀
    LED (+) GP15
    버튼 GP14
    부저 (+) GP13

    ✅ 체크포인트: 세 부품이 모두 피코에 연결되어 있나요?

    Step 2: 기본 설정 코드 작성¶

    from machine import Pin, PWM
import time

# 입력: 버튼
button = Pin(14, Pin.IN, Pin.PULL_DOWN)

# 출력: LED
led = Pin(15, Pin.OUT)

# 출력: 부저
buzzer = PWM(Pin(13))
buzzer.duty_u16(0)  # 처음엔 소리 끄기

    이 코드가 하는 일: 버튼, LED, 부저 세 부품을 각각 초기화합니다.

    Step 3: 멜로디 함수 만들기¶

    def play_melody():
    """짧은 멜로디를 재생하는 함수"""
    notes = [262, 330, 392, 523]  # 도, 미, 솔, 높은 도

    for note in notes:
        buzzer.freq(note)
        buzzer.duty_u16(30000)
        time.sleep(0.2)

    buzzer.duty_u16(0)  # 멜로디 끝나면 소리 끄기

    💡 함수(function)란? 자주 쓰는 코드를 묶어서 이름을 붙인 거예요. play_melody()라고 부르면 멜로디가 재생됩니다!

    Step 4: 메인 동작 코드 작성¶

    print("장치가 준비되었습니다! 버튼을 눌러보세요.")

while True:
    if button.value() == 1:    # 입력: 버튼이 눌렸는지 확인
        led.value(1)           # 출력: LED 켜기
        play_melody()          # 출력: 멜로디 재생
        led.value(0)           # LED 끄기
        time.sleep(0.5)        # 연속 입력 방지

    ✅ 체크포인트: 버튼을 누르면 LED가 켜지고, 도-미-솔-도 멜로디가 들리나요?

    Step 5: 테스트하고 개선하기¶

    잘 동작한다면, 아래 중 하나를 시도해 보세요:

    • 🎵 notes 리스트의 숫자를 바꿔서 나만의 멜로디 만들기
    • ⏱️ time.sleep(0.2)를 바꿔서 빠르기 조절하기
    • 💡 멜로디 재생 중에 LED를 깜빡이게 만들기

    📝 전체 코드¶

    from machine import Pin, PWM
import time

# --- 부품 설정 ---
button = Pin(14, Pin.IN, Pin.PULL_DOWN)
led = Pin(15, Pin.OUT)
buzzer = PWM(Pin(13))
buzzer.duty_u16(0)

# --- 멜로디 함수 ---
def play_melody():
    notes = [262, 330, 392, 523]  # 도, 미, 솔, 높은 도
    for note in notes:
        buzzer.freq(note)
        buzzer.duty_u16(30000)
        time.sleep(0.2)
    buzzer.duty_u16(0)

# --- 메인 루프 ---
print("장치가 준비되었습니다! 버튼을 눌러보세요.")

while True:
    if button.value() == 1:
        led.value(1)
        play_melody()
        led.value(0)
        time.sleep(0.5)

    실행 결과: 

    장치가 준비되었습니다! 버튼을 눌러보세요.
(버튼을 누르면 → LED 켜짐 + 도미솔도 멜로디 → LED 꺼짐)

    ⚠️ 주의할 점¶

    1. 부저가 계속 울린다면? - buzzer.duty_u16(0) 코드가 빠져 있지 않은지 확인하세요 - 멜로디 함수 마지막에 반드시 소리를 꺼야 합니다

    2. 버튼을 한 번 눌렀는데 여러 번 반응한다면? - time.sleep(0.5) 값을 늘려보세요 (예: 0.8) - 이 현상을 바운싱이라고 하는데, 2단원에서 더 자세히 다룹니다

    📌 1단원 핵심 정리¶

    축하합니다! 🎉 1단원을 모두 마쳤어요!

    배운 것 핵심 키워드
    LED 제어 Pin.OUT, value(1), value(0)
    버튼 입력 Pin.IN, Pin.PULL_DOWN
    부저 소리 PWM, freq(), duty_u16()
    프로그래밍 if, while, for, 함수
    설계 구조 입력 → 처리 → 출력

    ✅ 점검하기¶

    1. 입력-처리-출력 구조에서 "버튼"은 어디에 해당하나요?

    정답 확인 **입력**에 해당합니다. 버튼은 사용자의 행동을 피코에게 전달하는 입력 장치예요.

    2. buzzer.duty_u16(0)은 왜 필요한가요?

    정답 확인 부저의 소리를 끄기 위해서입니다. 이 코드가 없으면 부저가 계속 울리게 됩니다.

    3. 아래 체크리스트로 스스로 점검해 보세요:

    • [ ] LED를 코드로 켜고 끌 수 있나요?
    • [ ] 버튼이 눌렸는지 if문으로 확인할 수 있나요?
    • [ ] 부저로 원하는 음을 낼 수 있나요?
    • [ ] 세 부품을 합쳐서 하나의 장치를 만들 수 있나요?

    💡 4개 모두 체크했다면 2단원으로 넘어갈 준비 완료! 2개 이하라면 해당 챕터를 한 번만 더 읽어보세요. 천천히 해도 괜찮아요 😊
