    챕터 22: 조도에 따른 자동 조명 시스템 만들기 💡¶

    🎯 이 장의 학습 목표¶

    이 장을 마치면 다음을 할 수 있습니다:

    • [ ] map() 함수로 값의 범위를 변환하는 방법을 이해한다
    • [ ] 조도 값에 따라 LED 밝기를 자동 조절하는 프로그램을 작성할 수 있다

    예상 학습 시간: 약 40분

    📚 미리 알아야 할 것¶

    이전 장에서 배운 내용을 간단히 떠올려 볼까요?

    • 조도 센서로 빛의 밝기를 숫자(0~65535)로 읽는 방법
    • PWM으로 LED 밝기를 조절하는 방법 (0~100%)
    • if 조건문으로 상황에 따라 다르게 동작시키는 방법

    📚 핵심 개념¶

    개념 1: map() 함수 — 값의 범위를 바꿔주는 통역사 🌐¶

    비유로 시작할게요.

    여러분이 미국 여행을 갔다고 상상해 보세요. 온도계가 77°F(화씨)를 가리키고 있어요. 이게 더운 건지 추운 건지 감이 안 잡히죠? 이때 "화씨 → 섭씨 변환"을 하면 25°C라는 걸 알 수 있어요.

    map() 함수가 바로 이런 통역사 역할을 합니다!

    정확한 정의:

    map(값, 원래 최솟값, 원래 최댓값, 변환 최솟값, 변환 최댓값) → 원래 범위의 값을 새로운 범위의 값으로 비례 변환합니다.

    예시로 확인:

    # 조도 센서값(0~65535)을 LED 밝기(0~100)로 변환
def map(value, from_min, from_max, to_min, to_max):
    return (value - from_min) * (to_max - to_min) / (from_max - from_min) + to_min

# 센서값이 32768이면? (중간 밝기)
result = map(32768, 0, 65535, 0, 100)
print(result)  # 약 50.0 → LED 밝기 50%

    개념 2: 반비례 관계 — 어두울수록 밝게! 🔄¶

    가로등을 떠올려 보세요. 주변이 어두우면 가로등이 환하게 켜지고, 낮에는 꺼져 있죠.

    즉, 조도 센서값과 LED 밝기는 반대로 움직여야 합니다:

    주변 밝기 조도 센서값 LED 밝기
    ☀️ 아주 밝음 65535 (높음) 0% (꺼짐)
    🌤️ 보통 32768 (중간) 50% (중간)
    🌙 어두움 0 (낮음) 100% (최대)

    이 반비례를 map() 함수로 구현하려면, 변환 범위를 뒤집으면 됩니다:

    # 핵심: to_min과 to_max를 뒤집기!
brightness = map(sensor_value, 0, 65535, 100, 0)
#                                        ↑    ↑
#                               100에서 0으로 = 반비례!

    💡 잠깐! 여기까지 이해가 잘 되셨나요? map() 함수는 결국 비례식 계산을 대신 해주는 편리한 도구예요. 수학 공식을 외울 필요 없이 "어디서 어디로 바꿀지"만 알려주면 됩니다!

    🔨 따라하기¶

    Step 1: map 함수 정의하기¶

    마이크로파이썬에는 map() 함수가 내장되어 있지 않으므로, 직접 만들어 줍니다.

    코드: 

    def map(value, from_min, from_max, to_min, to_max):
    return (value - from_min) * (to_max - to_min) / (from_max - from_min) + to_min

    ✅ 체크포인트: 이 함수는 앞으로 계속 사용할 거예요. 의미를 이해하는 게 중요합니다!

    Step 2: 조도 센서 연결 및 값 읽기¶

    코드: 

    from machine import ADC, Pin
import time

sensor = ADC(Pin(26))  # 조도 센서 → GP26

value = sensor.read_u16()  # 0~65535 범위의 값
print("조도 센서값:", value)

    실행 결과: 

    조도 센서값: 42130

    Step 3: 센서값을 LED 밝기로 변환하기¶

    어두울수록 밝게! 반비례 변환을 적용합니다.

    코드: 

    brightness = map(value, 0, 65535, 100, 0)  # 반비례!
print("LED 밝기:", round(brightness), "%")

    실행 결과: 

    LED 밝기: 36 %

    Step 4: PWM으로 LED 밝기 제어하기¶

    코드: 

    from machine import PWM

led = PWM(Pin(15))       # LED → GP15
led.freq(1000)           # 주파수 설정

# 밝기(0~100)를 PWM 듀티값(0~65535)으로 변환
duty = int(map(brightness, 0, 100, 0, 65535))
led.duty_u16(duty)

    Step 5: 반복문으로 자동 조명 완성!¶

    코드: 

    while True:
    value = sensor.read_u16()
    brightness = map(value, 0, 65535, 100, 0)  # 반비례 변환
    duty = int(map(brightness, 0, 100, 0, 65535))
    led.duty_u16(duty)

    print("센서:", value, "→ 밝기:", round(brightness), "%")
    time.sleep(0.5)

    실행 결과: 

    센서: 58000 → 밝기: 12 %
센서: 30000 → 밝기: 54 %
센서: 5000 → 밝기: 92 %

    손으로 센서를 가리면 LED가 밝아지고, 빛을 비추면 LED가 어두워지는 것을 확인하세요! 🎉

    📝 전체 코드¶

    from machine import ADC, Pin, PWM
import time

# map 함수 정의
def map(value, from_min, from_max, to_min, to_max):
    return (value - from_min) * (to_max - to_min) / (from_max - from_min) + to_min

# 하드웨어 설정
sensor = ADC(Pin(26))    # 조도 센서
led = PWM(Pin(15))       # LED
led.freq(1000)

# 자동 조명 루프
while True:
    value = sensor.read_u16()                    # 센서 읽기
    brightness = map(value, 0, 65535, 100, 0)    # 반비례 변환
    duty = int(map(brightness, 0, 100, 0, 65535))
    led.duty_u16(duty)                           # LED 밝기 적용

    print("센서:", value, "→ 밝기:", round(brightness), "%")
    time.sleep(0.5)

    ⚠️ 주의할 점¶

    1. map() 결과는 소수점이 나와요! duty_u16()에는 정수만 넣을 수 있으므로 반드시 int()로 감싸주세요.

    2. 센서를 완전히 가려도 0이 안 나올 수 있어요. 실제 환경에서는 센서 범위를 테스트한 뒤 from_min, from_max 값을 조정하면 더 정확한 반응을 얻을 수 있습니다.

    ✅ 점검하기¶

    1. map(100, 0, 200, 0, 50)의 결과는?

    정답 확인 **25.0**입니다. 100은 0~200 범위에서 딱 절반(50%) 위치이고, 0~50 범위의 절반은 25이기 때문입니다.

    2. 어두울수록 LED를 밝게 하려면 map() 함수를 어떻게 써야 할까요?

    정답 확인 변환 범위를 **뒤집어서** 작성합니다: `map(value, 0, 65535, 100, 0)` — 센서값이 0(어두움)이면 밝기 100, 센서값이 65535(밝음)이면 밝기 0이 됩니다.

    3. 이 원리가 적용된 실생활 예시를 하나 말해보세요.

    정답 확인 **가로등** — 해가 지면 자동으로 켜지고 해가 뜨면 꺼집니다. **자동차 계기판 조명** — 터널에 들어가면 밝아지고, 밝은 곳에서는 어두워집니다.
