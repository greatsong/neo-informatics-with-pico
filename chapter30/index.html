    3단원 마무리 - 스마트 교실 환경 제어기¶

    🎯 이 장의 학습 목표¶

    이 장을 마치면 다음을 할 수 있습니다:

    • [ ] 여러 센서와 출력 장치를 통합한 시스템을 구현할 수 있다
    • [ ] 상태 기계 패턴으로 복잡한 로직을 관리할 수 있다
    • [ ] 센서 값을 기반으로 불쾌지수를 계산하고 판단할 수 있다
    • [ ] 자신의 코드를 문서화하고 설명할 수 있다

    예상 학습 시간: 약 90분

    📚 미리 알아야 할 것¶

    3단원 전체를 마무리하는 종합 프로젝트입니다! 지금까지 배운 내용을 간단히 떠올려 볼까요?

    • 변수와 조건문: 센서 값을 저장하고 조건에 따라 분기하기
    • 함수: 반복되는 로직을 묶어서 재사용하기
    • 반복문: 센서 값을 주기적으로 읽기
    • 센서 입력과 출력 제어: 온습도, 조도 센서 읽기 / LED, 부저 제어하기

    💡 걱정 마세요! 이 장은 새로운 개념을 배우는 게 아니라, 배운 것들을 조합하는 시간이에요. 레고 블록을 하나씩 배웠다면, 이제 멋진 작품을 만드는 거예요!

    💡 왜 이걸 배우나요?¶

    실제 세상의 프로그램은 하나의 센서, 하나의 기능만 가지고 있지 않아요. 스마트폰을 떠올려 보세요. 밝기 센서로 화면 밝기를 조절하고, 온도 센서로 과열을 감지하고, 여러 상태(잠금, 홈 화면, 앱 실행 등)를 오가죠.

    "스마트 교실 환경 제어기"는 바로 이런 통합 시스템의 축소판이에요:

    • 🌡️ 온습도가 높으면 → "환기하세요!" 알림
    • 🔆 교실이 어두우면 → "조명을 켜세요!" 제안
    • 여러 상황을 상태(state)로 관리

    이 프로젝트를 완성하면, 여러분은 "센서 읽기 → 판단하기 → 행동하기"라는 IoT 시스템의 핵심 흐름을 직접 경험하게 됩니다.

    📚 핵심 개념¶

    개념 1: 시스템 통합 — 레고 조립하기¶

    지금까지 우리는 블록을 하나씩 만들었어요:

    • "온도 읽기" 블록
    • "조도 읽기" 블록
    • "LED 켜기" 블록
    • "부저 울리기" 블록

    시스템 통합이란, 이 블록들을 하나의 프로그램 안에서 유기적으로 연결하는 것이에요. 마치 레고 블록을 조립해서 하나의 완성품을 만드는 것처럼요.

    # 각 블록(함수)을 만들고
def read_temperature():
    ...

def read_light():
    ...

def alert_ventilation():
    ...

# 하나의 시스템으로 조립!
while True:
    temp = read_temperature()
    light = read_light()

    if temp > 28:
        alert_ventilation()
    if light < 300:
        suggest_light_on()

    핵심은 각 기능을 함수로 분리한 뒤, 메인 루프에서 조합하는 거예요.

    개념 2: 불쾌지수 — 센서 값을 의미 있는 정보로¶

    온도와 습도 숫자만으로는 "지금 불쾌한가?"를 판단하기 어려워요. 그래서 기상청에서 사용하는 불쾌지수(THI) 공식을 활용합니다:

    불쾌지수 = 1.8 × 온도 - 0.55 × (1 - 습도/100) × (1.8 × 온도 - 26) + 32

    이 공식의 결과로 나온 숫자의 의미는 이렇습니다:

    • 68 미만: 쾌적해요 😊
    • 68~75: 약간 불쾌해요 😐
    • 75~80: 불쾌해요 😣
    • 80 이상: 매우 불쾌해요 🥵
    def calc_discomfort(temp, humidity):
    """불쾌지수를 계산하는 함수"""
    thi = 1.8 * temp - 0.55 * (1 - humidity / 100) * (1.8 * temp - 26) + 32
    return round(thi, 1)  # 소수점 1자리까지

# 사용 예시
thi = calc_discomfort(28, 70)
print(f"불쾌지수: {thi}")  # 결과: 불쾌지수: 77.8

    💡 포인트! 센서의 "날것 그대로의 숫자"를 사람이 이해할 수 있는 "의미 있는 정보"로 바꾸는 과정이에요. 이것이 프로그래밍의 힘이랍니다!

    개념 3: 상태 기계 — 교실의 "기분"을 관리하기¶

    교실 환경은 한순간에 여러 상태 중 하나에 있어요. 이걸 체계적으로 관리하는 패턴이 상태 기계(State Machine)입니다.

    학교를 비유로 생각해 볼게요. 학교에는 "수업 중", "쉬는 시간", "점심시간" 같은 상태가 있고, 종이 울리면 다음 상태로 전환되죠. 우리 프로그램도 마찬가지예요!

    stateDiagram-v2 [*] --> 쾌적 쾌적 --> 더움주의: 불쾌지수 68 이상 쾌적 --> 어두움주의: 조도 300 미만 더움주의 --> 쾌적: 불쾌지수 68 미만 더움주의 --> 위험: 불쾌지수 80 이상 위험 --> 더움주의: 불쾌지수 80 미만 어두움주의 --> 쾌적: 조도 300 이상

    코드로는 이렇게 표현해요:

    # 상태를 문자열 변수 하나로 관리
current_state = "쾌적"

def update_state(thi, light):
    global current_state

    if thi >= 80:
        current_state = "위험"
    elif thi >= 68:
        current_state = "더움주의"
    elif light < 300:
        current_state = "어두움주의"
    else:
        current_state = "쾌적"

    return current_state

    상태 기계의 장점: 조건이 아무리 복잡해져도, "지금 어떤 상태인가?"만 보면 무엇을 해야 할지 바로 알 수 있어요!

    개념 4: 코드 문서화 — 미래의 나에게 보내는 편지¶

    한 달 뒤에 자기가 짠 코드를 다시 보면, "이게 뭐였지?" 하는 경험이 반드시 찾아옵니다. 그래서 문서화가 중요해요.

    좋은 문서화의 세 가지 원칙:

    • 함수마다 docstring 작성: 이 함수가 무엇을 하는지 한 줄로 설명
    • 왜(Why)를 적기: 코드가 "무엇을" 하는지는 코드 자체로 보이지만, "왜" 이렇게 했는지는 주석으로만 알 수 있어요
    • 프로그램 설명서 작성: 전체 시스템이 어떤 기능을 하는지 정리
    def alert_ventilation(thi_value):
    """불쾌지수가 높을 때 환기 알림을 울리는 함수

    Args:
        thi_value: 현재 불쾌지수 값
    """
    # 75 이상일 때만 부저를 울림 (68~75는 LED 경고만)
    # 이유: 부저가 너무 자주 울리면 수업에 방해됨
    if thi_value >= 75:
        buzzer_on()
    led_warning_on()

    💡 잠깐! 여기까지 4가지 핵심 개념을 살펴봤어요. 새로운 게 아니라 배운 것들의 조합이라는 게 느껴지시나요? 이제 직접 만들어 봅시다!

    🔨 따라하기: 스마트 교실 환경 제어기 만들기¶

    Step 1: 센서 시뮬레이터 만들기¶

    실제 센서가 없어도 괜찮아요! random 모듈로 센서를 흉내 내겠습니다.

    import random
import time

def read_temperature():
    """온도 센서 읽기 (시뮬레이션: 20~35도)"""
    return round(random.uniform(20, 35), 1)

def read_humidity():
    """습도 센서 읽기 (시뮬레이션: 30~90%)"""
    return round(random.uniform(30, 90), 1)

def read_light():
    """조도 센서 읽기 (시뮬레이션: 100~800 lux)"""
    return random.randint(100, 800)

    ✅ 체크포인트: 각 함수를 호출해서 값이 나오는지 확인해 보세요! 

    print(read_temperature())  # 예: 27.3
print(read_humidity())     # 예: 65.2
print(read_light())        # 예: 450

    Step 2: 불쾌지수 계산 함수 만들기¶

    def calc_discomfort(temp, humidity):
    """불쾌지수(THI)를 계산하는 함수"""
    thi = 1.8 * temp - 0.55 * (1 - humidity / 100) * (1.8 * temp - 26) + 32
    return round(thi, 1)

def get_comfort_level(thi):
    """불쾌지수를 사람이 읽을 수 있는 단계로 변환"""
    if thi >= 80:
        return "매우불쾌"
    elif thi >= 75:
        return "불쾌"
    elif thi >= 68:
        return "약간불쾌"
    else:
        return "쾌적"

    Step 3: 상태 판단 함수 만들기¶

    def determine_state(thi, light):
    """센서 값을 종합하여 교실 상태를 판단"""
    if thi >= 80:
        return "🚨 위험"
    elif thi >= 68 and light < 300:
        return "⚠️ 복합주의"   # 덥고 어둡다
    elif thi >= 68:
        return "🌡️ 더움주의"
    elif light < 300:
        return "🔅 어두움주의"
    else:
        return "✅ 쾌적"

    💡 포인트! 복합 조건(and)을 사용해서 "덥고 어두운" 상황도 처리했어요. 실제 교실에서는 여러 문제가 동시에 발생할 수 있으니까요.

    Step 4: 출력(알림) 함수 만들기¶

    def take_action(state, thi, light):
    """상태에 따라 적절한 조치를 안내"""
    print(f"\n{'='*40}")
    print(f"  현재 상태: {state}")
    print(f"  불쾌지수: {thi} | 조도: {light} lux")
    print(f"{'='*40}")

    if "위험" in state:
        print("  🔴 [긴급] 즉시 환기가 필요합니다!")
        print("  🔴 에어컨 가동을 권장합니다!")
        print("  🔊 부저: 삐삐삐!")  # 실제로는 buzzer_on()

    elif "더움" in state:
        print("  🟡 창문을 열어 환기해 주세요.")
        print("  💡 LED: 노란색 점등")  # 실제로는 led_yellow()

    elif "어두움" in state:
        print("  🟡 조명을 켜는 것을 추천합니다.")
        print("  💡 LED: 파란색 점등")

    elif "복합" in state:
        print("  🟡 환기도 하고 조명도 켜주세요!")

    else:
        print("  🟢 교실 환경이 쾌적합니다.")
        print("  💡 LED: 초록색 점등")

    Step 5: 메인 루프로 통합하기¶

    이제 모든 블록을 조립합니다!

    def main():
    """스마트 교실 환경 제어기 메인 함수"""
    print("🏫 스마트 교실 환경 제어기 시작!")
    print("   Ctrl+C 를 누르면 종료됩니다.\n")

    cycle = 0

    try:
        while True:
            cycle += 1
            print(f"\n--- 측정 #{cycle} ---")

            # 1. 센서 읽기
            temp = read_temperature()
            humidity = read_humidity()
            light = read_light()
            print(f"  온도: {temp}°C | 습도: {humidity}% | 조도: {light} lux")

            # 2. 불쾌지수 계산
            thi = calc_discomfort(temp, humidity)
            level = get_comfort_level(thi)
            print(f"  불쾌지수: {thi} ({level})")

            # 3. 상태 판단
            state = determine_state(thi, light)

            # 4. 조치 실행
            take_action(state, thi, light)

            # 5. 3초 대기 후 다시 측정
            time.sleep(3)

    except KeyboardInterrupt:
        print("\n\n🏫 환경 제어기를 종료합니다. 수고하셨습니다!")

# 프로그램 실행
main()

    📝 전체 코드¶

    import random
import time

# ===== 1. 센서 읽기 함수 =====
def read_temperature():
    """온도 센서 읽기 (시뮬레이션)"""
    return round(random.uniform(20, 35), 1)

def read_humidity():
    """습도 센서 읽기 (시뮬레이션)"""
    return round(random.uniform(30, 90), 1)

def read_light():
    """조도 센서 읽기 (시뮬레이션)"""
    return random.randint(100, 800)

# ===== 2. 데이터 처리 함수 =====
def calc_discomfort(temp, humidity):
    """불쾌지수(THI) 계산"""
    thi = 1.8 * temp - 0.55 * (1 - humidity / 100) * (1.8 * temp - 26) + 32
    return round(thi, 1)

def get_comfort_level(thi):
    """불쾌지수를 단계 문자열로 변환"""
    if thi >= 80:
        return "매우불쾌"
    elif thi >= 75:
        return "불쾌"
    elif thi >= 68:
        return "약간불쾌"
    else:
        return "쾌적"

# ===== 3. 상태 판단 함수 =====
def determine_state(thi, light):
    """교실 환경 상태를 종합 판단"""
    if thi >= 80:
        return "🚨 위험"
    elif thi >= 68 and light < 300:
        return "⚠️ 복합주의"
    elif thi >= 68:
        return "🌡️ 더움주의"
    elif light < 300:
        return "🔅 어두움주의"
    else:
        return "✅ 쾌적"

# ===== 4. 출력(알림) 함수 =====
def take_action(state, thi, light):
    """상태에 따른 조치 안내"""
    print(f"\n{'='*40}")
    print(f"  현재 상태: {state}")
    print(f"  불쾌지수: {thi} | 조도: {light} lux")
    print(f"{'='*40}")

    if "위험" in state:
        print("  🔴 즉시 환기 + 에어컨 가동 권장!")
    elif "복합" in state:
        print("  🟡 환기하고 조명도 켜주세요!")
    elif "더움" in state:
        print("  🟡 창문을 열어 환기해 주세요.")
    elif "어두움" in state:
        print("  🟡 조명을 켜는 것을 추천합니다.")
    else:
        print("  🟢 교실 환경이 쾌적합니다!")

# ===== 5. 메인 함수 =====
def main():
    print("🏫 스마트 교실 환경 제어기 시작!\n")
    cycle = 0

    try:
        while True:
            cycle += 1
            temp = read_temperature()
            humidity = read_humidity()
            light = read_light()
            thi = calc_discomfort(temp, humidity)
            level = get_comfort_level(thi)
            state = determine_state(thi, light)

            print(f"[#{cycle}] 온도:{temp}°C 습도:{humidity}% 조도:{light}lux")
            print(f"       불쾌지수:{thi}({level})")
            take_action(state, thi, light)

            time.sleep(3)
    except KeyboardInterrupt:
        print("\n🏫 종료합니다. 수고하셨습니다!")

main()

    ⚠️ 자주 하는 실수¶

    실수 1: 상태 조건의 순서를 잘못 배치하기

    # ❌ 잘못된 순서
if thi >= 68:
    return "더움주의"
elif thi >= 80:      # 여기에 절대 도달하지 않음!
    return "위험"
    • 왜 이런 일이 생기나요? thi가 85일 때, >= 68이 먼저 True가 되어서 "위험"까지 가지 않아요.
    • 이렇게 해결해요: 더 엄격한 조건(큰 값)을 먼저 검사하세요!
    # ✅ 올바른 순서: 큰 값부터!
if thi >= 80:
    return "위험"
elif thi >= 68:
    return "더움주의"

    실수 2: global 변수 남용하기

    # ❌ 전역 변수를 여기저기서 수정
state = "쾌적"
temp = 0

def update():
    global state, temp  # 이런 게 많아지면 버그 추적이 어려움
    • 이렇게 해결해요: 함수의 매개변수와 반환값으로 데이터를 전달하세요. 위 전체 코드처럼요!

    실수 3: 무한 루프에서 탈출 방법을 안 만들기

    # ❌ 종료할 수 없는 프로그램
while True:
    do_something()  # 영원히 반복...
    • 이렇게 해결해요: try-except KeyboardInterrupt를 반드시 넣어서 Ctrl+C로 안전하게 종료할 수 있게 하세요.
