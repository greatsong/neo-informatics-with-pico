    처음 만나는 피코2와 개발환경¶

    🎯 이 장의 학습 목표¶

    이 장을 마치면 다음을 할 수 있습니다:

    • [ ] 라즈베리파이 피코2 WH의 주요 구성요소를 알아볼 수 있다
    • [ ] Thonny IDE를 설치하고 피코2와 연결할 수 있다
    • [ ] 첫 번째 Python 코드를 실행하여 결과를 확인할 수 있다

    예상 학습 시간: 약 50분

    📚 미리 알아야 할 것¶

    이전 장에서 마이크로컨트롤러가 무엇인지 간단히 살펴봤어요. 오늘은 그 마이크로컨트롤러인 피코2 WH를 직접 눈으로 살펴보고, 컴퓨터와 연결해서 첫 코드를 실행해 볼 거예요! 🎉

    📚 핵심 개념¶

    개념 1: 피코2 WH 보드 알아보기¶

    "피코2 WH는 마치 작은 사람의 몸과 같아요" 🧍

    우리 몸에 뇌, 심장, 손발이 있듯이, 피코2 보드에도 각각의 역할을 하는 부분이 있습니다.

    부품 우리 몸 비유 하는 일

    GPIO 핀 🖐️ 손과 발 LED, 센서 등 외부 장치와 연결해요

    WH가 뭐예요? W는 Wi-Fi/Bluetooth 무선 기능, H는 Header(핀이 미리 납땜됨)를 뜻해요. 덕분에 납땜 없이 바로 사용할 수 있어요!

    개념 2: Thonny IDE — 피코2와 대화하는 도구¶

    "Thonny는 마치 번역기 같아요" 🗣️

    우리가 한국어를 쓰듯이, 피코2에게는 Python이라는 언어로 명령을 내려야 해요. Thonny는 우리가 작성한 Python 코드를 피코2에게 전달해주는 통역사 역할을 합니다.

    flowchart LR A["👤 나<br/>(코드 작성)"] -->|Python 코드| B["💻 Thonny IDE<br/>(통역사)"] B -->|USB 케이블| C["🟢 피코2<br/>(실행)"] C -->|결과 전달| B style A fill:#e3f2fd,stroke:#1976d2 style B fill:#fff3e0,stroke:#f57c00 style C fill:#e8f5e9,stroke:#388e3c

    💡 IDE란 통합 개발 환경(Integrated Development Environment)의 줄임말이에요. 코드 작성, 실행, 오류 확인을 한 곳에서 할 수 있는 프로그램이랍니다.

    🔨 따라하기¶

    Step 1: Thonny 설치하기¶

    1. 웹 브라우저에서 thonny.org 에 접속합니다
    2. 화면 오른쪽 위에서 자신의 운영체제(Windows / Mac / Linux)를 클릭합니다
    3. 다운로드된 설치 파일을 실행하고 Next → Next → Install 순서로 클릭합니다

    ✅ 체크포인트: 바탕화면이나 시작 메뉴에 Thonny 아이콘이 보이면 성공이에요!

    Step 2: 피코2에 MicroPython 펌웨어 설치하기¶

    피코2가 Python을 이해하려면, 먼저 MicroPython이라는 운영체제를 설치해야 해요.

    1. 피코2 보드의 BOOTSEL 버튼을 누른 채로 USB 케이블을 컴퓨터에 연결합니다
    2. 컴퓨터에 RPI-RP2라는 USB 드라이브가 나타납니다 (마치 USB 메모리처럼!)
    3. Thonny를 실행합니다
    4. 하단 오른쪽 구석에 인터프리터가 표시되는 부분을 클릭하고, "MicroPython (Raspberry Pi Pico)"를 선택합니다
    5. Thonny가 "펌웨어를 설치하시겠습니까?"라고 물으면 Install을 클릭합니다

    ⚠️ BOOTSEL 버튼을 먼저 누르고 있는 상태에서 USB를 연결해야 해요. 순서가 바뀌면 드라이브가 나타나지 않습니다!

    ✅ 체크포인트: Thonny 하단 Shell(쉘) 창에 MicroPython v1.2x.x 같은 메시지가 나타나면 성공이에요!

    Step 3: 피코2와 연결 확인하기¶

    펌웨어 설치가 끝났다면, 피코2를 일반적으로 연결해 봅시다.

    1. USB 케이블로 피코2와 컴퓨터를 연결합니다 (이번에는 버튼 안 눌러도 돼요)
    2. Thonny 하단 오른쪽에서 "MicroPython (Raspberry Pi Pico)"가 선택되어 있는지 확인합니다
    3. Shell 창에 >>> 표시가 나타나면 연결 성공!

    >>> 표시는 "명령을 기다리고 있어요"라는 뜻이에요. 마치 피코2가 귀를 쫑긋 세우고 여러분의 말을 기다리는 것과 같아요 👂

    Step 4: 첫 코드 실행하기! 🎉¶

    드디어 첫 코드를 실행할 차례예요!

    코드: 

    print("안녕, 피코!")

    Thonny 위쪽 편집 창(넓은 영역)에 위 코드를 입력하고, ▶ 실행 버튼(초록색 재생 버튼)을 클릭하세요.

    실행 결과: 

    안녕, 피코!

    Shell 창에 위 문장이 나타났다면, 축하합니다! 여러분이 피코2에게 보낸 첫 번째 명령이 성공적으로 실행된 거예요! 🥳

    Step 5: 조금 더 해보기¶

    코드: 

    # 나의 첫 피코2 프로그램
print("안녕, 피코!")
print("나는 프로그래밍을 시작했어!")
print("1 + 1 =", 1 + 1)

    실행 결과: 

    안녕, 피코!
나는 프로그래밍을 시작했어!
1 + 1 = 2

    💡 잠깐! #으로 시작하는 줄은 주석이라고 해요. 사람이 읽기 위한 메모이고, 피코2는 이 줄을 무시합니다.

    📝 전체 코드¶

    # 나의 첫 피코2 프로그램
# 챕터 2 - 처음 만나는 피코2와 개발환경

print("안녕, 피코!")
print("나는 프로그래밍을 시작했어!")
print("1 + 1 =", 1 + 1)

    ⚠️ 주의할 점¶

    1. 피코2가 인식되지 않을 때 - USB 케이블이 데이터 전송용인지 확인하세요. 충전만 되는 케이블은 연결이 안 돼요! - 다른 USB 포트에 꽂아보세요 - Thonny 하단에서 인터프리터를 다시 선택해보세요

    2. Shell에 >>> 가 안 나올 때 - Thonny 메뉴에서 실행 → 인터프리터 설정에서 "MicroPython (Raspberry Pi Pico)"를 선택합니다 - 빨간 정지 버튼(🔴)을 한 번 클릭한 후 기다려보세요

    ✅ 점검하기¶

    1. 피코2 보드에서 프로그램을 실행하는 "두뇌" 역할을 하는 칩의 이름은?

    정답 확인 **RP2350** 칩입니다. 피코2의 중앙에 있는 검은색 사각형 칩이에요.

    2. BOOTSEL 버튼은 언제 사용하나요?

    정답 확인 **MicroPython 펌웨어를 처음 설치할 때** 사용합니다. BOOTSEL 버튼을 누른 채로 USB를 연결하면 피코2가 USB 드라이브처럼 인식되어 펌웨어를 설치할 수 있어요.

    3. Thonny Shell 창에서 >>> 표시는 무슨 뜻인가요?

    정답 확인 피코2가 **명령을 기다리고 있다**는 뜻이에요. 이 표시가 보이면 피코2와 정상적으로 연결된 것입니다.

    📌 이 장의 핵심 정리¶

    • ✅ 피코2 WH는 두뇌(RP2350), 연결 통로(USB), 손발(GPIO 핀)로 구성되어 있어요
    • ✅ Thonny IDE는 우리와 피코2 사이의 통역사 역할을 해요
    • ✅ print() 명령어로 피코2에게 글자를 출력하도록 시킬 수 있어요
