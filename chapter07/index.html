    Chapter 07. 부저로 소리 만들기 🎵¶

    🎯 이 장의 학습 목표¶

    이 장을 마치면 다음을 할 수 있습니다:

    • [ ] 부저를 연결하고 원하는 높낮이의 소리를 낼 수 있다
    • [ ] 주파수와 음계의 관계를 이해하고, 간단한 멜로디를 연주할 수 있다

    예상 학습 시간: 약 45분

    📚 미리 알아야 할 것¶

    지난 장에서 우리는 피코에 Grove 부품을 연결하고, 코드로 제어하는 법을 배웠어요. 이번에도 같은 방식으로 Grove 부저를 연결할 거예요. import, Pin, 그리고 반복문(for)을 사용했던 기억을 떠올려 주세요!

    📚 핵심 개념¶

    개념 1: 주파수 — 소리의 높낮이¶

    "주파수는 마치 줄넘기의 속도와 같아요."

    줄넘기를 천천히 돌리면 줄이 느릿느릿 움직이고, 빠르게 돌리면 휘익 빠르게 움직이죠? 소리도 마찬가지예요. 공기가 빠르게 떨리면 높은 소리, 느리게 떨리면 낮은 소리가 납니다.

    이 "떨리는 빠르기"를 주파수라고 하고, 단위는 Hz(헤르츠)를 써요.

    주파수 느낌
    낮은 Hz (예: 200Hz) 웅~ 낮은 소리 🐻
    높은 Hz (예: 1000Hz) 삐~ 높은 소리 🐦

    개념 2: 음계와 주파수의 관계¶

    우리가 아는 도레미파솔라시도에는 각각 정해진 주파수가 있어요.

    음계 도 레 미 파 솔 라 시 높은 도
    주파수(Hz) 262 294 330 349 392 440 494 523

    💡 기억 포인트: 숫자가 커질수록 음이 높아져요! "라(440Hz)"는 전 세계 악기의 기준음이랍니다.

    🔨 따라하기¶

    Step 1: 부저 연결하기¶

    Grove 부저를 피코 보드의 포트 0번에 연결하세요. 케이블을 꾹 눌러 끝까지 꽂으면 됩니다.

    flowchart LR A["🔊 Grove 부저"] -- "Grove 케이블" --> B["📟 피코 포트 0 (GP0)"] style A fill:#fff3e0,stroke:#f57c00 style B fill:#e3f2fd,stroke:#1976d2

    ✅ 체크포인트: 케이블이 딸깍 소리와 함께 단단히 고정되었나요?

    Step 2: 소리 한 번 내보기¶

    Thonny를 열고 아래 코드를 입력해 보세요.

    from machine import Pin, PWM
import time

# 부저를 PWM으로 설정 (GP0 핀)
buzzer = PWM(Pin(0))

# 도(262Hz) 소리 내기
buzzer.freq(262)       # 주파수를 262Hz로 설정
buzzer.duty_u16(32768) # 소리 크기 (중간 세기)

time.sleep(1)          # 1초 동안 울림

buzzer.duty_u16(0)     # 소리 끄기

    실행 결과: 

    🔊 "도~" 소리가 1초 동안 울린 뒤 멈춥니다

    💡 잠깐! PWM이 처음 보여도 걱정 마세요. "전기 신호를 빠르게 껐다 켰다 해서 소리를 만드는 기능"이라고만 이해하면 충분해요. duty_u16(32768)은 소리 크기를 절반(중간)으로 설정한 거예요.

    Step 3: 도레미파솔 연주하기¶

    이번에는 리스트에 주파수를 담아 여러 음을 연속으로 연주해 볼게요.

    from machine import Pin, PWM
import time

buzzer = PWM(Pin(0))

# 도레미파솔 주파수 리스트
melody = [262, 294, 330, 349, 392]

for freq in melody:
    buzzer.freq(freq)
    buzzer.duty_u16(32768)
    time.sleep(0.5)       # 각 음을 0.5초씩
    buzzer.duty_u16(0)
    time.sleep(0.1)       # 음 사이 짧은 쉼

buzzer.duty_u16(0)        # 연주 끝, 소리 끄기

    실행 결과: 

    🔊 도 → 레 → 미 → 파 → 솔 이 차례로 들립니다!

    ✅ 체크포인트: 음이 점점 높아지는 게 느껴지나요? 축하해요, 피코가 노래를 부르고 있어요! 🎉

    Step 4: "학교종"을 연주해보자! 🏫¶

    "학교종이 땡땡땡"의 첫 소절을 연주해 볼게요. 음과 박자를 함께 리스트로 만듭니다.

    from machine import Pin, PWM
import time

buzzer = PWM(Pin(0))

# 음 이름표 (보기 쉽게)
C = 262  # 도
D = 294  # 레
E = 330  # 미
G = 392  # 솔

# 학교종: 솔솔라라 솔솔미 솔솔미미 레
notes =    [G, G, 440, 440, G, G, E, G, G, E, E, D]
duration = [0.4, 0.4, 0.4, 0.4, 0.4, 0.4, 0.8,
            0.4, 0.4, 0.4, 0.4, 0.8]

for i in range(len(notes)):
    buzzer.freq(notes[i])
    buzzer.duty_u16(32768)
    time.sleep(duration[i])
    buzzer.duty_u16(0)
    time.sleep(0.05)

buzzer.duty_u16(0)

    실행 결과: 

    🔊 ♪ 솔솔라라 솔솔미~ 솔솔미미 레~ ♪

    💡 포인트: notes 리스트에는 어떤 음을, duration 리스트에는 얼마나 길게 연주할지를 담았어요. 두 리스트가 짝꿍처럼 함께 움직입니다!

    📝 전체 코드¶

    학교종 연주 전체 코드입니다. 복사해서 바로 실행해 보세요!

    from machine import Pin, PWM
import time

buzzer = PWM(Pin(0))

# 음계 정의
C = 262; D = 294; E = 330; F = 349
G = 392; A = 440; B = 494

# 학교종 첫 소절
notes =    [G, G, A, A, G, G, E, G, G, E, E, D]
duration = [0.4, 0.4, 0.4, 0.4, 0.4, 0.4, 0.8,
            0.4, 0.4, 0.4, 0.4, 0.8]

for i in range(len(notes)):
    buzzer.freq(notes[i])
    buzzer.duty_u16(32768)
    time.sleep(duration[i])
    buzzer.duty_u16(0)
    time.sleep(0.05)

buzzer.duty_u16(0)
print("연주 끝!")

    ⚠️ 주의할 점¶

    1. 소리가 안 날 때: duty_u16(0)이 아니라 duty_u16(32768)로 설정했는지 확인하세요. 0이면 소리가 꺼진 상태예요!

    2. 연주 후 반드시 소리 끄기: 코드 마지막에 buzzer.duty_u16(0)을 빼먹으면 부저가 계속 울릴 수 있어요. 삐~ 소리가 멈추지 않으면 당황하지 말고 Thonny의 Stop 버튼을 누른 뒤, buzzer.duty_u16(0)을 실행하세요.

    ✅ 점검하기¶

    1. 주파수 숫자가 커지면 소리는 어떻게 변하나요?

    정답 확인 주파수가 커지면 소리가 **높아집니다**. 예: 262Hz(도) → 392Hz(솔)로 갈수록 높은 음이 나요.

    2. 아래 코드에서 time.sleep(0.05)의 역할은 무엇인가요? 

    buzzer.duty_u16(0)
time.sleep(0.05)

    정답 확인 음과 음 사이에 **짧은 쉼표(무음)** 를 넣어서 각 음이 구분되게 해줍니다. 이게 없으면 음이 이어 붙어서 멜로디가 뭉개져 들려요.

    3. "레미레" 세 음을 연주하려면 notes 리스트를 어떻게 만들면 될까요?

    정답 확인 
    notes = [294, 330, 294]
    D(레)=294, E(미)=330이니까 이렇게 담으면 됩니다!
