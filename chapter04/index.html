    Chapter 04: Grove 센서 시스템 이해하기¶

    🎯 이 장의 학습 목표¶

    이 장을 마치면 다음을 할 수 있습니다:

    • [ ] Grove 시스템이 무엇인지, 왜 편리한지 설명할 수 있다
    • [ ] Grove 쉴드의 포트 종류(디지털/아날로그/I2C)를 구분할 수 있다
    • [ ] 버튼 센서를 연결하고 신호를 읽는 코드를 작성할 수 있다

    예상 학습 시간: 약 50분

    📚 미리 알아야 할 것¶

    지난 장에서 우리는 피코2에 MicroPython 펌웨어를 설치하고, Thonny에서 LED를 깜빡이는 코드를 실행해봤어요. 피코2가 코드를 받아 실행하는 흐름이 기억나시죠? 이번 장에서는 피코2에 센서를 연결하는 방법을 배웁니다!

    📚 핵심 개념¶

    개념 1: Grove 시스템 — 레고 블록 같은 센서 연결¶

    "Grove는 마치 레고 블록과 같아요."

    레고는 블록 위의 돌기에 다른 블록을 '딸깍' 끼우기만 하면 되죠? 방향이나 크기를 고민할 필요가 없어요. Grove 시스템도 똑같습니다.

    정확한 정의: Grove는 Seeed Studio에서 만든 표준화된 센서 연결 시스템입니다. 모든 센서와 보드가 동일한 4핀 커넥터를 사용해서, 케이블 하나로 '딸깍' 꽂으면 연결이 끝납니다.

    브레드보드 배선 vs Grove 연결:

    항목 브레드보드 배선 Grove 시스템
    연결 방법 점퍼선 여러 개 케이블 1개
    실수 가능성 높음 (잘못 꽂기 쉬움) 거의 없음
    소요 시간 수 분 3초
    필요한 지식 핀 배열, 저항값 등 포트에 꽂기만!

    💡 핵심: Grove를 쓰면 배선 실수 걱정 없이 센서 자체에 집중할 수 있어요!

    개념 2: Grove 쉴드와 포트의 종류¶

    피코2에 Grove 센서를 연결하려면 Grove Shield(쉴드)가 필요합니다. 쉴드는 피코2 위에 얹는 확장 보드로, 여러 개의 Grove 포트가 달려 있어요.

    flowchart TB subgraph Shield["Grove 쉴드 (피코2 위에 장착)"] D1["🟡 D16 - 디지털"] D2["🟡 D18 - 디지털"] A1["🔵 A0 - 아날로그"] A2["🔵 A1 - 아날로그"] I1["🔴 I2C-1"] I2["🔴 I2C-2"] end P["Pico2 보드"] --- Shield

    세 가지 포트를 기억하세요:

    포트 종류 신호 타입 읽을 수 있는 값 예시 센서
    디지털(D) 0 또는 1 켜짐/꺼짐 버튼, 모션 감지
    아날로그(A) 0~65535 연속적인 수치 빛 센서, 온도 센서
    I2C 데이터 통신 복합 데이터 LCD 디스플레이, 컬러 센서

    쉽게 비유하면: - 디지털 = 전등 스위치 (ON/OFF 두 가지) - 아날로그 = 볼륨 다이얼 (0부터 최대까지 부드럽게) - I2C = USB처럼 여러 정보를 주고받는 대화 채널

    💡 잠깐! 여기까지 이해되셨나요? "디지털 = 0 or 1, 아날로그 = 범위 값, I2C = 대화"만 기억하면 충분해요!

    🔨 따라하기: 버튼 센서로 신호 읽기¶

    Grove 버튼 센서를 연결하고, 버튼을 누르면 값이 바뀌는 것을 확인해봅시다.

    Step 1: 하드웨어 연결¶

    1. 피코2를 Grove 쉴드 위에 꽂습니다 (핀 방향 맞춰서)
    2. Grove 버튼 모듈과 쉴드의 D16 포트를 Grove 케이블로 연결합니다
    3. 피코2를 USB로 컴퓨터에 연결합니다
    flowchart LR B["🔘 Grove 버튼"] -->|Grove 케이블| S["Grove 쉴드\nD16 포트"] S -->|장착| P["Pico2"] P -->|USB| C["💻 컴퓨터"]

    ✅ 체크포인트: 케이블이 '딸깍' 소리와 함께 단단히 꽂혔는지 확인하세요!

    Step 2: Thonny에서 코드 작성¶

    Thonny를 열고 아래 코드를 입력하세요.

    from machine import Pin
import time

# 버튼이 연결된 핀 설정 (D16 포트 = GP16)
button = Pin(16, Pin.IN)

# 반복해서 버튼 상태 읽기
while True:
    value = button.value()   # 0 또는 1 읽기
    print("버튼 상태:", value)
    time.sleep(0.5)          # 0.5초마다 확인

    Step 3: 실행하고 결과 확인¶

    ▶ 버튼을 눌러 실행하세요.

    실행 결과 (Shell 창): 

    버튼 상태: 0
버튼 상태: 0
버튼 상태: 1    ← 버튼을 누른 순간!
버튼 상태: 1
버튼 상태: 0    ← 버튼에서 손을 뗀 순간

    • 0 = 버튼을 안 누른 상태
    • 1 = 버튼을 누른 상태

    ✅ 체크포인트: 버튼을 누를 때 Shell에 1이 출력되면 성공이에요! 🎉

    Step 4: 프로그램 멈추기¶

    Shell 창에서 Ctrl + C를 누르면 프로그램이 멈춥니다. 또는 Thonny의 🔴 Stop 버튼을 클릭하세요.

    📝 전체 코드¶

    from machine import Pin
import time

# 버튼 센서: Grove 쉴드 D16 포트에 연결
button = Pin(16, Pin.IN)

while True:
    value = button.value()
    print("버튼 상태:", value)
    time.sleep(0.5)

    ⚠️ 주의할 점¶

    1. 쉴드 장착 방향 확인: 피코2를 쉴드에 꽂을 때 USB 포트 방향과 쉴드의 표시를 맞춰주세요. 거꾸로 꽂으면 동작하지 않거나 고장날 수 있어요!

    2. 포트 번호와 코드 일치: D16 포트에 연결했으면 코드에서도 Pin(16, ...)이어야 해요. D18 포트에 연결했다면 Pin(18, ...)로 바꿔야 합니다.

    ✅ 점검하기¶

    1. Grove 시스템의 가장 큰 장점은 무엇인가요?

    정답 확인 표준화된 4핀 커넥터로 케이블 하나만 꽂으면 연결이 끝나서, 복잡한 배선 없이 빠르고 안전하게 센서를 연결할 수 있습니다.

    2. 버튼처럼 ON/OFF 두 가지 상태만 있는 센서는 어떤 포트에 연결하나요?

    정답 확인 **디지털(D) 포트**에 연결합니다. 디지털 포트는 0과 1, 두 가지 값을 읽을 수 있어요.

    3. 빛의 밝기처럼 연속적인 값을 읽으려면 어떤 포트를 사용해야 할까요?

    정답 확인 **아날로그(A) 포트**를 사용합니다. 아날로그 포트는 0~65535 범위의 연속적인 수치를 읽을 수 있어요.
