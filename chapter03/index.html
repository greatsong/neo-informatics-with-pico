    Chapter 03: LED 깜빡이기 - 나의 첫 하드웨어 제어¶

    🎯 이 장의 학습 목표¶

    이 장을 마치면 다음을 할 수 있습니다:

    • [ ] 피코2의 내장 LED를 코드로 켜고 끌 수 있다
    • [ ] GPIO 핀의 개념과 디지털 출력을 이해한다
    • [ ] 무한 반복문으로 LED를 깜빡이게 할 수 있다

    예상 학습 시간: 약 50분

    📚 미리 알아야 할 것¶

    • Thonny에서 피코2에 코드를 입력하고 실행하는 방법 (Chapter 02)
    • print() 함수로 글자를 출력해본 경험

    📚 핵심 개념¶

    개념 1: GPIO 핀 — 피코의 "소통하는 문" 🚪¶

    피코2 보드를 자세히 보면 양쪽에 작은 금속 구멍들이 줄지어 있죠? 이것이 바로 GPIO 핀입니다.

    GPIO는 General Purpose Input/Output의 약자로, "범용 입출력"이라는 뜻이에요.

    🏠 비유로 이해하기: GPIO 핀은 집의 문과 같아요. 문을 통해 택배를 받을 수도 있고(입력), 편지를 내보낼 수도 있죠(출력). 피코2는 이 문들을 통해 바깥 세상의 부품들과 소통합니다.

    오늘은 이 문을 출력 모드로 사용해서, 피코2가 LED에게 "켜져!", "꺼져!" 신호를 보내볼 거예요.

    개념 2: 디지털 출력 — 켜거나(1) 끄거나(0)¶

    디지털 출력은 아주 단순합니다. 딱 두 가지 상태만 있어요:

    값 의미 LED 상태
    1 (HIGH) 전기가 흐른다 💡 켜짐
    0 (LOW) 전기가 안 흐른다 ⚫ 꺼짐

    🔦 비유로 이해하기: 방의 조명 스위치와 똑같아요! 올리면(1) 불이 켜지고, 내리면(0) 불이 꺼지죠. 우리는 코드로 이 스위치를 조작하는 겁니다.

    flowchart LR A["🖥️ 코드 명령<br>value(1)"] --> B["📍 GPIO 핀<br>(소통하는 문)"] --> C["💡 LED 켜짐!"] style A fill:#e3f2fd,stroke:#1976d2 style B fill:#fff3e0,stroke:#f57c00 style C fill:#e8f5e9,stroke:#388e3c

    🔨 따라하기¶

    🎉 좋은 소식! 피코2에는 LED가 하나 내장되어 있어서, 별도 부품 없이 바로 실습할 수 있어요!

    Step 1: LED 켜기¶

    Thonny를 열고 피코2를 연결한 뒤, 아래 코드를 입력하세요.

    from machine import Pin  # Pin 기능 가져오기

led = Pin("LED", Pin.OUT)  # 내장 LED를 출력 모드로 설정
led.value(1)  # LED 켜기!

    실행 결과: 피코2 보드의 초록색 LED가 켜집니다! 🎉

    💡 코드 해석: - Pin("LED", Pin.OUT) → "LED"라는 이름의 핀을 출력(OUT) 모드로 설정 - led.value(1) → 그 핀에 1(HIGH) 신호를 보내서 LED를 켬

    Step 2: LED 끄기¶

    이번엔 value(0)으로 바꿔볼까요?

    from machine import Pin

led = Pin("LED", Pin.OUT)
led.value(0)  # LED 끄기!

    실행 결과: LED가 꺼집니다.

    ✅ 체크포인트: value(1)로 켜지고, value(0)으로 꺼지는 것을 확인했나요? 축하해요! 코드로 하드웨어를 제어한 첫 경험입니다!

    Step 3: LED 깜빡이기 — 반복의 마법 ✨¶

    LED를 계속 깜빡이게 하려면 "켜고 → 기다리고 → 끄고 → 기다리고"를 반복해야 해요. 이때 while True:라는 무한 반복문을 사용합니다.

    from machine import Pin
import time  # 시간 관련 기능 가져오기

led = Pin("LED", Pin.OUT)

while True:        # 무한 반복 시작!
    led.value(1)   # LED 켜기
    time.sleep(0.5) # 0.5초 기다리기
    led.value(0)   # LED 끄기
    time.sleep(0.5) # 0.5초 기다리기

    실행 결과: LED가 0.5초 간격으로 깜빡깜빡 반복합니다! ✨

    ⏹️ 멈추는 방법: Thonny에서 빨간 Stop 버튼을 누르면 프로그램이 멈춰요.

    flowchart TD A["💡 LED 켜기<br>value(1)"] --> B["⏱️ 0.5초 대기"] B --> C["⚫ LED 끄기<br>value(0)"] C --> D["⏱️ 0.5초 대기"] D --> A style A fill:#e8f5e9,stroke:#388e3c style C fill:#fce4ec,stroke:#c62828

    Step 4: 속도 바꿔보기 🎮¶

    time.sleep() 안의 숫자를 바꾸면 깜빡이는 속도가 달라져요. 직접 바꿔보세요!

    sleep 값 효과
    0.1 아주 빠르게 깜빡
    0.5 적당한 속도
    2.0 느긋하게 깜빡

    💡 잠깐! 여기까지 이해가 잘 되셨나요? 숫자를 이것저것 바꿔보는 것이 가장 좋은 학습법이에요. 마음껏 실험해보세요!

    📝 전체 코드¶

    from machine import Pin
import time

led = Pin("LED", Pin.OUT)

while True:
    led.value(1)
    time.sleep(0.5)
    led.value(0)
    time.sleep(0.5)

    ⚠️ 주의할 점¶

    1. time.sleep()을 빼먹으면? LED가 너무 빠르게 켜졌다 꺼져서 사람 눈에는 계속 켜져 있는 것처럼 보여요. 반드시 대기 시간을 넣어주세요!

    2. while True: 아래 코드는 들여쓰기 필수! 

    # ❌ 잘못된 예 (들여쓰기 없음)
while True:
led.value(1)    # 에러 발생!

# ✅ 올바른 예 (스페이스 4칸)
while True:
    led.value(1)  # 정상 동작!

    ✅ 점검하기¶

    1. GPIO 핀을 한마디로 설명하면?

    정답 확인 피코2가 외부 부품과 **소통하는 통로(문)**입니다. 입력을 받거나 출력을 내보낼 수 있어요.

    2. led.value(1)과 led.value(0)의 차이는?

    정답 확인 `value(1)`은 LED를 **켜는** 것(전기 흐름), `value(0)`은 LED를 **끄는** 것(전기 차단)입니다.

    3. LED를 1초 간격으로 깜빡이게 하려면 코드를 어떻게 바꿀까요?

    정답 확인 `time.sleep(0.5)`를 `time.sleep(1)`로 바꾸면 됩니다!
