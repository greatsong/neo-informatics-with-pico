    Chapter 05: 버튼으로 LED 제어하기¶

    🎯 이 장의 학습 목표¶

    이 장을 마치면 다음을 할 수 있습니다:

    • [ ] 버튼 입력값을 읽어 조건에 따라 LED를 제어할 수 있다
    • [ ] if-else 조건문의 기본 구조를 이해하고 활용할 수 있다

    ⏱️ 예상 학습 시간: 약 50분

    📚 미리 알아야 할 것¶

    이전 장에서 우리는 LED를 켜고 끄는 방법과 반복문(while)을 배웠어요. 오늘은 여기에 버튼이라는 새로운 친구를 추가합니다!

    # 지난 시간에 배운 것 - 기억나시죠?
from machine import Pin
led = Pin(25, Pin.OUT)
led.value(1)  # LED 켜기

    📚 핵심 개념¶

    개념 1: 디지털 입력 — 버튼 읽기¶

    "버튼은 마치 초인종과 같아요" 🔔

    초인종을 누르면 벨이 울리고, 손을 떼면 멈추죠? 피코에 연결된 버튼도 마찬가지예요. 버튼을 누르면 신호가 전달되고, 떼면 신호가 사라집니다.

    정확한 정의: 디지털 입력이란 외부 장치(버튼 등)의 상태를 0 또는 1로 읽어오는 것입니다.

    button = Pin(15, Pin.IN, Pin.PULL_DOWN)
    코드 부분 의미
    Pin(15, ...) GP15번 핀 사용
    Pin.IN 입력 모드 (외부 신호를 읽겠다)
    Pin.PULL_DOWN 버튼을 안 누르면 0, 누르면 1

    💡 Pull-down이 뭐예요? 버튼을 누르지 않았을 때 값을 확실히 0으로 잡아주는 설정이에요. 이걸 안 하면 값이 불안정하게 흔들릴 수 있어요. 지금은 "안 눌렀을 때 0이 되게 하는 설정"으로 기억하면 충분합니다!

    예시로 확인: 

    print(button.value())  # 안 누름 → 0 출력
print(button.value())  # 누르는 중 → 1 출력

    개념 2: if-else 조건문 — 만약 ~라면¶

    "조건문은 마치 갈림길 표지판과 같아요" 🪧

    비가 오면 → 우산을 쓴다
비가 안 오면 → 그냥 나간다

    프로그래밍에서도 똑같아요!

    if 조건:
    # 조건이 참일 때 실행
else:
    # 조건이 거짓일 때 실행

    우리 프로젝트에 적용하면:

    if button.value() == 1:    # 버튼이 눌렸다면
    led.value(1)            # LED 켜기
else:                       # 그렇지 않다면
    led.value(0)            # LED 끄기
    flowchart TD A["버튼 상태 확인"] --> B{"button.value() == 1?"} B -- "Yes (눌림)" --> C["💡 LED 켜기"] B -- "No (안 눌림)" --> D["LED 끄기"] C --> A D --> A style B fill:#fff3e0,stroke:#f57c00 style C fill:#e8f5e9,stroke:#388e3c style D fill:#fce4ec,stroke:#c62828

    ⚠️ 주의! ==는 비교(같은지 확인)이고, =는 대입(값 넣기)이에요. 헷갈리기 쉬우니 꼭 구분하세요!

    🔨 따라하기¶

    Step 1: 회로 연결하기¶

    브레드보드에 버튼을 연결합니다.

    버튼 다리 연결 위치
    한쪽 다리 GP15 핀
    반대쪽 다리 3V3 핀

    💡 버튼은 보통 다리가 4개인데, 같은 쪽 2개씩 짝이에요. 브레드보드 가운데 홈을 걸쳐서 꽂으면 됩니다.

    ✅ 체크포인트: 버튼이 브레드보드에 단단히 꽂혀 있나요? 흔들리면 접촉 불량이 날 수 있어요!

    Step 2: 버튼 값 확인하기¶

    먼저 버튼이 잘 연결되었는지 확인해 봐요.

    코드: 

    from machine import Pin
import time

button = Pin(15, Pin.IN, Pin.PULL_DOWN)

while True:
    print(button.value())
    time.sleep(0.5)

    실행 결과: 

    0        ← 버튼 안 누름
0
1        ← 버튼 누르는 중!
1
0        ← 버튼 뗌

    ✅ 체크포인트: Shell 창에 0과 1이 번갈아 나오면 성공이에요! 버튼을 눌렀을 때 1이 나오는지 확인하세요.

    Step 3: 버튼으로 LED 제어하기¶

    이제 조건문을 추가해서 버튼과 LED를 연결해 봅시다!

    코드: 

    from machine import Pin
import time

led = Pin(25, Pin.OUT)
button = Pin(15, Pin.IN, Pin.PULL_DOWN)

while True:
    if button.value() == 1:   # 버튼이 눌렸다면
        led.value(1)           # LED 켜기
    else:                      # 아니라면
        led.value(0)           # LED 끄기
    time.sleep(0.1)

    실행 결과: 

    버튼 누름 → 💡 LED 켜짐
버튼 뗌   → LED 꺼짐

    💡 잠깐! 여기까지 잘 되셨나요? 버튼을 누르는 동안 LED가 켜지고, 떼면 꺼지면 완벽해요! 어렵지 않죠? 😊

    Step 4: 상태 메시지 추가하기¶

    어떤 상태인지 화면에도 표시해 볼까요?

    코드: 

    from machine import Pin
import time

led = Pin(25, Pin.OUT)
button = Pin(15, Pin.IN, Pin.PULL_DOWN)

while True:
    if button.value() == 1:
        led.value(1)
        print("버튼 눌림! LED ON 💡")
    else:
        led.value(0)
        print("LED OFF")
    time.sleep(0.3)

    실행 결과: 

    LED OFF
LED OFF
버튼 눌림! LED ON 💡
버튼 눌림! LED ON 💡
LED OFF

    📝 전체 코드¶

    from machine import Pin
import time

# 핀 설정
led = Pin(25, Pin.OUT)                    # LED: 출력
button = Pin(15, Pin.IN, Pin.PULL_DOWN)   # 버튼: 입력

# 메인 루프
while True:
    if button.value() == 1:   # 버튼 눌림?
        led.value(1)           # → LED 켜기
        print("LED ON 💡")
    else:                      # 버튼 안 눌림?
        led.value(0)           # → LED 끄기
        print("LED OFF")
    time.sleep(0.1)

    ⚠️ 주의할 점¶

    1. =와 ==를 구분하세요! 

    button.value() = 1    # ❌ 이건 대입 (에러 남!)
button.value() == 1   # ✅ 이건 비교 (맞는 표현)

    2. if 문 뒤에 콜론(:)과 들여쓰기를 잊지 마세요! 

    # ❌ 틀린 예
if button.value() == 1
    led.value(1)

# ✅ 맞는 예
if button.value() == 1:    # 콜론 필수!
    led.value(1)            # 들여쓰기 필수!

    ✅ 점검하기¶

    1. 다음 코드에서 버튼을 누르면 어떤 일이 일어날까요? 

    if button.value() == 1:
    led.value(0)
else:
    led.value(1)

    정답 확인 버튼을 누르면 LED가 **꺼지고**, 버튼을 떼면 LED가 **켜집니다**. 원래와 반대로 동작해요! `led.value(0)`과 `led.value(1)`의 위치가 바뀌었기 때문이에요.

    2. Pin.IN과 Pin.OUT의 차이는 무엇인가요?

    정답 확인 - `Pin.IN`: **입력** 모드 — 외부 신호를 읽어옴 (예: 버튼) - `Pin.OUT`: **출력** 모드 — 외부 장치에 신호를 보냄 (예: LED)

    3. if-else 문에서 반드시 필요한 두 가지 문법 요소는?

    정답 확인 1. 조건 뒤의 **콜론(`:`)** 2. 실행할 코드의 **들여쓰기(스페이스 4칸)**

    📌 이 장의 핵심 정리¶

    • ✅ 디지털 입력: Pin(핀번호, Pin.IN, Pin.PULL_DOWN)으로 버튼 값을 읽을 수 있다
    • ✅ if-else 조건문: if 조건: → 참일 때 실행, else: → 거짓일 때 실행
    • ✅ 입력 + 출력: 버튼(입력)의 상태에 따라 LED(출력)를 제어할 수 있다
