    Chapter 33: WiFi 연결과 데이터 전송 기초¶

    🎯 이 장의 학습 목표¶

    • [ ] 피코2 WH를 WiFi에 연결하는 코드를 작성할 수 있다
    • [ ] HTTP 요청을 보내고 응답을 확인할 수 있다
    • 예상 학습 시간: 약 50분

    📚 미리 알아야 할 것¶

    이전 장까지 피코2 WH에서 센서 데이터를 읽는 방법을 배웠어요. 하지만 데이터가 피코 안에만 갇혀 있으면 활용이 어렵죠? 이번 장에서는 WiFi로 인터넷에 연결해서 데이터를 바깥 세상으로 보내는 첫걸음을 내딛습니다! 🌐

    📚 핵심 개념¶

    개념 1: WiFi 연결 — 전화 거는 것과 같아요 ☎️¶

    WiFi에 연결하는 과정은 전화를 거는 것과 아주 비슷해요.

    1. SSID = 전화번호부에서 상대방 이름 찾기

    2. WiFi 네트워크의 이름이에요. 집에서 "우리집WiFi"처럼 보이는 그 이름!

    3. 비밀번호 = 전화가 연결되기 위한 인증

    4. WiFi에 접속하려면 비밀번호를 입력해야 해요.

    5. IP 주소 = 연결 후 부여받는 내 전화번호

    6. WiFi에 성공적으로 연결되면 피코가 고유한 주소(IP)를 받아요. 예: 192.168.0.15

    개념 2: HTTP 요청 — 편지 보내고 답장 받기 ✉️¶

    인터넷에 연결되었으면 이제 데이터를 주고받을 수 있어요. 가장 기본적인 방법이 HTTP 요청이에요.

    비유하면 편지와 같아요: - 요청(Request): "이 주소로 편지를 보내요" → 웹 서버에 데이터를 달라고 부탁 - 응답(Response): "답장이 왔어요!" → 서버가 데이터를 돌려줌

    우리가 웹 브라우저에서 주소를 입력하고 엔터를 누르면? 그게 바로 HTTP 요청이에요! 피코에서도 똑같은 일을 코드로 할 수 있습니다.

    💡 잠깐! SSID, IP 주소, HTTP… 용어가 많죠? 걱정 마세요. 코드를 직접 실행하면서 자연스럽게 익힐 거예요! 천천히 따라와 주세요. 😊

    🔨 따라하기¶

    Step 1: WiFi 연결 코드 작성하기¶

    피코2 WH에는 WiFi 칩이 내장되어 있어요. network 모듈로 연결합니다.

    코드: 

    import network
import time

# 1. WiFi 모듈 켜기
wlan = network.WLAN(network.STA_IF)
wlan.active(True)

# 2. WiFi에 연결하기 (본인의 SSID와 비밀번호로 바꾸세요!)
wlan.connect("여기에_WiFi이름", "여기에_비밀번호")

# 3. 연결될 때까지 기다리기
print("WiFi 연결 중...")
while not wlan.isconnected():
    time.sleep(1)
    print(".", end="")

# 4. 연결 완료!
print("\nWiFi 연결 성공!")
print("내 IP 주소:", wlan.ifconfig()[0])

    실행 결과: 

    WiFi 연결 중...
...
WiFi 연결 성공!
내 IP 주소: 192.168.0.15

    ✅ 체크포인트: "WiFi 연결 성공!"과 IP 주소가 출력되면 성공이에요!

    Step 2: 연결 상태를 안정적으로 확인하기¶

    가끔 연결이 오래 걸리거나 실패할 수 있어요. 타임아웃을 추가해서 안전하게 만들어 봅시다.

    코드: 

    import network
import time

def connect_wifi(ssid, password):
    wlan = network.WLAN(network.STA_IF)
    wlan.active(True)
    wlan.connect(ssid, password)

    # 최대 10초 기다리기
    timeout = 10
    while not wlan.isconnected() and timeout > 0:
        time.sleep(1)
        timeout -= 1
        print(f"대기 중... {timeout}초 남음")

    if wlan.isconnected():
        print("✅ 연결 성공! IP:", wlan.ifconfig()[0])
        return True
    else:
        print("❌ 연결 실패. SSID와 비밀번호를 확인하세요.")
        return False

# 사용하기
connect_wifi("여기에_WiFi이름", "여기에_비밀번호")

    실행 결과: 

    대기 중... 9초 남음
대기 중... 8초 남음
✅ 연결 성공! IP: 192.168.0.15

    Step 3: HTTP 요청으로 데이터 가져오기¶

    WiFi가 연결되었으니, 인터넷에서 데이터를 가져와 봐요! urequests 모듈을 사용합니다.

    코드: 

    import urequests

# 공개 테스트 API에 요청 보내기
response = urequests.get("http://httpbin.org/get")

# 응답 확인
print("상태 코드:", response.status_code)
print("응답 내용:", response.text[:200])  # 앞 200자만

# 메모리 해제 (중요!)
response.close()

    실행 결과: 

    상태 코드: 200
응답 내용: {
  "args": {},
  "headers": {
    "Host": "httpbin.org"...

    💡 상태 코드 200은 "요청 성공!"이라는 뜻이에요. 마치 편지를 보냈더니 "잘 받았어요!"라는 답장이 온 것과 같아요.

    Step 4: 센서 데이터를 URL에 실어 보내기¶

    실제로 센서 값을 인터넷으로 전송하는 느낌을 체험해 봅시다.

    코드: 

    import urequests

# 가상의 온도 데이터
temperature = 26.5

# 데이터를 URL 파라미터로 보내기
url = f"http://httpbin.org/get?temp={temperature}"
response = urequests.get(url)

print("보낸 데이터 확인:")
print(response.json()["args"])  # 서버가 받은 데이터 확인

response.close()

    실행 결과: 

    보낸 데이터 확인:
{'temp': '26.5'}

    서버가 우리가 보낸 온도 데이터 26.5를 잘 받았다는 걸 확인할 수 있어요! 🎉

    📝 전체 코드¶

    WiFi 연결부터 데이터 전송까지 합친 완성 코드입니다:

    import network
import time
import urequests

# --- WiFi 연결 ---
def connect_wifi(ssid, password):
    wlan = network.WLAN(network.STA_IF)
    wlan.active(True)
    wlan.connect(ssid, password)

    timeout = 10
    while not wlan.isconnected() and timeout > 0:
        time.sleep(1)
        timeout -= 1

    if wlan.isconnected():
        print("✅ WiFi 연결 성공! IP:", wlan.ifconfig()[0])
        return True
    else:
        print("❌ WiFi 연결 실패")
        return False

# --- 메인 실행 ---
if connect_wifi("여기에_WiFi이름", "여기에_비밀번호"):
    # 센서 데이터 (예시)
    temperature = 26.5

    # HTTP 요청으로 데이터 전송
    url = f"http://httpbin.org/get?temp={temperature}"
    response = urequests.get(url)

    print("상태 코드:", response.status_code)
    print("서버가 받은 데이터:", response.json()["args"])

    response.close()
    print("🎉 데이터 전송 완료!")

    ⚠️ 주의할 점¶

    1. WiFi 이름과 비밀번호를 정확히 입력하세요! - SSID는 대소문자를 구분해요. "MyWiFi"와 "mywifi"는 다릅니다 - 비밀번호에 특수문자가 있다면 그대로 정확히 입력하세요 - 5GHz WiFi는 피코2 WH에서 지원하지 않을 수 있어요. 2.4GHz를 사용하세요

    2. response.close()를 반드시 호출하세요! - 피코는 메모리가 작아요. 응답을 닫지 않으면 메모리가 부족해져서 다음 요청이 실패할 수 있어요

    ✅ 점검하기¶

    1. SSID는 무엇을 의미하나요?

    정답 확인 WiFi 네트워크의 이름이에요. 집이나 카페에서 WiFi 목록에 나타나는 그 이름입니다.

    2. HTTP 상태 코드 200은 무슨 뜻인가요?

    정답 확인 "요청이 성공했습니다"라는 뜻이에요. 서버가 우리의 요청을 잘 처리했다는 의미입니다.

    3. WiFi 연결 후 피코가 받는 것은 무엇인가요?

    정답 확인 IP 주소를 받아요. 이것은 네트워크에서 피코를 식별하는 고유한 주소입니다. (예: 192.168.0.15)
