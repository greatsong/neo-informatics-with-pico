    AI 코드 검증과 개선하기¶

    🎯 이 장의 학습 목표¶

    • [ ] AI가 생성한 코드에서 오류를 발견하고 수정할 수 있다
    • [ ] AI에게 개선 요청을 하여 더 나은 코드를 얻을 수 있다

    예상 학습 시간: 약 40분

    📚 미리 알아야 할 것¶

    이전 장들에서 AI에게 프롬프트를 작성하고, 코드를 받아 실행해 본 경험이 있어야 해요. AI가 만들어준 코드를 Streamlit으로 실행해 본 적이 있다면 준비 완료입니다! 😊

    📚 핵심 개념¶

    개념 1: AI 코드는 "초안"이다¶

    AI가 만들어주는 코드는 마치 친구가 빠르게 적어준 시험 답안지와 같아요. 대부분 맞지만, 가끔 실수가 있을 수 있고, 내 상황에 딱 맞지 않을 수도 있어요.

    AI 코드에서 자주 발생하는 문제 3가지:

    • 🔴 실행 오류: 라이브러리 버전 차이, 오타, 없는 함수 호출 등으로 아예 실행이 안 되는 경우
    • 🟡 논리 오류: 실행은 되지만 결과가 의도와 다른 경우 (예: 합계를 구해야 하는데 평균을 계산)
    • 🟠 품질 문제: 동작은 하지만 코드가 비효율적이거나, 변수명이 이해하기 어려운 경우

    💡 핵심 포인트: AI는 "내 데이터"와 "내 환경"을 정확히 알지 못해요. 그래서 검증은 항상 사람의 몫입니다!

    개념 2: 반복 대화로 개선하기¶

    AI와의 코드 작업은 한 번에 끝나는 게 아니라 대화를 통해 점점 나아지는 과정이에요. 마치 디자이너에게 로고를 의뢰할 때, 첫 시안을 보고 "여기는 이렇게 바꿔주세요"라고 피드백하는 것과 같아요.

    flowchart LR A["🗣️ 요청"] --> B["🤖 코드 생성"] B --> C["👀 검증"] C --> D{"문제 발견?"} D -- 예 --> E["🗣️ 개선 요청"] E --> B D -- 아니오 --> F["✅ 완성!"]

    이 순환을 2~3번 반복하면 대부분 원하는 결과를 얻을 수 있어요.

    🔨 따라하기¶

    실제로 AI가 생성한 코드에 문제가 있는 상황을 경험하고, 이를 개선하는 과정을 함께 해봐요.

    Step 1: AI에게 코드 요청하기¶

    AI에게 다음과 같이 요청했다고 가정해 볼게요:

    프롬프트: "Streamlit으로 월별 매출 데이터를 막대 차트로 보여주는 코드를 만들어줘"

    AI가 이렇게 응답했어요:

    import streamlit as st
import pandas as pd

st.title("월별 매출 현황")

data = {
    "월": ["1월", "2월", "3월", "4월", "5월", "6월"],
    "매출": [1200, 1500, 1800, 1400, 2000, 1700]
}

df = pd.DataFrame(data)
st.bar_chart(df, x="월", y="매출")

    Step 2: 코드를 실행하고 문제 발견하기¶

    이 코드를 실행해 보세요. 실행은 되지만, 몇 가지 아쉬운 점이 보일 거예요:

    • 차트에 단위(만원) 표시가 없어요
    • 데이터가 고정값이라 다른 데이터로 바꾸기 어려워요
    • 전체 합계나 평균 같은 요약 정보가 없어요

    ✅ 체크포인트: 코드가 실행되었다면, 화면에 막대 차트가 보여야 해요. 여기서 "동작은 하지만 더 나아질 수 있다"는 점을 발견하는 것이 핵심이에요!

    Step 3: AI에게 구체적으로 개선 요청하기¶

    이제 발견한 문제를 구체적으로 AI에게 전달해요. 아래 프롬프트를 참고하세요:

    개선 프롬프트 예시:

    위 코드를 다음과 같이 개선해줘:

1. 차트 제목에 "(단위: 만원)"을 추가해줘
2. 데이터를 CSV 파일에서 읽어오도록 변경해줘
3. 전체 매출 합계와 월평균 매출을 차트 위에 표시해줘
4. 가장 매출이 높은 달을 강조 표시해줘

    💡 잠깐! 개선 요청의 핵심은 구체적으로 말하는 거예요. "더 좋게 해줘"보다 "합계를 추가해줘"처럼 무엇을 어떻게 바꿀지 명확하게 말해야 해요.

    Step 4: 개선된 코드 확인하기¶

    AI가 개선해준 코드는 이런 모습일 거예요:

    import streamlit as st
import pandas as pd

st.title("월별 매출 현황 (단위: 만원)")

# CSV 파일 업로드 또는 기본 데이터 사용
uploaded_file = st.file_uploader("CSV 파일을 업로드하세요", type="csv")

if uploaded_file:
    df = pd.read_csv(uploaded_file)
else:
    data = {
        "월": ["1월", "2월", "3월", "4월", "5월", "6월"],
        "매출": [1200, 1500, 1800, 1400, 2000, 1700]
    }
    df = pd.DataFrame(data)

# 요약 정보 표시
total = df["매출"].sum()
average = df["매출"].mean()
best_month = df.loc[df["매출"].idxmax(), "월"]

col1, col2, col3 = st.columns(3)
col1.metric("총 매출", f"{total:,}만원")
col2.metric("월평균", f"{average:,.0f}만원")
col3.metric("최고 매출 달", best_month)

# 차트 표시
st.bar_chart(df, x="월", y="매출")

    실행 결과:

    월별 매출 현황 (단위: 만원)
[CSV 파일 업로드 버튼]

총 매출: 9,600만원  |  월평균: 1,600만원  |  최고 매출 달: 5월

[막대 차트]

    Step 5: 오류가 있다면 에러 메시지로 다시 요청하기¶

    만약 실행 중 에러가 발생하면, 에러 메시지를 그대로 복사해서 AI에게 보내세요:

    아래 에러가 발생했어. 원인과 해결 방법을 알려줘:

KeyError: '매출'

    AI는 에러 메시지를 보고 정확한 원인을 파악할 수 있어요. 이것이 가장 효율적인 디버깅 방법입니다!

    📝 전체 코드¶

    import streamlit as st
import pandas as pd

st.title("월별 매출 현황 (단위: 만원)")

# 데이터 준비 (CSV 업로드 또는 기본 데이터)
uploaded_file = st.file_uploader("CSV 파일을 업로드하세요", type="csv")

if uploaded_file:
    df = pd.read_csv(uploaded_file)
else:
    data = {
        "월": ["1월", "2월", "3월", "4월", "5월", "6월"],
        "매출": [1200, 1500, 1800, 1400, 2000, 1700]
    }
    df = pd.DataFrame(data)

# 요약 정보
total = df["매출"].sum()
average = df["매출"].mean()
best_month = df.loc[df["매출"].idxmax(), "월"]

col1, col2, col3 = st.columns(3)
col1.metric("총 매출", f"{total:,}만원")
col2.metric("월평균", f"{average:,.0f}만원")
col3.metric("최고 매출 달", best_month)

# 차트
st.bar_chart(df, x="월", y="매출")

    ⚠️ 주의할 점¶

    • AI 코드를 무조건 신뢰하지 마세요: 반드시 실행해보고, 결과가 의도한 것과 맞는지 확인하세요. 특히 숫자 계산 결과는 직접 검산해보는 습관이 중요해요.

    • 개선 요청은 한 번에 하나씩: "이것도 바꾸고, 저것도 바꾸고, 전부 다 바꿔줘"라고 하면 AI도 혼란스러워해요. 2~4가지 이내로 요청하고, 확인 후 다시 요청하는 것이 좋아요.

    ✅ 점검하기¶

    1. AI가 생성한 코드에서 확인해야 할 3가지 유형의 문제는 무엇인가요?

    정답 확인 - **실행 오류**: 코드가 아예 실행되지 않는 문제 - **논리 오류**: 실행은 되지만 결과가 의도와 다른 문제 - **품질 문제**: 동작하지만 비효율적이거나 읽기 어려운 문제

    2. AI에게 코드 개선을 요청할 때 가장 중요한 원칙은?

    정답 확인 **구체적으로 요청하는 것**입니다. "더 좋게 해줘"가 아니라 "합계를 표시해줘", "단위를 추가해줘"처럼 무엇을 어떻게 바꿀지 명확하게 말해야 합니다.

    3. 코드 실행 중 에러가 발생했을 때, AI에게 도움을 요청하는 가장 효과적인 방법은?

    정답 확인 **에러 메시지를 그대로 복사**해서 AI에게 전달하는 것입니다. AI는 에러 메시지를 분석해서 정확한 원인과 해결 방법을 알려줄 수 있어요.
