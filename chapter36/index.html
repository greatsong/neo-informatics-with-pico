    Chapter 36: 실시간 데이터 업데이트¶

    🎯 이 장의 학습 목표¶

    • [ ] JavaScript가 웹페이지에서 어떤 역할을 하는지 설명할 수 있다
    • [ ] 페이지 새로고침 없이 데이터가 자동 업데이트되는 코드를 구현할 수 있다

    예상 학습 시간: 약 40분

    📚 미리 알아야 할 것¶

    이전 장에서 HTML과 CSS로 대시보드의 뼈대와 디자인을 만들었어요. 지금 우리 대시보드는 멋지게 보이지만, 데이터가 멈춰 있죠. 오늘은 이 대시보드에 생명을 불어넣는 시간입니다!

    📚 핵심 개념¶

    개념 1: JavaScript — 웹페이지의 두뇌 🧠¶

    HTML이 뼈대, CSS가 옷이라면, JavaScript는 두뇌예요.

    "JavaScript는 마치 건물의 전기 시스템과 같아요." 건물(HTML)이 있고, 인테리어(CSS)가 있어도, 전기가 없으면 엘리베이터도 안 움직이고, 자동문도 안 열리죠. JavaScript가 바로 그 전기 역할을 합니다.

    정확한 정의: JavaScript는 웹페이지를 동적으로 변화시키는 프로그래밍 언어입니다. 버튼 클릭에 반응하거나, 데이터를 자동으로 바꾸거나, 서버에서 새 정보를 가져오는 일을 합니다.

    예시로 확인해볼까요?

    // HTML에 있는 온도 텍스트를 바꾸는 코드
document.getElementById("temperature").textContent = "25°C";

    이 한 줄이면, 화면에 표시된 온도 값이 "25°C"로 바뀝니다. 페이지를 새로고침할 필요가 없어요!

    개념 2: setInterval — 자동 반복 타이머 ⏰¶

    "setInterval은 마치 알람시계와 같아요." 5초마다 울리도록 설정하면, 우리가 따로 신경 쓰지 않아도 자동으로 5초마다 울리죠.

    정확한 정의: setInterval은 정해진 시간 간격마다 특정 코드를 반복 실행하는 JavaScript 함수입니다.

    // 5초(5000밀리초)마다 데이터를 업데이트
setInterval(데이터업데이트함수, 5000);

    💡 잠깐! 1초 = 1000밀리초입니다. 그래서 5초는 5000이에요. 처음엔 헷갈리지만 금방 익숙해질 거예요!

    🔨 따라하기¶

    이제 실제로 5초마다 센서 데이터가 자동 갱신되는 대시보드를 만들어 봅시다!

    Step 1: HTML 뼈대 만들기¶

    먼저, 온도와 습도를 표시할 간단한 대시보드를 준비합니다.

    코드: 

    <!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>실시간 센서 대시보드</title>
    <style>
        body { font-family: sans-serif; text-align: center; padding: 40px; background: #f0f4f8; }
        .card { display: inline-block; background: white; border-radius: 12px; padding: 30px 40px; margin: 10px; box-shadow: 0 2px 8px rgba(0,0,0,0.1); }
        .value { font-size: 48px; font-weight: bold; color: #2196F3; }
        .label { font-size: 18px; color: #666; margin-top: 8px; }
        #status { margin-top: 20px; color: #888; }
    </style>
</head>
<body>
    <h1>🌡️ 실시간 센서 대시보드</h1>
    <div class="card">
        <div class="value" id="temperature">--</div>
        <div class="label">온도 (°C)</div>
    </div>
    <div class="card">
        <div class="value" id="humidity">--</div>
        <div class="label">습도 (%)</div>
    </div>
    <p id="status">데이터 로딩 중...</p>

    <script>
        <!-- Step 2에서 여기에 JavaScript를 추가합니다 -->
    </script>
</body>
</html>

    실행 결과: 온도와 습도가 "--"로 표시된 깔끔한 카드 2개가 나타납니다.

    Step 2: 센서 데이터 생성 함수 만들기¶

    실제 센서 대신, 랜덤 값으로 센서 데이터를 흉내 내봅시다. <script> 태그 안에 다음 코드를 넣으세요.

    코드: 

    // 센서 데이터를 가져오는 함수 (랜덤으로 시뮬레이션)
function getSensorData() {
    return {
        temperature: (20 + Math.random() * 10).toFixed(1),  // 20~30도
        humidity: (40 + Math.random() * 30).toFixed(1)       // 40~70%
    };
}

    💡 Math.random()은 0~1 사이 랜덤 숫자를 만들어요. toFixed(1)은 소수점 한 자리까지만 표시합니다. 나중에 실제 센서 API를 연결할 때 이 함수만 바꾸면 돼요!

    Step 3: 화면 업데이트 함수 만들기¶

    가져온 데이터를 화면에 반영하는 함수를 추가합니다.

    코드: 

    // 화면을 업데이트하는 함수
function updateDashboard() {
    var data = getSensorData();

    // HTML 요소의 텍스트를 새 값으로 변경
    document.getElementById("temperature").textContent = data.temperature;
    document.getElementById("humidity").textContent = data.humidity;

    // 마지막 업데이트 시간 표시
    var now = new Date().toLocaleTimeString();
    document.getElementById("status").textContent = "마지막 업데이트: " + now;
}

    핵심 포인트: document.getElementById("temperature")는 HTML에서 id="temperature"인 요소를 찾아오고, .textContent로 그 안의 글자를 바꿉니다.

    Step 4: 자동 반복 설정하기¶

    이제 5초마다 자동 실행되도록 타이머를 걸어봅시다.

    코드: 

    // 페이지가 열리자마자 1번 실행
updateDashboard();

// 그 후 5초마다 반복 실행
setInterval(updateDashboard, 5000);

    실행 결과: 

    🌡️ 실시간 센서 대시보드

    24.7          53.2
  온도 (°C)     습도 (%)

마지막 업데이트: 오후 3:25:10

    5초마다 숫자가 바뀌고, 업데이트 시간도 갱신됩니다! 🎉

    Step 5: AI에게 기능 추가 요청하기¶

    이제 AI에게 추가 기능을 요청해 봅시다. 다음 프롬프트를 사용해 보세요.

    AI에게 이렇게 요청하세요:

    "아래 대시보드 코드에, 온도가 28도 이상이면 온도 숫자 색상을 빨간색으로, 22도 미만이면 파란색으로 바뀌는 기능을 추가해줘"

    AI가 돌려준 코드에서 핵심 부분은 이런 형태일 거예요:

    // updateDashboard 함수 안에 추가
var tempElement = document.getElementById("temperature");
if (data.temperature >= 28) {
    tempElement.style.color = "#F44336";  // 빨간색
} else if (data.temperature < 22) {
    tempElement.style.color = "#2196F3";  // 파란색
} else {
    tempElement.style.color = "#4CAF50";  // 초록색 (정상)
}

    ✅ 체크포인트: 5초마다 숫자가 바뀌면서, 28도 이상일 때 빨간색으로 변하나요? 성공이에요!

    <script>
        function getSensorData() {

                humidity: (40 + Math.random() * 30).toFixed(1)

        }

        function updateDashboard() {
            var data = getSensorData();

    </script>

</html>

    ⚠️ 주의할 점¶

    • id 오타 조심! HTML의 id="temperature"와 JavaScript의 getElementById("temperature")가 정확히 일치해야 합니다. 대소문자도 구분해요!
    • setInterval 시간 단위는 밀리초입니다. 5000은 5초, 1000은 1초예요. 5라고 쓰면 0.005초마다 실행되어 브라우저가 멈출 수 있어요!

    ✅ 점검하기¶

    1. JavaScript의 역할을 한 문장으로 설명해 보세요.

    정답 확인JavaScript는 웹페이지를 동적으로 변화시키는 프로그래밍 언어로, 페이지 새로고침 없이 화면의 내용을 바꾸거나 사용자와 상호작용할 수 있게 합니다.

    2. setInterval(myFunc, 3000)은 어떻게 동작하나요?

    정답 확인myFunc 함수를 3초(3000밀리초)마다 반복해서 실행합니다.

    3. document.getElementById("humidity").textContent = "65.3"은 무슨 일을 하나요?

    정답 확인HTML에서 id가 "humidity"인 요소를 찾아서, 그 안의 텍스트를 "65.3"으로 바꿉니다.
