    상태 기계 - 여러 모드를 가진 시스템¶

    🎯 이 장의 학습 목표¶

    이 장을 마치면 다음을 할 수 있습니다:

    • [ ] 상태 기계의 개념과 필요성을 설명할 수 있다
    • [ ] 버튼으로 모드를 전환하는 프로그램을 작성할 수 있다
    • [ ] 현재 상태에 따라 다르게 동작하는 시스템을 구현할 수 있다

    예상 학습 시간: 약 40분

    📚 미리 알아야 할 것¶

    • 조건문 (if/elif/else): 조건에 따라 다른 코드를 실행하는 방법
    • 반복문 (while): 코드를 반복 실행하는 방법
    • 함수: 코드를 묶어서 이름을 붙이는 방법

    📚 핵심 개념¶

    개념 1: 상태 기계란?¶

    "상태 기계는 마치 신호등과 같아요." 🚦

    신호등을 떠올려 보세요. 신호등에는 빨간불, 노란불, 초록불 세 가지 상태가 있습니다. 현재 어떤 불이 켜져 있느냐에 따라 차가 멈추거나, 주의하거나, 출발합니다. 그리고 일정 시간이 지나면 다음 상태로 전환되죠.

    상태 기계(State Machine): 시스템이 가질 수 있는 상태(모드)들과, 어떤 조건에서 다른 상태로 전환되는지를 정의한 구조

    상태 기계의 핵심 3요소:

    요소 설명 신호등 예시
    상태 시스템이 현재 어떤 모드인지 빨강, 노랑, 초록
    전이 상태가 바뀌는 것 빨강 → 초록
    이벤트 전이를 일으키는 조건 시간 경과

    개념 2: 상태 전이도¶

    상태 기계를 그림으로 표현한 것이 상태 전이도입니다. 동그라미는 상태, 화살표는 전이를 나타내요.

    stateDiagram-v2 [*] --> 측정모드 측정모드 --> 경보모드 : 버튼 누름 경보모드 --> 절전모드 : 버튼 누름 절전모드 --> 측정모드 : 버튼 누름

    이 그림만 보면 시스템의 동작을 한눈에 파악할 수 있어요. 버튼을 누를 때마다 측정 → 경보 → 절전 → 측정으로 순환합니다.

    💡 잠깐! 우리가 매일 쓰는 것들 중에도 상태 기계가 숨어 있어요. 선풍기의 풍속 버튼(약풍 → 중풍 → 강풍), 음악 앱의 반복 모드(반복 없음 → 전체 반복 → 한곡 반복)… 모두 상태 기계입니다!

    🔨 따라하기: 3모드 환경 모니터 만들기¶

    버튼을 누를 때마다 모드가 바뀌는 환경 모니터를 만들어 봅시다.

    Step 1: 상태 정의하기¶

    먼저 시스템이 가질 상태들을 정의합니다.

    # 상태를 숫자로 정의
MODE_MEASURE = 0   # 측정 모드
MODE_ALARM = 1     # 경보 모드
MODE_SLEEP = 2     # 절전 모드

# 현재 상태를 저장하는 변수
current_mode = MODE_MEASURE

    핵심: current_mode 변수 하나가 시스템의 현재 상태를 기억합니다.

    Step 2: 상태 전환 함수 만들기¶

    버튼을 누르면 다음 모드로 넘어가는 함수입니다.

    def next_mode(current):
    """버튼을 누르면 다음 모드로 전환"""
    if current == MODE_MEASURE:
        return MODE_ALARM
    elif current == MODE_ALARM:
        return MODE_SLEEP
    else:
        return MODE_MEASURE

    Step 3: 각 상태별 동작 정의하기¶

    현재 모드에 따라 다르게 동작하는 것이 핵심입니다.

    def do_action(mode):
    """현재 모드에 따른 동작 수행"""
    if mode == MODE_MEASURE:
        print("📊 [측정 모드] 온도: 24.5°C, 습도: 60%")
    elif mode == MODE_ALARM:
        print("🚨 [경보 모드] 온도 30°C 초과 시 경보 작동!")
    elif mode == MODE_SLEEP:
        print("💤 [절전 모드] 화면 꺼짐... 대기 중")

    Step 4: 메인 루프 완성하기¶

    모든 것을 합쳐 실행해 봅니다.

    def get_mode_name(mode):
    """모드 번호를 이름으로 변환"""
    names = {0: "측정 모드", 1: "경보 모드", 2: "절전 모드"}
    return names[mode]

current_mode = MODE_MEASURE

while True:
    print(f"\n현재: {get_mode_name(current_mode)}")
    do_action(current_mode)

    user_input = input("\n🔘 버튼 누름(Enter) / 종료(q): ")
    if user_input == 'q':
        print("시스템을 종료합니다.")
        break

    current_mode = next_mode(current_mode)
    print(f"➡️ {get_mode_name(current_mode)}(으)로 전환!")

    실행 결과: 

    현재: 측정 모드
📊 [측정 모드] 온도: 24.5°C, 습도: 60%

🔘 버튼 누름(Enter) / 종료(q): 
➡️ 경보 모드(으)로 전환!

현재: 경보 모드
🚨 [경보 모드] 온도 30°C 초과 시 경보 작동!

🔘 버튼 누름(Enter) / 종료(q): 
➡️ 절전 모드(으)로 전환!

    ✅ 체크포인트: Enter를 누를 때마다 모드가 순환하며 바뀌나요? 'q'를 누르면 종료되나요?

    📝 전체 코드¶

    # === 상태 기계: 3모드 환경 모니터 ===

# 1. 상태 정의
MODE_MEASURE = 0
MODE_ALARM = 1
MODE_SLEEP = 2

# 2. 상태 전환
def next_mode(current):
    if current == MODE_MEASURE:
        return MODE_ALARM
    elif current == MODE_ALARM:
        return MODE_SLEEP
    else:
        return MODE_MEASURE

# 3. 상태별 동작
def do_action(mode):
    if mode == MODE_MEASURE:
        print("📊 [측정 모드] 온도: 24.5°C, 습도: 60%")
    elif mode == MODE_ALARM:
        print("🚨 [경보 모드] 온도 30°C 초과 시 경보 작동!")
    elif mode == MODE_SLEEP:
        print("💤 [절전 모드] 화면 꺼짐... 대기 중")

# 4. 모드 이름
def get_mode_name(mode):
    names = {0: "측정 모드", 1: "경보 모드", 2: "절전 모드"}
    return names[mode]

# 5. 메인 루프
current_mode = MODE_MEASURE

while True:
    print(f"\n현재: {get_mode_name(current_mode)}")
    do_action(current_mode)

    user_input = input("\n🔘 버튼 누름(Enter) / 종료(q): ")
    if user_input == 'q':
        print("시스템을 종료합니다.")
        break

    current_mode = next_mode(current_mode)
    print(f"➡️ {get_mode_name(current_mode)}(으)로 전환!")

    ⚠️ 주의할 점¶

    1. 상태 변수를 빠뜨리지 마세요!

    상태 기계의 핵심은 "지금 어떤 상태인지 기억하는 변수"입니다. current_mode를 업데이트하지 않으면 모드가 바뀌지 않아요.

    # ❌ 잘못된 예: 전환 결과를 저장하지 않음
next_mode(current_mode)  # 반환값을 버림!

# ✅ 올바른 예: 반환값을 다시 저장
current_mode = next_mode(current_mode)

    2. 모든 상태를 빠짐없이 처리하세요!

    if/elif에서 하나의 상태를 빠뜨리면, 그 상태일 때 아무 동작도 하지 않는 버그가 생깁니다. else로 예외 상황을 잡아두면 안전해요.

    ✅ 점검하기¶

    1. 상태 기계의 3가지 핵심 요소는 무엇인가요?

    정답 확인 **상태**(시스템의 현재 모드), **전이**(상태가 바뀌는 것), **이벤트**(전이를 일으키는 조건)입니다.

    2. 아래 코드에서 current_mode가 MODE_SLEEP일 때, next_mode()는 무엇을 반환하나요?

    정답 확인 `MODE_MEASURE` (0)를 반환합니다. `else` 블록에 해당하므로 다시 측정 모드로 돌아갑니다.

    3. 선풍기 풍속 조절(약풍→중풍→강풍→끔)을 상태 기계로 만든다면, 상태는 몇 개인가요?

    정답 확인 **4개**입니다 — 약풍, 중풍, 강풍, 끔. 버튼을 누를 때마다 순환합니다.
