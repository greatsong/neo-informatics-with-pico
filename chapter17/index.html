    Chapter 17: 함수로 코드 정리하기¶

    🎯 이 장의 학습 목표¶

    이 장을 마치면 다음을 할 수 있습니다:

    • [ ] 함수의 개념과 필요성을 설명할 수 있다
    • [ ] 매개변수와 반환값을 사용하는 함수를 작성할 수 있다

    예상 학습 시간: 약 45분

    📚 미리 알아야 할 것¶

    이전 장까지 우리는 센서값을 읽고 if문과 반복문으로 조건을 판단하는 코드를 작성했습니다. 코드가 점점 길어지고 있죠? 이번 장에서 그 코드를 깔끔하게 정리하는 방법을 배웁니다!

    📚 핵심 개념¶

    개념 1: 함수 — 이름을 붙인 코드 묶음¶

    비유로 시작할게요. 🍳

    함수는 마치 요리 레시피와 같아요.

    • 레시피에 "김치찌개 만들기"라고 이름을 붙이면, 매번 재료와 순서를 처음부터 설명할 필요 없이 "김치찌개 만들어줘!" 한마디면 됩니다.
    • 함수도 마찬가지예요. 여러 줄의 코드에 이름을 붙여두면, 그 이름만 불러서 코드를 실행할 수 있어요.
    flowchart LR A["📝 코드 묶음에<br>이름 붙이기"] --> B["📢 이름을 불러서<br>실행하기"] B --> C["🔄 몇 번이든<br>재사용!"] style A fill:#e3f2fd,stroke:#1976d2 style B fill:#fff3e0,stroke:#f57c00 style C fill:#e8f5e9,stroke:#388e3c

    정확한 정의: 함수(function)란 특정 작업을 수행하는 코드 블록에 이름을 붙인 것입니다. 한 번 만들어두면 필요할 때마다 호출(call)하여 재사용할 수 있습니다.

    왜 필요할까요? 같은 코드를 여러 번 복사-붙여넣기하면 수정할 때 전부 찾아서 고쳐야 합니다. 함수로 만들면 한 곳만 수정하면 끝!

    개념 2: 매개변수와 반환값¶

    함수를 요리에 비유하면:

    요리 함수
    🥬 재료 (김치, 두부) 매개변수 (함수에 넣는 값)
    🍲 완성 요리 (김치찌개) 반환값 (함수가 돌려주는 결과)
    flowchart LR A["📥 매개변수<br>(재료)"] --> B["⚙️ 함수<br>(조리 과정)"] B --> C["📤 반환값<br>(완성 요리)"] style A fill:#e3f2fd,stroke:#1976d2 style B fill:#fff3e0,stroke:#f57c00 style C fill:#e8f5e9,stroke:#388e3c

    매개변수(parameter): 함수가 작업하는 데 필요한 입력값 반환값(return value): 함수가 작업을 마치고 돌려주는 결과값

    💡 잠깐! 여기까지 이해가 잘 되셨나요? "함수 = 이름 붙인 코드 묶음", "매개변수 = 재료", "반환값 = 결과물" — 이 세 가지만 기억하면 됩니다!

    🔨 따라하기¶

    Step 1: 가장 간단한 함수 만들기¶

    def라는 키워드로 함수를 정의(define)합니다.

    코드: 

    # 함수 정의하기
def say_hello():
    print("안녕하세요!")
    print("아두이노 학습에 오신 걸 환영합니다!")

# 함수 호출하기
say_hello()
say_hello()

    실행 결과: 

    안녕하세요!
아두이노 학습에 오신 걸 환영합니다!
안녕하세요!
아두이노 학습에 오신 걸 환영합니다!

    ✅ 체크포인트: 함수를 한 번 만들고 두 번 호출했더니 같은 내용이 두 번 출력되었어요!

    Step 2: 매개변수 사용하기¶

    같은 함수에 다른 재료를 넣어봅시다.

    코드: 

    # 매개변수 name을 받는 함수
def greet(name):
    print(name + "님, 반갑습니다!")

# 다른 이름으로 호출
greet("철수")
greet("영희")

    실행 결과: 

    철수님, 반갑습니다!
영희님, 반갑습니다!

    핵심은 name 자리에 호출할 때 넣은 값이 들어간다는 것입니다!

    Step 3: 반환값 사용하기¶

    함수가 결과를 돌려주게 만들어 봅시다.

    코드: 

    # 센서값을 섭씨로 변환하는 함수
def to_celsius(raw_value):
    voltage = raw_value * 5.0 / 1023
    celsius = voltage * 100
    return celsius  # 결과를 돌려줌!

# 함수 사용
temp = to_celsius(150)
print("온도: " + str(temp) + "°C")

    실행 결과: 

    온도: 73.31...°C

    return이 있으면 함수의 결과를 변수에 저장할 수 있어요!

    Step 4: 센서 코드를 함수로 정리하기 (Before → After)¶

    Before — 같은 변환 코드가 반복됨: 

    raw1 = 150
voltage1 = raw1 * 5.0 / 1023
temp1 = voltage1 * 100
print("센서1: " + str(temp1))

raw2 = 200
voltage2 = raw2 * 5.0 / 1023
temp2 = voltage2 * 100
print("센서2: " + str(temp2))

    After — 함수로 깔끔하게: 

    def to_celsius(raw_value):
    voltage = raw_value * 5.0 / 1023
    celsius = voltage * 100
    return celsius

print("센서1: " + str(to_celsius(150)))
print("센서2: " + str(to_celsius(200)))

    💡 변환 공식에 오류가 있으면 함수 한 곳만 수정하면 전부 해결됩니다!

    📝 전체 코드¶

    # 온도 변환 함수
def to_celsius(raw_value):
    voltage = raw_value * 5.0 / 1023
    celsius = voltage * 100
    return celsius

# 상태 메시지 함수
def check_temp(celsius):
    if celsius > 30:
        return "🔥 더워요!"
    else:
        return "😊 쾌적해요!"

# 사용하기
sensor_values = [150, 200, 350]

for val in sensor_values:
    temp = to_celsius(val)
    status = check_temp(temp)
    print("온도: " + str(round(temp, 1)) + "°C → " + status)

    실행 결과: 

    온도: 73.3°C → 🔥 더워요!
온도: 97.8°C → 🔥 더워요!
온도: 171.1°C → 🔥 더워요!

    ⚠️ 주의할 점¶

    1. 함수를 정의하기 전에 호출하면 안 돼요! 

    # ❌ 잘못된 순서
say_hello()        # 아직 정의 안 됨 → 에러!

def say_hello():
    print("안녕!")

    # ✅ 올바른 순서
def say_hello():
    print("안녕!")

say_hello()        # 정의 후 호출 → 정상!

    2. return과 print는 달라요! - print → 화면에 보여주기만 함 (값을 저장할 수 없음) - return → 값을 돌려줌 (변수에 저장 가능)

    ✅ 점검하기¶

    1. 다음 코드의 출력 결과는? 

    def add(a, b):
    return a + b

result = add(3, 5)
print(result)

    정답 확인 `8`이 출력됩니다. 매개변수 `a`에 3, `b`에 5가 들어가고 `3 + 5 = 8`이 반환됩니다.

    2. 함수가 필요한 이유를 한 문장으로 말해보세요.

    정답 확인 반복되는 코드를 한 곳에 모아 재사용하고, 수정도 한 곳에서만 하면 되기 때문입니다.

    3. return이 없는 함수의 결과를 변수에 저장하면 어떻게 될까요?

    정답 확인 `None`이라는 특별한 값이 저장됩니다. 아무것도 돌려주지 않았기 때문이에요.

    📌 이 장의 핵심 정리¶

    • ✅ 함수 = def 이름(): 으로 코드 묶음에 이름 붙이기
    • ✅ 매개변수 = 함수에 전달하는 재료 / 반환값 = return으로 돌려주는 결과
    • ✅ 반복되는 코드를 함수로 만들면 재사용과 유지보수가 쉬워진다
