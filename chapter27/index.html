    코드 리팩토링 - 더 좋은 코드로 발전시키기¶

    🎯 이 장의 학습 목표¶

    • [ ] 리팩토링이 무엇인지 설명하고, 왜 필요한지 이해할 수 있다
    • [ ] 반복되는 코드를 함수로 묶어 정리할 수 있다
    • 예상 학습 시간: 약 40분

    📚 미리 알아야 할 것¶

    • 함수를 만들고 호출하는 방법 (def, return)
    • 변수에 값을 저장하고 사용하는 방법
    • for 반복문의 기본 사용법

    📚 핵심 개념¶

    개념 1: 리팩토링이란?¶

    비유로 시작해볼게요. 🏠

    리팩토링은 마치 방 정리와 같아요. 방이 지저분해도 생활은 할 수 있죠. 옷도 찾을 수 있고, 잠도 잘 수 있어요. 하지만 정리를 하면 옷을 더 빨리 찾고, 공간도 넓어지고, 기분도 좋아지잖아요?

    코드도 마찬가지예요. 지금 잘 돌아가는 코드라도, 더 읽기 쉽고 수정하기 편하게 다듬는 작업을 리팩토링(Refactoring) 이라고 합니다.

    리팩토링의 정확한 정의: 코드의 동작(결과)은 바꾸지 않으면서, 코드의 구조와 가독성을 개선하는 작업

    핵심은 "결과는 그대로, 품질만 높인다" 는 거예요!

    flowchart LR A["🔧 리팩토링 전\n동작: ✅\n읽기: 😵"] --> B["✨ 리팩토링"] B --> C["🎉 리팩토링 후\n동작: ✅\n읽기: 😊"]

    개념 2: 코드 스멜 — "냄새 나는 코드"¶

    리팩토링이 필요한 코드에는 특징이 있어요. 프로그래머들은 이걸 "코드 스멜(Code Smell)" 이라고 부릅니다. 말 그대로 "코드에서 냄새가 난다"는 뜻이에요. 🤢

    대표적인 코드 스멜 두 가지만 기억하세요:

    • 🔁 반복되는 코드: 비슷한 코드가 여러 곳에 복사-붙여넣기 되어 있음
    • 😵 의미를 알 수 없는 이름: a, x, tmp 같은 변수명으로 가득한 코드

    💡 잠깐! "코드 스멜"이라는 말이 재미있죠? 에러는 아니지만, "뭔가 개선할 수 있을 것 같은 느낌"을 냄새에 비유한 거예요. 이 감각은 코딩을 하면 할수록 발달합니다!

    🔨 따라하기: 리팩토링 실습¶

    학생 3명의 시험 점수를 분석하는 코드를 단계별로 리팩토링해볼게요.

    Step 1: 리팩토링 "전" 코드 살펴보기¶

    먼저, 동작은 하지만 냄새가 나는 코드를 봅시다.

    # 리팩토링 전 - 냄새 나는 코드 😵
a = 85
b = 92
c = 78

# 학생1 결과
if a >= 90:
    print("철수: A등급")
elif a >= 80:
    print("철수: B등급")
else:
    print("철수: C등급")

# 학생2 결과
if b >= 90:
    print("영희: A등급")
elif b >= 80:
    print("영희: B등급")
else:
    print("영희: C등급")

# 학생3 결과
if c >= 90:
    print("민수: A등급")
elif c >= 80:
    print("민수: B등급")
else:
    print("민수: C등급")

    실행 결과: 

    철수: B등급
영희: A등급
민수: C등급

    코드가 잘 돌아가요! 하지만 문제가 보이시나요?

    • a, b, c가 무슨 뜻인지 모르겠음 😵
    • 등급 판별하는 if-elif-else가 3번이나 복사-붙여넣기 됨 🔁

    Step 2: 의미 있는 변수명으로 바꾸기¶

    가장 쉬운 리팩토링부터 시작해요. 변수명만 바꿔도 코드가 확 달라집니다.

    # 의미 있는 이름으로 변경 ✨
score_철수 = 85
score_영희 = 92
score_민수 = 78

    a보다 score_철수가 훨씬 이해하기 쉽죠? 이것만으로도 훌륭한 리팩토링이에요!

    Step 3: 반복 코드를 함수로 묶기¶

    이제 핵심이에요! 3번 반복되는 등급 판별 코드를 함수 하나로 만들어봅시다.

    def get_grade(name, score):
    """학생 이름과 점수를 받아 등급을 출력하는 함수"""
    if score >= 90:
        grade = "A등급"
    elif score >= 80:
        grade = "B등급"
    else:
        grade = "C등급"
    print(f"{name}: {grade}")

    Step 4: 함수를 활용해 코드 완성하기¶

    반복되던 15줄이 깔끔한 3줄로 바뀝니다!

    get_grade("철수", 85)
get_grade("영희", 92)
get_grade("민수", 78)

    실행 결과: 

    철수: B등급
영희: A등급
민수: C등급

    결과는 완전히 동일해요. 하지만 코드는 훨씬 깔끔해졌죠!

    Step 5: 더 발전시키기 — 리스트 활용¶

    학생이 10명, 100명이 되면? 리스트와 반복문을 함께 쓰면 됩니다.

    students = [("철수", 85), ("영희", 92), ("민수", 78)]

for name, score in students:
    get_grade(name, score)

    💡 여기까지 이해가 잘 되셨나요? 리팩토링의 핵심은 "결과는 같되, 구조를 개선하는 것"이에요. 천천히 각 단계를 비교해보세요!

    📝 전체 코드¶

    def get_grade(name, score):
    """학생 이름과 점수를 받아 등급을 출력하는 함수"""
    if score >= 90:
        grade = "A등급"
    elif score >= 80:
        grade = "B등급"
    else:
        grade = "C등급"
    print(f"{name}: {grade}")

# 학생 데이터
students = [("철수", 85), ("영희", 92), ("민수", 78)]

# 모든 학생의 등급 출력
for name, score in students:
    get_grade(name, score)

    리팩토링 전후를 비교해보세요:

    • 전: 약 20줄, 변수명 의미 없음, 같은 로직 3번 반복
    • 후: 약 10줄, 변수명 명확, 로직 1번만 작성, 학생 추가도 간편

    ⚠️ 주의할 점¶

    1. 리팩토링 후 결과가 달라지면 안 돼요!

    리팩토링은 "코드 정리"이지 "기능 변경"이 아닙니다. 리팩토링 전후에 반드시 같은 결과가 나오는지 확인하세요. 실행해서 비교하는 습관이 중요해요.

    2. 한 번에 다 바꾸지 마세요!

    위 실습처럼 한 단계씩 조금씩 고치세요. 변수명 먼저 → 함수 만들기 → 반복문 적용. 한꺼번에 바꾸면 어디서 문제가 생겼는지 찾기 어려워요.

    ✅ 점검하기¶

    1. 리팩토링이란 무엇인가요?

    정답 확인 코드의 동작(결과)은 바꾸지 않으면서, 코드의 구조와 가독성을 개선하는 작업입니다. 방 정리처럼, 기능은 그대로인데 더 깔끔하게 만드는 거예요!

    2. 다음 코드에서 "코드 스멜"을 찾아보세요.

    x = 10
y = 20
print(x + y)
print(x * y)
    정답 확인 `x`, `y`라는 변수명이 의미를 알 수 없어요. 예를 들어 가격과 수량이라면 `price = 10`, `quantity = 20`처럼 바꾸는 것이 좋습니다.

    3. 비슷한 코드가 5번 반복된다면 어떻게 리팩토링하나요?

    정답 확인 반복되는 코드를 **함수로 만들고**, 달라지는 부분은 **매개변수**로 받으면 됩니다. 그리고 반복문으로 함수를 호출하면 깔끔해져요!
