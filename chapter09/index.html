    📚 핵심 개념¶

    개념 1: 라이브러리 — 미리 만들어진 도구 상자 🧰¶

    여러분이 집에서 책장을 조립한다고 생각해 보세요. 못, 망치, 드라이버를 직접 만들 필요는 없죠? 공구 상자에서 꺼내 쓰면 됩니다.

    프로그래밍에서 라이브러리(Library)가 바로 이 공구 상자예요!

    라이브러리: 누군가 미리 만들어 놓은 코드 모음. 복잡한 기능을 직접 만들지 않고 가져다 쓸 수 있어요.

    DHT 센서에서 온도와 습도를 읽으려면 복잡한 신호 처리가 필요한데, 라이브러리를 쓰면 딱 한 줄로 해결됩니다!

    # 라이브러리 없이 (상상만 해도 복잡!) ❌
# 핀에 신호 보내고, 타이밍 맞추고, 비트 해석하고...

# 라이브러리 사용 (간단!) ✅
from dht import DHT11
sensor = DHT11(pin0)
sensor.measure()
temperature = sensor.temperature()

    개념 2: f-string — 데이터를 예쁘게 포장하기 🎁¶

    센서에서 읽은 숫자를 그냥 출력하면 밋밋하죠. f-string을 사용하면 문자와 변수를 자유롭게 섞어서 출력할 수 있어요.

    temp = 24.5
humidity = 55

# 기존 방식 (번거로움)
print("온도: " + str(temp) + "°C")

# f-string 방식 (깔끔!) ✨
print(f"온도: {temp}°C, 습도: {humidity}%")

    규칙은 딱 두 가지: 1. 따옴표 앞에 f를 붙인다 2. 변수를 {중괄호} 안에 넣는다

    💡 잠깐! f-string의 f는 format(형식)의 약자예요. "이 문자열에는 변수가 들어갈 자리가 있어!" 라고 파이썬에게 알려주는 거예요.

    🔨 따라하기¶

    준비물¶

    • 마이크로비트 본체
    • DHT11 온습도 센서 모듈 (3핀: VCC, GND, DATA)
    • 점퍼 와이어 3개

    Step 1: 센서 연결하기¶

    DHT11 센서를 마이크로비트에 연결합니다.

    flowchart LR subgraph DHT11["🌡️ DHT11 센서"] V["VCC (전원)"] D["DATA (데이터)"] G["GND (접지)"] end subgraph MB["💻 마이크로비트"] P3V["3V"] P0["pin0"] PGND["GND"] end V -->|빨간 선| P3V D -->|노란 선| P0 G -->|검은 선| PGND
    DHT11 핀 연결 위치 선 색상
    VCC 3V 빨간색
    DATA pin0 노란색
    GND GND 검은색

    ✅ 체크포인트: 3개의 선이 모두 연결되었는지 확인하세요!

    Step 2: 기본 코드 작성하기¶

    Mu 에디터를 열고 아래 코드를 입력하세요.

    from microbit import *
from dht import DHT11

# 센서 객체 만들기 (pin0에 연결)
sensor = DHT11(pin0)

    여기서 from dht import DHT11이 바로 라이브러리에서 도구를 꺼내는 코드예요. 마이크로비트 MicroPython에는 DHT 라이브러리가 기본 내장되어 있어서 별도 설치가 필요 없습니다!

    Step 3: 온도와 습도 읽기¶

    센서에서 데이터를 읽는 코드를 추가합니다.

    from microbit import *
from dht import DHT11

sensor = DHT11(pin0)

while True:
    try:
        sensor.measure()          # 센서에게 "측정해!" 명령
        temp = sensor.temperature()   # 온도 값 가져오기
        humi = sensor.humidity()      # 습도 값 가져오기

        print(f"온도: {temp}°C, 습도: {humi}%")
    except Exception as e:
        print(f"측정 실패: {e}")

    sleep(2000)  # 2초 대기 (DHT11은 최소 1초 간격 필요)

    💡 try-except는 "혹시 에러가 나더라도 프로그램을 멈추지 마!" 라는 안전장치예요. 센서 통신이 가끔 실패할 수 있거든요.

    Step 4: 코드 업로드 및 결과 확인¶

    1. Flash 버튼을 눌러 코드를 마이크로비트에 업로드하세요
    2. REPL 버튼을 눌러 시리얼 모니터를 열어보세요

    실행 결과: 

    온도: 24°C, 습도: 55%
온도: 24°C, 습도: 56%
온도: 25°C, 습도: 55%

    ✅ 체크포인트: 2초마다 온도와 습도가 출력되고 있나요? 축하합니다! 🎉

    Step 5: LED에도 표시하기¶

    시리얼 모니터 없이도 값을 확인할 수 있도록 LED에 표시를 추가해 봅시다.

    from microbit import *
from dht import DHT11

sensor = DHT11(pin0)

while True:
    try:
        sensor.measure()
        temp = sensor.temperature()
        humi = sensor.humidity()

        # 시리얼 출력
        print(f"온도: {temp}°C, 습도: {humi}%")

        # LED에 스크롤 표시
        display.scroll(f"{temp}C {humi}%")
    except:
        display.scroll("Err")

    sleep(2000)

    📝 전체 코드¶

    from microbit import *
from dht import DHT11

# DHT11 센서를 pin0에 연결
sensor = DHT11(pin0)

while True:
    try:
        # 1. 센서 측정 시작
        sensor.measure()

        # 2. 값 읽기
        temp = sensor.temperature()   # 온도 (정수, °C)
        humi = sensor.humidity()      # 습도 (정수, %)

        # 3. 시리얼 모니터에 출력
        print(f"온도: {temp}°C, 습도: {humi}%")

        # 4. LED에 표시
        display.scroll(f"{temp}C {humi}%")

    except Exception as e:
        print(f"측정 실패: {e}")
        display.scroll("Err")

    sleep(2000)  # 2초 간격으로 측정

    ⚠️ 주의할 점¶

    1. 측정 간격을 너무 짧게 하지 마세요! - DHT11은 최소 1초 간격이 필요해요. sleep(2000) (2초)을 권장합니다. - 너무 빨리 읽으면 에러가 발생하거나 잘못된 값이 나올 수 있어요.

    2. DHT11과 DHT22의 차이 - DHT11: 온도 0~50°C (정수), 습도 20~80% — 저렴하고 입문용 - DHT22: 더 넓은 범위, 소수점 지원 — 더 정밀하지만 비쌈 - 코드에서 DHT11을 DHT22로 바꾸면 DHT22도 사용 가능!

    ✅ 점검하기¶

    1. 라이브러리란 무엇인가요?

    정답 확인 누군가 미리 만들어 놓은 코드 모음(도구 상자)으로, 복잡한 기능을 직접 만들지 않고 가져다 쓸 수 있는 것입니다. `from 라이브러리 import 도구` 형태로 불러옵니다.

    2. 다음 f-string의 출력 결과는? 

    name = "교실"
temp = 26
print(f"{name} 온도는 {temp}도입니다")

    정답 확인 
    교실 온도는 26도입니다
    f-string은 `{}`안의 변수를 실제 값으로 바꿔줍니다.

    3. DHT11 센서 측정 간격을 1초 미만으로 하면 어떤 문제가 생길 수 있나요?

    정답 확인 센서가 아직 측정을 완료하지 못한 상태에서 다시 읽으려고 하기 때문에, 에러가 발생하거나 잘못된 값이 출력될 수 있습니다.
