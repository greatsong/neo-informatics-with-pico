    📘 Chapter 21: 온도에 따른 LED 색상 표시기 만들기¶

    🎯 이 장의 학습 목표¶

    이 장을 마치면 다음을 할 수 있습니다:

    • [ ] RGB LED의 원리를 이해하고 코드로 색상을 제어할 수 있다
    • [ ] 온도 범위에 따라 다른 색상을 표시하는 프로그램을 작성할 수 있다

    예상 학습 시간: 약 40분

    📚 미리 알아야 할 것¶

    이전 장에서 배운 내용을 간단히 떠올려 볼까요?

    • 조건문(if/elif/else): 조건에 따라 다른 코드를 실행하는 방법
    • 비교 연산자: <, >, <=, >= 등으로 값을 비교하는 방법
    • 변수: 데이터를 저장하는 이름표 붙은 상자

    이 개념들이 기억나지 않아도 괜찮아요. 실습하면서 자연스럽게 복습하게 됩니다! 😊

    📚 핵심 개념¶

    개념 1: RGB LED — 빛의 삼원색으로 모든 색 만들기¶

    RGB LED는 마치 물감 팔레트와 같아요. 빨강(Red), 초록(Green), 파랑(Blue) 세 가지 빛을 섞어서 거의 모든 색을 만들어낼 수 있습니다.

    flowchart LR R["🔴 빨강\n(Red)"] --> MIX["🎨 색상 혼합"] G["🟢 초록\n(Green)"] --> MIX B["🔵 파랑\n(Blue)"] --> MIX MIX --> RESULT["💡 원하는 색상!"] style R fill:#ffcdd2,stroke:#e53935 style G fill:#c8e6c9,stroke:#43a047 style B fill:#bbdefb,stroke:#1e88e5 style MIX fill:#fff9c4,stroke:#f9a825 style RESULT fill:#f3e5f5,stroke:#8e24aa

    각 색상의 밝기를 0~255 숫자로 조절합니다:

    색상 조합 R G B 결과
    빨강만 255 0 0 🔴 빨간색
    초록만 0 255 0 🟢 초록색
    파랑만 0 0 255 🔵 파란색
    빨강+초록 255 255 0 🟡 노란색
    모두 끔 0 0 0 ⚫ 꺼짐

    💡 기억하세요: 0은 완전히 꺼진 상태, 255는 최대 밝기예요!

    개념 2: 조건문으로 온도 구간 나누기¶

    온도계를 볼 때, 우리는 자연스럽게 구간으로 나눠서 판단하죠:

    • "18도 이하면 춥다" → 🔵 파란색
    • "18~28도면 쾌적하다" → 🟢 초록색
    • "28도 이상이면 덥다" → 🔴 빨간색

    이것을 코드로 옮기면 if/elif/else 구조가 됩니다:

    if temperature <= 18:
    # 춥다 → 파란색
elif temperature <= 28:
    # 쾌적 → 초록색
else:
    # 덥다 → 빨간색
    flowchart TD START["🌡️ 온도 측정"] --> CHECK1{"온도 ≤ 18?"} CHECK1 -->|예| BLUE["🔵 파란색 표시\n추워요!"] CHECK1 -->|아니오| CHECK2{"온도 ≤ 28?"} CHECK2 -->|예| GREEN["🟢 초록색 표시\n쾌적해요!"] CHECK2 -->|아니오| RED["🔴 빨간색 표시\n더워요!"] style BLUE fill:#bbdefb,stroke:#1e88e5 style GREEN fill:#c8e6c9,stroke:#43a047 style RED fill:#ffcdd2,stroke:#e53935 style START fill:#fff9c4,stroke:#f9a825

    💡 잠깐! 여기까지 이해가 잘 되셨나요? RGB의 숫자 조합으로 색을 만들고, 조건문으로 온도 구간을 나눈다 — 이 두 가지만 알면 준비 끝이에요!

    🔨 따라하기¶

    이제 직접 코드를 작성해 봅시다! 실제 하드웨어가 없어도, 시뮬레이션 방식으로 동작 원리를 완벽히 익힐 수 있어요.

    Step 1: RGB 색상을 표현하는 함수 만들기¶

    먼저 RGB LED에 색상을 보내는 함수를 만들어 볼게요.

    코드: 

    def set_led_color(red, green, blue):
    """RGB LED의 색상을 설정하는 함수"""
    print(f"LED 색상 → R:{red}, G:{green}, B:{blue}")

    # 어떤 색인지 알기 쉽게 표시
    if red > 0 and green == 0 and blue == 0:
        print("🔴 빨간색 빛이 켜졌습니다!")
    elif red == 0 and green > 0 and blue == 0:
        print("🟢 초록색 빛이 켜졌습니다!")
    elif red == 0 and green == 0 and blue > 0:
        print("🔵 파란색 빛이 켜졌습니다!")

# 테스트
set_led_color(255, 0, 0)

    실행 결과: 

    LED 색상 → R:255, G:0, B:0
🔴 빨간색 빛이 켜졌습니다!

    Step 2: 온도에 따라 색상 결정하기¶

    핵심 로직을 함수로 만듭니다.

    코드: 

    def get_color_by_temperature(temp):
    """온도에 따라 RGB 값을 반환하는 함수"""
    if temp <= 18:
        return (0, 0, 255)    # 🔵 파랑 = 추움
    elif temp <= 28:
        return (0, 255, 0)    # 🟢 초록 = 쾌적
    else:
        return (255, 0, 0)    # 🔴 빨강 = 더움

    ✅ 체크포인트: return (0, 0, 255)는 R=0, G=0, B=255, 즉 파란색을 의미해요!

    Step 3: 온도 입력받아 LED 표시하기¶

    사용자가 온도를 입력하면 해당하는 색상을 보여주는 부분을 만들어요.

    코드: 

    # 온도 입력받기
temp = float(input("현재 온도를 입력하세요 (°C): "))

# 온도에 맞는 색상 가져오기
r, g, b = get_color_by_temperature(temp)

# LED 색상 설정
print(f"\n🌡️ 현재 온도: {temp}°C")
set_led_color(r, g, b)

    실행 결과 (15를 입력한 경우): 

    현재 온도를 입력하세요 (°C): 15
🌡️ 현재 온도: 15.0°C
LED 색상 → R:0, G:0, B:255
🔵 파란색 빛이 켜졌습니다!

    Step 4: 여러 온도를 연속으로 테스트하기¶

    반복문으로 여러 온도를 한 번에 확인해 봅시다.

    코드: 

    # 다양한 온도를 테스트
test_temperatures = [5, 15, 20, 25, 30, 35]

print("=" * 40)
print("🌡️ 온도별 LED 색상 표시기")
print("=" * 40)

for temp in test_temperatures:
    r, g, b = get_color_by_temperature(temp)

    # 색상 이모지 결정
    if b > 0:
        emoji = "🔵"
        status = "추움"
    elif g > 0:
        emoji = "🟢"
        status = "쾌적"
    else:
        emoji = "🔴"
        status = "더움"

    print(f"  {temp:>4}°C → {emoji} {status}")

    실행 결과: 

    ========================================
🌡️ 온도별 LED 색상 표시기
========================================
     5°C → 🔵 추움
    15°C → 🔵 추움
    20°C → 🟢 쾌적
    25°C → 🟢 쾌적
    30°C → 🔴 더움
    35°C → 🔴 더움

    💡 18도 이하는 파랑, 19~28도는 초록, 29도 이상은 빨강으로 잘 나뉘는 것이 보이시죠?

    📝 전체 코드¶

    아래 코드를 복사해서 바로 실행해 보세요!

    # === 온도에 따른 LED 색상 표시기 ===

def set_led_color(red, green, blue):
    """RGB LED의 색상을 설정하는 함수"""
    print(f"  LED → R:{red}, G:{green}, B:{blue}")

def get_color_by_temperature(temp):
    """온도에 따라 RGB 값을 반환하는 함수"""
    if temp <= 18:
        return (0, 0, 255)    # 파랑 = 추움
    elif temp <= 28:
        return (0, 255, 0)    # 초록 = 쾌적
    else:
        return (255, 0, 0)    # 빨강 = 더움

# --- 자동 테스트 ---
test_temps = [5, 15, 20, 25, 30, 35]

print("🌡️ 온도별 LED 색상 표시기")
print("-" * 35)

for temp in test_temps:
    r, g, b = get_color_by_temperature(temp)
    if b > 0:
        emoji, status = "🔵", "추움"
    elif g > 0:
        emoji, status = "🟢", "쾌적"
    else:
        emoji, status = "🔴", "더움"
    print(f"  {temp:>3}°C → {emoji} {status}")
    set_led_color(r, g, b)

# --- 사용자 입력 모드 ---
print("\n" + "=" * 35)
temp = float(input("온도를 직접 입력해 보세요 (°C): "))
r, g, b = get_color_by_temperature(temp)
print(f"\n🌡️ {temp}°C →", end=" ")
if b > 0:
    print("🔵 파란색 (추워요!)")
elif g > 0:
    print("🟢 초록색 (쾌적해요!)")
else:
    print("🔴 빨간색 (더워요!)")
set_led_color(r, g, b)

    ⚠️ 주의할 점¶

    1. 조건 순서가 중요해요!

    elif는 위의 조건이 거짓일 때만 검사합니다. 그래서 temp <= 28이라고만 써도, 이미 18 이하는 위에서 걸러졌기 때문에 실제로는 19~28도 구간만 해당돼요.

    # ✅ 올바른 순서
if temp <= 18:      # 18 이하
elif temp <= 28:    # 19~28 (위에서 18 이하는 이미 처리됨)
else:               # 29 이상

# ❌ 순서를 바꾸면 문제 발생!
if temp <= 28:      # 28 이하 전부(5도도 여기에 걸림!)
elif temp <= 18:    # 여기는 절대 실행 안 됨!

    2. 입력값은 float()로 변환하세요!

    input()은 항상 문자열을 반환합니다. 숫자로 비교하려면 float()로 감싸야 해요.

    ✅ 점검하기¶

    1. RGB 값 (0, 255, 0)은 무슨 색일까요?¶

    정답 확인 🟢 **초록색**입니다! R=0, G=255(최대), B=0이므로 초록 빛만 최대 밝기로 켜집니다.

    2. 온도가 정확히 18도일 때, 어떤 색이 표시될까요?¶

    정답 확인 🔵 **파란색**입니다! 조건이 `temp <= 18`이므로, 18도는 "이하"에 포함되어 파란색이 됩니다.

    3. "매우 추움(10도 이하)은 보라색"을 추가하려면 어디에 조건을 넣어야 할까요?¶

    정답 확인 **가장 위에** 추가해야 합니다! 
    if temp <= 10:
    return (128, 0, 255)   # 보라색 = 매우 추움
elif temp <= 18:
    return (0, 0, 255)     # 파랑 = 추움
elif temp <= 28:
    return (0, 255, 0)     # 초록 = 쾌적
else:
    return (255, 0, 0)     # 빨강 = 더움
    좁은 범위의 조건을 위에 놓아야 먼저 검사됩니다!
