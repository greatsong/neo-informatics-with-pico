    4단원 마무리 - 나만의 환경 대시보드 완성¶

    🎯 이 장의 학습 목표¶

    이 장을 마치면 다음을 할 수 있습니다:

    • [ ] 온습도, 조도 데이터를 한 화면에 표시하는 대시보드를 완성할 수 있다
    • [ ] AI에게 그래프, 알림 등 추가 기능을 요청하여 구현할 수 있다
    • [ ] 완성된 대시보드를 스마트폰 등 다른 기기에서 접속하여 시연할 수 있다
    • [ ] Part 4 전체에서 배운 AI 협업 경험을 정리할 수 있다

    예상 학습 시간: 약 90분

    📚 미리 알아야 할 것¶

    Part 4를 진행하며 여러분은 이미 많은 것을 배웠습니다:

    • 챕터 35~36: Flask 웹 서버로 센서 데이터를 웹페이지에 표시하기
    • 챕터 37: AI에게 코드 수정을 요청하는 프롬프트 작성법
    • 아두이노 센서: 온습도(DHT11)와 조도(CdS) 센서에서 데이터 읽기

    💡 이번 장은 Part 4의 "졸업 작품"이에요! 지금까지 조각조각 만들었던 것들을 하나로 합쳐서 멋진 대시보드를 완성합니다. 천천히 따라오세요!

    💡 왜 이걸 배우나요?¶

    여러분이 지금까지 만든 것들을 떠올려 보세요. 온도를 읽는 코드, 습도를 표시하는 웹페이지, 조도 센서 데이터... 모두 따로따로 존재했죠?

    실제 세상의 대시보드를 생각해 보세요. 자동차 계기판은 속도, 연료, 엔진 온도를 한 화면에 보여줍니다. 우리도 마찬가지예요. 여러 센서 정보를 하나의 화면에 모아서 보여주는 것, 그것이 바로 대시보드입니다.

    이번 장에서는 AI와 대화하며 "내가 원하는 기능"을 하나씩 추가해 나갑니다. 이 과정이 바로 현업 개발자가 AI를 활용하는 방식과 같아요!

    📚 핵심 개념¶

    개념 1: 통합 대시보드 구조¶

    비유: 대시보드는 뉴스 앵커의 모니터 벽과 같습니다. 각 모니터에 다른 정보(날씨, 교통, 뉴스)가 나오지만, 앵커는 한자리에서 모든 것을 확인하죠.

    우리 대시보드도 마찬가지입니다: - 왼쪽 영역: 온도·습도 표시 - 오른쪽 영역: 조도(밝기) 표시 - 아래 영역: 시간별 변화 그래프

    flowchart TB subgraph 대시보드["🖥️ 나만의 환경 대시보드"] direction TB subgraph 상단["실시간 데이터"] A["🌡️ 온도: 24.5°C"] B["💧 습도: 55%"] C["☀️ 조도: 320"] end subgraph 하단["📈 변화 그래프"] D["시간별 데이터 차트"] end end

    개념 2: 데이터 자동 갱신¶

    웹페이지가 스스로 새로운 데이터를 가져오는 것을 자동 갱신이라고 합니다.

    비유: 시계를 생각해 보세요. 매 초마다 자동으로 숫자가 바뀌잖아요? 우리 대시보드도 일정 시간마다(예: 5초) 서버에 "새 데이터 주세요!"라고 요청합니다.

    이것을 JavaScript의 setInterval 함수로 구현해요:

    // 5초마다 자동으로 데이터를 가져오는 코드
setInterval(function() {
    fetch('/data')  // 서버에 데이터 요청
    .then(response => response.json())
    .then(data => {
        // 화면에 새 데이터 표시
        document.getElementById('temp').innerText = data.temperature + '°C';
    });
}, 5000);  // 5000밀리초 = 5초

    개념 3: 조건별 색상 알림¶

    온도가 30도를 넘으면 빨간색, 정상이면 초록색으로 표시하는 기능입니다.

    비유: 신호등과 같아요! 상황에 따라 색이 바뀌면 한눈에 "지금 괜찮은지 아닌지" 알 수 있죠.

    # 온도에 따라 색상을 결정하는 함수
def get_temp_color(temp):
    if temp >= 30:
        return "#ff4444"   # 빨간색 (더워요!)
    elif temp >= 20:
        return "#44bb44"   # 초록색 (쾌적해요)
    else:
        return "#4444ff"   # 파란색 (추워요!)

    개념 4: AI에게 기능 추가 요청하기¶

    대시보드를 만들 때 모든 코드를 외울 필요가 없습니다. AI에게 구체적으로 요청하면 돼요.

    효과적인 프롬프트의 3요소: - 현재 상태: "지금 Flask로 온습도를 표시하는 웹페이지가 있어" - 원하는 것: "여기에 조도 데이터도 추가하고 싶어" - 구체적 조건: "카드 형태로 나란히 배치하고, 5초마다 자동 갱신되게 해줘"

    💡 핵심 팁: AI에게 요청할 때 "한 번에 하나씩" 요청하세요. "대시보드 전체를 만들어줘"보다 "먼저 온도 카드를 만들어줘"가 훨씬 좋은 결과를 줍니다!

    🔨 따라하기: 환경 대시보드 완성하기¶

    Step 1: 통합 서버 코드 준비하기¶

    아두이노에서 온습도와 조도 데이터를 모두 읽어오는 Flask 서버를 만듭니다.

    파일명: dashboard.py

    from flask import Flask, render_template, jsonify
import serial
import json
import time

app = Flask(__name__)

# 시리얼 포트 연결 (본인 환경에 맞게 수정)
# Windows: 'COM3', Mac/Linux: '/dev/ttyUSB0'
try:
    ser = serial.Serial('COM3', 9600, timeout=1)
    time.sleep(2)  # 아두이노 초기화 대기
except:
    ser = None
    print("⚠️ 아두이노 연결 없음 - 테스트 모드로 실행")

# 데이터 기록 저장 (최근 20개)
history = []

def get_sensor_data():
    """센서에서 데이터를 읽어오는 함수"""
    if ser and ser.is_open:
        try:
            line = ser.readline().decode('utf-8').strip()
            data = json.loads(line)
            return data
        except:
            pass

    # 테스트용 더미 데이터
    import random
    return {
        "temperature": round(22 + random.uniform(-3, 5), 1),
        "humidity": round(50 + random.uniform(-10, 15), 1),
        "light": round(300 + random.uniform(-100, 200))
    }

@app.route('/')
def index():
    return render_template('dashboard.html')

@app.route('/data')
def data():
    sensor = get_sensor_data()

    # 히스토리에 저장 (최대 20개)
    sensor['time'] = time.strftime('%H:%M:%S')
    history.append(sensor)
    if len(history) > 20:
        history.pop(0)

    return jsonify(sensor)

@app.route('/history')
def get_history():
    return jsonify(history)

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000, debug=True)

    ✅ 체크포인트: host='0.0.0.0'으로 설정하면 같은 Wi-Fi의 다른 기기에서도 접속할 수 있어요!

            fetch('/data')

                    status.innerText = '🔴 실내가 더워요! 환기가 필요합니다.';

                    status.innerText = '🟢 쾌적한 환경입니다!';
                    status.style.background = '#224422';

            })
            .catch(err => {
                document.getElementById('statusBar').innerText = 
                    '⚠️ 데이터를 불러올 수 없습니다.';
            });
        }

        // 처음 한 번 실행 + 5초마다 반복
        updateDashboard();
        setInterval(updateDashboard, 5000);
    </script>

    Step 3: AI에게 기능 추가 요청하기¶

    대시보드가 기본적으로 동작하면, 이제 AI에게 원하는 기능을 요청해 봅시다.

    예시 프롬프트 1 - 그래프 추가:

    지금 Flask + HTML로 환경 대시보드를 만들었어.
온도, 습도, 조도 데이터가 5초마다 갱신돼.

여기에 Chart.js를 사용해서 최근 20개 데이터의 
온도 변화를 꺾은선 그래프로 보여주고 싶어.

/history 라우트에서 기록 데이터를 받을 수 있어.
그래프를 카드 아래쪽에 추가하는 HTML/JS 코드를 알려줘.

    예시 프롬프트 2 - 디자인 개선:

    현재 대시보드의 카드 디자인을 더 예쁘게 바꾸고 싶어.
각 카드에 그라데이션 배경을 넣고,

CSS만 수정하면 돼.

    💡 잠깐! AI가 준 코드를 바로 전체 교체하지 마세요. 변경된 부분만 확인하고 기존 코드에 추가하는 습관을 들이세요. 한꺼번에 바꾸면 문제가 생겼을 때 원인을 찾기 어려워요.

    Step 4: 스마트폰에서 접속하기¶

    완성된 대시보드를 스마트폰에서 확인해 봅시다!

    1단계: 컴퓨터의 IP 주소 확인하기

    # Windows - 명령 프롬프트에서
ipconfig
# "IPv4 주소" 항목을 찾으세요 (예: 192.168.0.15)

# Mac - 터미널에서  
ifconfig | grep inet

    2단계: 스마트폰 브라우저에서 접속

    http://192.168.0.15:5000

    (위 IP 주소를 본인 컴퓨터의 IP로 바꾸세요)

    3단계: 스마트폰에서도 카드가 잘 보이고, 데이터가 갱신되는지 확인!

    ✅ 체크포인트: 스마트폰 화면에서 3개의 센서 카드가 보이고, 상태 메시지가 표시되면 성공입니다! 🎉

    Step 5: 나만의 개성 추가하기¶

    • 🎨 배경 테마 변경: 다크모드/라이트모드 전환 버튼
    • 📊 미니 그래프: 각 카드 안에 작은 스파크라인 차트
    • 🔔 소리 알림: 온도가 30도 이상이면 알림음 재생
    • 📱 레이아웃 변경: 카드 배치를 2x2로 바꾸기
    • 🏷️ 대시보드 이름: 상단에 본인 이름과 프로젝트명 추가

    📝 전체 코드¶

    핵심 파일 2개의 구조를 정리합니다:

    프로젝트 폴더/
├── dashboard.py          ← Flask 서버 (Step 1)
└── templates/
    └── dashboard.html    ← 대시보드 화면 (Step 2)

    전체 코드는 Step 1과 Step 2에 있습니다. 그대로 복사하여 사용할 수 있어요.

    💡 Tip: 아두이노가 없어도 테스트 모드(더미 데이터)로 동작하도록 만들었으므로, 코드만으로도 대시보드를 체험할 수 있습니다!

    ⚠️ 자주 하는 실수¶

    실수 1: 스마트폰에서 접속이 안 돼요! - 왜 이런 일이 생기나요? app.run()에서 host='0.0.0.0'을 빠뜨리면 외부 접속이 차단됩니다. - 이렇게 해결해요: app.run(host='0.0.0.0', port=5000)으로 수정하세요. 또한 컴퓨터와 스마트폰이 같은 Wi-Fi에 연결되어 있어야 합니다.

    실수 2: 데이터가 갱신되지 않아요! - 왜 이런 일이 생기나요? JavaScript의 fetch('/data')가 에러를 반환하면 화면이 멈춘 것처럼 보입니다. - 이렇게 해결해요: 브라우저에서 http://localhost:5000/data를 직접 열어보세요. JSON 데이터가 나오면 서버는 정상입니다. 안 나오면 dashboard.py의 에러 메시지를 확인하세요.

    실수 3: AI가 준 코드를 붙여넣었는데 전체가 망가졌어요! - 왜 이런 일이 생기나요? AI가 기존 코드 구조를 다르게 이해하고 전혀 다른 구조의 코드를 줄 수 있습니다. - 이렇게 해결해요: 항상 변경 전 코드를 백업하세요. 파일을 dashboard_backup.html로 복사해 두고, 문제가 생기면 되돌리면 됩니다.
