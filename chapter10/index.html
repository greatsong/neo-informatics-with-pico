    챕터 10: 조도 센서로 빛의 밝기 측정하기 💡¶

    🎯 이 장의 학습 목표¶

    이 장을 마치면 다음을 할 수 있습니다:

    • [ ] 조도 센서의 아날로그 값을 읽고 밝기 변화를 확인할 수 있다
    • [ ] ADC(아날로그-디지털 변환) 개념을 이해하고 설명할 수 있다
    • [ ] 측정값을 활용해 밝기 상태를 판별하는 프로그램을 만들 수 있다

    예상 학습 시간: 약 50분

    📚 미리 알아야 할 것¶

    이전 장에서 배운 내용을 간단히 떠올려 볼까요?

    • 디지털 입력: HIGH(1) 또는 LOW(0), 두 가지 상태만 읽었어요
    • print() 로 시리얼 모니터에 값 출력하는 방법
    • 아두이노에 센서를 연결하고 코드를 업로드하는 기본 과정

    이번에는 0과 1이 아닌, 중간 값까지 읽는 방법을 배웁니다!

    📚 핵심 개념¶

    개념 1: 아날로그 신호와 ADC¶

    비유로 시작할게요. 🎵

    여러분이 노래를 부르면 목소리는 부드럽게 연결된 파도처럼 흘러갑니다. 이것이 아날로그 신호예요 — 끊김 없이 연속적으로 변하는 값이죠.

    그런데 이 노래를 스마트폰에 저장하려면? 컴퓨터는 연속적인 파도를 이해하지 못해요. 그래서 일정 간격으로 높이를 측정해서 숫자로 기록합니다. 이 과정이 바로 ADC(Analog-to-Digital Conversion), 아날로그-디지털 변환이에요.

    flowchart LR A["🌊 아날로그 신호<br/>(연속적인 빛의 밝기)"] --> B["⚙️ ADC 변환<br/>(숫자로 바꾸기)"] --> C["🔢 디지털 값<br/>(0 ~ 1023)"] style A fill:#fff3e0,stroke:#f57c00 style B fill:#e3f2fd,stroke:#1976d2 style C fill:#e8f5e9,stroke:#388e3c

    정확한 정의: ADC란 연속적으로 변하는 아날로그 신호를 컴퓨터가 처리할 수 있는 정수 값으로 바꾸는 과정입니다.

    아두이노의 ADC 핵심 수치: | 항목 | 값 | |------|-----| | 입력 전압 범위 | 0V ~ 5V | | 해상도 | 10비트 | | 출력 값 범위 | 0 ~ 1023 |

    0V → 0, 5V → 1023, 2.5V → 약 512

    개념 2: 조도 센서(CdS 포토레지스터)¶

    비유로 시작할게요. 👁️

    조도 센서는 빛에 반응하는 저항이에요. 마치 우리 눈의 동공처럼, 밝으면 저항이 줄어들고 어두우면 저항이 커집니다.

    정확한 정의: CdS(황화카드뮴) 포토레지스터는 빛의 양에 따라 저항값이 변하는 소자입니다.

    환경 저항 아날로그 읽기 값
    밝은 곳 ☀️ 낮음 높은 값 (700~1023)
    보통 🏠 중간 중간 값 (300~700)
    어두운 곳 🌙 높음 낮은 값 (0~300)

    ⚠️ 회로 구성 방식에 따라 밝을 때 값이 높을 수도, 낮을 수도 있어요. 이 교재에서는 밝을수록 값이 큰 회로를 사용합니다.

    💡 잠깐! 여기까지 이해가 잘 되셨나요? 정리하면: 빛 → 센서 저항 변화 → 전압 변화 → ADC가 숫자로 변환 → 우리가 읽기! 이 흐름만 기억하면 됩니다 😊

    🔨 따라하기¶

    Step 1: 회로 연결하기¶

    준비물: 아두이노 UNO, CdS 조도 센서, 10kΩ 저항, 브레드보드, 점퍼선

    연결 방법:

    부품 연결 위치
    CdS 센서 한쪽 다리 5V
    CdS 센서 다른 다리 A0 핀 + 10kΩ 저항
    10kΩ 저항 다른 쪽 GND
    flowchart LR V["5V ⚡"] --> CDS["CdS 센서"] CDS --> NODE["연결점 → A0"] NODE --> R["10kΩ 저항"] R --> GND["GND ⏚"] style V fill:#ffcdd2,stroke:#c62828 style GND fill:#bbdefb,stroke:#1565c0 style NODE fill:#fff9c4,stroke:#f9a825

    이 회로를 전압 분배 회로라고 해요. 센서와 저항이 전압을 나눠 갖고, 그 중간 지점의 전압을 A0에서 읽는 원리입니다.

    Step 2: 아날로그 값 읽기¶

    코드: 

    int sensorPin = A0;  // 조도 센서 연결 핀
int sensorValue = 0; // 읽은 값 저장용

void setup() {
  Serial.begin(9600);  // 시리얼 통신 시작
}

void loop() {
  sensorValue = analogRead(sensorPin);  // 아날로그 값 읽기 (0~1023)
  Serial.print("조도 값: ");
  Serial.println(sensorValue);
  delay(500);  // 0.5초 간격으로 측정
}

    실행 결과 (시리얼 모니터): 

    조도 값: 742
조도 값: 738
조도 값: 215
조도 값: 48

    ✅ 체크포인트: 시리얼 모니터에 숫자가 출력되면 성공! 손으로 센서를 가려보세요 — 값이 줄어들면 정상입니다.

    Step 3: 밝기 상태 판별하기¶

    측정값을 사람이 이해하기 쉬운 상태 메시지로 바꿔봅시다.

    코드: 

    int sensorPin = A0;
int sensorValue = 0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  sensorValue = analogRead(sensorPin);

  Serial.print("조도 값: ");
  Serial.print(sensorValue);
  Serial.print(" → ");

  // 밝기 상태 판별
  if (sensorValue > 700) {
    Serial.println("☀️ 아주 밝음");
  } else if (sensorValue > 400) {
    Serial.println("🏠 보통 밝기");
  } else if (sensorValue > 150) {
    Serial.println("🌅 어두움");
  } else {
    Serial.println("🌙 매우 어두움");
  }

  delay(1000);
}

    실행 결과: 

    조도 값: 782 → ☀️ 아주 밝음
조도 값: 523 → 🏠 보통 밝기
조도 값: 87 → 🌙 매우 어두움

    Step 4: 직접 실험해보기¶

    코드를 업로드한 후, 다음을 시도해보세요:

    1. 손으로 센서를 완전히 감싸기 → 값이 얼마까지 떨어지나요?
    2. 스마트폰 손전등을 센서에 비추기 → 값이 얼마까지 올라가나요?
    3. 서서히 손을 가까이/멀리 하기 → 값이 부드럽게 변하나요?

    💡 이것이 바로 아날로그의 장점이에요! 디지털은 ON/OFF 뿐이었지만, 아날로그는 중간 값을 모두 표현할 수 있습니다.

    📝 전체 코드¶

    // 챕터 10: 조도 센서로 밝기 측정하기
// 조도 센서(CdS)의 아날로그 값을 읽어 밝기 상태를 출력합니다

int sensorPin = A0;   // 조도 센서 핀
int sensorValue = 0;  // 센서 측정값

void setup() {
  Serial.begin(9600);
  Serial.println("=== 조도 센서 측정 시작 ===");
}

void loop() {
  // 1. 아날로그 값 읽기
  sensorValue = analogRead(sensorPin);

  // 2. 값 출력
  Serial.print("조도 값: ");
  Serial.print(sensorValue);
  Serial.print(" → ");

  // 3. 상태 판별
  if (sensorValue > 700) {
    Serial.println("아주 밝음");
  } else if (sensorValue > 400) {
    Serial.println("보통 밝기");
  } else if (sensorValue > 150) {
    Serial.println("어두움");
  } else {
    Serial.println("매우 어두움");
  }

  delay(1000);
}

    ⚠️ 주의할 점¶

    1. analogRead()와 digitalRead()를 혼동하지 마세요!

    함수 핀 반환 값
    digitalRead(핀) D0~D13 0 또는 1
    analogRead(핀) A0~A5 0 ~ 1023

    2. 임계값(700, 400, 150)은 환경에 따라 조정이 필요해요

    교재의 숫자는 예시일 뿐이에요. 여러분의 센서와 조명 환경에 맞게 시리얼 모니터 값을 관찰하면서 적절히 바꿔주세요.

    ✅ 점검하기¶

    1. analogRead(A0)의 반환 값 범위는?

    정답 확인 **0 ~ 1023**입니다. 아두이노 UNO의 ADC는 10비트 해상도로, 0V일 때 0, 5V일 때 1023을 반환합니다.

    2. ADC란 무엇인지 한 문장으로 설명해보세요.

    정답 확인 ADC(Analog-to-Digital Conversion)는 **연속적으로 변하는 아날로그 신호를 컴퓨터가 처리할 수 있는 정수 값으로 변환하는 과정**입니다.

    3. 조도 센서를 손으로 완전히 가렸을 때, 아날로그 값은 어떻게 변할까요?

    정답 확인 빛이 차단되면 센서 저항이 커지고, 아날로그 읽기 값은 **작아집니다** (0에 가까워짐). 우리 회로에서는 어두울수록 낮은 값이 나옵니다.

    📌 이 장의 핵심 정리¶

    • ✅ ADC는 연속적인 아날로그 신호를 0~1023 사이 숫자로 변환하는 과정이다
    • ✅ analogRead(핀) 함수로 아날로그 값을 읽고, if-else 로 상태를 판별할 수 있다
    • ✅ 조도 센서는 빛에 따라 저항이 변하는 소자로, 밝기를 숫자로 측정할 수 있게 해준다
