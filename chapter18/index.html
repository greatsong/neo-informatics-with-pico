    2단원 마무리 - 환경 모니터링 스테이션¶

    🎯 이 장의 학습 목표¶

    이 장을 마치면 다음을 할 수 있습니다:

    • [ ] 여러 센서를 하나의 프로그램에 통합하여 데이터를 수집할 수 있다
    • [ ] 수집한 데이터를 파일에 저장하고 불러올 수 있다
    • [ ] 데이터를 시각화하여 패턴과 인사이트를 도출할 수 있다
    • [ ] 환경 모니터링 스테이션을 완성하고 결과를 정리할 수 있다

    예상 학습 시간: 약 90분

    📚 미리 알아야 할 것¶

    2단원을 마무리하는 시간입니다! 지금까지 배운 내용을 간단히 되짚어 볼까요?

    배운 내용 핵심 키워드
    온습도 센서 (DHT11) temperature, humidity 읽기
    조도 센서 (CdS) 아날로그 값 → 밝기 측정
    시리얼 모니터 출력 print() / Serial.println()
    반복 측정 while 루프, time.sleep()

    💡 잠깐! 위 내용이 가물가물하다면, 이전 장들을 빠르게 훑어보고 오세요. 이번 장은 모든 것을 합치는 시간이니까요!

    💡 왜 이걸 배우나요?¶

    지금까지 센서를 하나씩 따로 사용해봤죠? 하지만 현실 세계에서는 여러 데이터를 동시에 수집합니다.

    기상청을 떠올려 보세요. 기상청은 온도만 측정하지 않습니다. 온도, 습도, 풍속, 강수량, 일조량을 한꺼번에 측정하고, 이 데이터를 시간순으로 기록해서, 패턴을 분석한 뒤 일기예보를 만들어냅니다.

    여러분도 지금 똑같은 일을 할 수 있습니다!

    flowchart LR A[🌡️ 온도 센서] --> D[📊 통합 수집] B[💧 습도 센서] --> D C[☀️ 조도 센서] --> D D --> E[💾 데이터 저장] E --> F[📈 시각화 & 분석] F --> G[💡 인사이트 도출] style D fill:#fff3e0,stroke:#f57c00 style F fill:#e8f5e9,stroke:#388e3c style G fill:#e3f2fd,stroke:#1976d2

    이번 장이 끝나면, 여러분은 미니 기상 관측소를 만든 셈이 됩니다. 멋지지 않나요? 🎉

    📚 핵심 개념¶

    개념 1: 센서 통합 — 여러 귀를 동시에 열기 👂¶

    비유: 여러분이 요리할 때를 생각해보세요. 타이머로 시간을 재면서, 온도계로 오븐 온도를 확인하고, 눈으로 음식 색깔도 봅니다. 여러 감각을 동시에 쓰는 것이죠.

    정확한 정의: 센서 통합이란, 여러 종류의 센서에서 데이터를 하나의 프로그램 안에서 순차적으로 읽어 하나의 데이터 세트로 묶는 것입니다.

    핵심 포인트: - 각 센서는 독립적으로 작동합니다 - 프로그램이 차례대로 각 센서를 읽습니다 - 읽은 값들을 하나의 묶음(레코드)으로 합칩니다

    # 개념 예시 (의사 코드)
while True:
    temp = read_temperature()    # 온도 읽기
    humi = read_humidity()       # 습도 읽기
    light = read_light()         # 조도 읽기

    record = [시간, temp, humi, light]  # 하나로 묶기!

    개념 2: 데이터 로깅 — 디지털 일기장 📓¶

    비유: 매일 일기를 쓰듯이, 센서가 측정한 값을 시간과 함께 기록하는 것을 데이터 로깅(logging)이라고 합니다.

    정확한 정의: 데이터 로깅은 센서 데이터를 타임스탬프(측정 시각)와 함께 파일에 순차적으로 저장하는 과정입니다.

    왜 파일에 저장하나요? - 시리얼 모니터 출력은 흘러가면 사라집니다 - 파일에 저장하면 나중에 다시 볼 수 있습니다 - 분석과 시각화가 가능해집니다

    📁 data.csv (저장된 파일 예시)
시간,       온도, 습도, 조도
09:00:00,  22.5, 45,  780
09:05:00,  22.8, 44,  820
09:10:00,  23.1, 43,  850
...

    CSV(Comma-Separated Values)란? 데이터를 쉼표로 구분해서 저장하는 간단한 파일 형식이에요. 엑셀에서도 바로 열 수 있답니다!

    개념 3: 데이터 시각화 — 숫자를 그림으로 📈¶

    비유: 성적표에 점수만 나열되어 있으면 변화를 파악하기 어렵죠? 하지만 그래프로 그리면 "아, 점수가 올라가고 있구나!"를 한눈에 알 수 있습니다.

    정확한 정의: 수집된 데이터를 그래프나 차트 형태로 변환하여, 사람이 패턴을 쉽게 인식할 수 있게 만드는 과정입니다.

    flowchart TD A["숫자 데이터<br/>22.5, 22.8, 23.1, 24.0, 23.5..."] B["📈 시각화"] C["인사이트!<br/>'오전에 온도가 올라가다가<br/>오후에 내려가는 패턴이구나!'"] A --> B --> C style A fill:#ffebee,stroke:#c62828 style B fill:#fff3e0,stroke:#f57c00 style C fill:#e8f5e9,stroke:#388e3c

    개념 4: 인사이트 도출 — 데이터가 들려주는 이야기 🔍¶

    비유: 탐정이 단서들을 모아 사건의 진실을 밝히듯, 우리는 데이터에서 의미 있는 발견을 찾아냅니다.

    정확한 정의: 인사이트란 데이터 분석을 통해 발견한 의미 있는 패턴이나 결론을 말합니다.

    예시: - "점심시간(12~13시)에 교실 온도가 2도 이상 내려간다" → 학생들이 나가서! - "오후 2시에 조도가 최고치를 찍는다" → 햇빛이 직접 들어오는 시간! - "습도가 40% 이하로 떨어지면 학생들이 목이 마르다고 한다" → 가습기 필요!

    💡 핵심: 데이터 자체는 그냥 숫자입니다. "그래서 뭐?"라는 질문에 답할 수 있어야 진짜 인사이트예요!

    🔨 따라하기: 환경 모니터링 스테이션 만들기¶

    Step 1: 회로 구성 — 모든 센서를 연결하기¶

    이전 장에서 배운 센서들을 모두 하나의 보드에 연결합니다.

    연결 구성:

    센서 연결 핀 역할
    DHT11 (온습도) 디지털 D4 온도 + 습도 측정
    CdS (조도) 아날로그 A0 밝기 측정

    ✅ 체크포인트: 두 센서가 모두 연결되었고, 보드에 전원이 들어오나요?

    Step 2: 통합 데이터 수집 코드 작성¶

    이제 두 센서를 하나의 프로그램에서 동시에 읽어봅시다.

    import time
import dht
import machine

# 센서 초기화
dht_sensor = dht.DHT11(machine.Pin(4))
light_sensor = machine.ADC(machine.Pin(36))  # A0

def read_all_sensors():
    """모든 센서를 한 번에 읽는 함수"""
    dht_sensor.measure()
    temp = dht_sensor.temperature()  # 온도 (°C)
    humi = dht_sensor.humidity()     # 습도 (%)
    light = light_sensor.read()      # 조도 (0~4095)
    return temp, humi, light

# 테스트: 한 번 읽어보기
temp, humi, light = read_all_sensors()
print(f"온도: {temp}°C, 습도: {humi}%, 조도: {light}")

    ✅ 체크포인트: 실행했을 때 온도, 습도, 조도 값이 모두 출력되나요?

    Step 3: 데이터를 파일에 저장하기 (로깅)¶

    측정 값을 CSV 파일에 차곡차곡 쌓아봅시다.

    import time

def save_to_file(filename, temp, humi, light):
    """측정값을 파일에 한 줄 추가"""
    timestamp = time.time()  # 현재 시간
    line = f"{timestamp},{temp},{humi},{light}\n"

    with open(filename, "a") as f:  # "a" = 추가 모드
        f.write(line)
    print(f"저장 완료: {line.strip()}")

# CSV 파일 헤더 만들기 (최초 1회만)
with open("env_data.csv", "w") as f:
    f.write("timestamp,temperature,humidity,light\n")

print("📁 데이터 파일 준비 완료!")

    "a" 모드가 뭔가요? - "w" = write, 파일을 새로 만듦 (기존 내용 삭제!) - "a" = append, 기존 파일 끝에 추가

    Step 4: 자동 반복 측정 실행¶

    일정 간격으로 계속 측정하고 저장하는 자동 모니터링을 시작합니다.

    # === 환경 모니터링 스테이션 메인 코드 ===

INTERVAL = 300  # 측정 간격: 300초 (5분)
FILENAME = "env_data.csv"

print("🏗️ 환경 모니터링 스테이션 시작!")
print(f"📊 {INTERVAL}초 간격으로 측정합니다.")
print("중지하려면 Ctrl+C를 누르세요.\n")

count = 0
try:
    while True:
        temp, humi, light = read_all_sensors()
        save_to_file(FILENAME, temp, humi, light)
        count += 1
        print(f"[{count}번째 측정] 🌡️{temp}°C 💧{humi}% ☀️{light}")
        time.sleep(INTERVAL)

except KeyboardInterrupt:
    print(f"\n⏹️ 모니터링 종료! 총 {count}회 측정 완료")
    print(f"📁 데이터가 '{FILENAME}'에 저장되었습니다.")

    💡 팁: 테스트할 때는 INTERVAL = 5 (5초)로 줄여서 빠르게 확인하세요. 실제 수집할 때 300(5분)으로 바꾸면 됩니다!

    ✅ 체크포인트: 5초 간격으로 3~4회 측정이 되고, "저장 완료" 메시지가 출력되나요?

    Step 5: 수집한 데이터 시각화하기¶

    데이터 수집이 끝났다면, 이제 그래프로 그려봅시다. (컴퓨터의 Python 환경에서 실행합니다)

    # 컴퓨터에서 실행 (matplotlib 필요)
# pip install matplotlib 으로 설치

import csv

    📝 전체 코드¶

    아래는 센서 수집 부분의 전체 코드입니다. 복사해서 바로 사용할 수 있어요.

    # ===================================
# 🏗️ 환경 모니터링 스테이션 v1.0
# ===================================

import time
import dht
import machine

# --- 센서 초기화 ---
dht_sensor = dht.DHT11(machine.Pin(4))
light_sensor = machine.ADC(machine.Pin(36))

# --- 설정 ---
INTERVAL = 300   # 측정 간격 (초) - 테스트시 5로 변경
FILENAME = "env_data.csv"

# --- 함수 정의 ---
def read_all_sensors():
    dht_sensor.measure()
    temp = dht_sensor.temperature()
    humi = dht_sensor.humidity()
    light = light_sensor.read()
    return temp, humi, light

def save_to_file(filename, temp, humi, light):
    timestamp = time.time()
    line = f"{timestamp},{temp},{humi},{light}\n"
    with open(filename, "a") as f:
        f.write(line)

# --- 파일 초기화 ---
with open(FILENAME, "w") as f:
    f.write("timestamp,temperature,humidity,light\n")

# --- 메인 루프 ---
print("🏗️ 환경 모니터링 스테이션 시작!")
count = 0

try:
    while True:
        temp, humi, light = read_all_sensors()
        save_to_file(FILENAME, temp, humi, light)
        count += 1
        print(f"[{count}] 🌡️{temp}°C 💧{humi}% ☀️{light}")
        time.sleep(INTERVAL)
except KeyboardInterrupt:
    print(f"\n⏹️ 종료! 총 {count}회 측정, '{FILENAME}'에 저장됨")

    ⚠️ 자주 하는 실수¶

    실수 1: 파일을 매번 "w" 모드로 열기¶

    # ❌ 잘못된 방법 — 매 측정마다 파일을 새로 만듦!
with open("data.csv", "w") as f:  # 이전 데이터 다 날아감!
    f.write(line)

# ✅ 올바른 방법 — 기존 데이터 뒤에 추가
with open("data.csv", "a") as f:  # "a" = append (추가)
    f.write(line)
    - 왜? "w"는 파일을 처음부터 다시 쓰기 때문에, 이전 데이터가 모두 삭제됩니다.

    실수 2: DHT11 센서를 너무 빠르게 읽기¶

    # ❌ 1초 간격 → 센서가 오류를 낼 수 있음
time.sleep(1)

# ✅ DHT11은 최소 2초 이상 간격 필요
time.sleep(2)  # 최소 간격
    - 왜? DHT11 센서는 내부적으로 데이터를 갱신하는 데 약 2초가 필요합니다.

    실수 3: 데이터 수집 중 보드 연결을 끊기¶

    # ❌ USB를 뽑으면 마지막 데이터가 저장 안 될 수 있음!

# ✅ 반드시 Ctrl+C로 프로그램을 먼저 종료
# try-except로 안전하게 종료 처리를 해두었으므로
# Ctrl+C만 누르면 됩니다!
    - 왜? 파일 쓰기 중 갑자기 전원이 끊기면 파일이 손상될 수 있어요.
