    Chapter 16: 데이터로 이야기 만들기¶

    🎯 이 장의 학습 목표¶

    이 장을 마치면 다음을 할 수 있습니다:

    • [ ] 수집한 데이터를 종합해 의미 있는 결론(인사이트)을 도출할 수 있다
    • [ ] 데이터 분석 결과를 다른 사람이 이해하기 쉬운 '이야기'로 전달할 수 있다

    예상 학습 시간: 약 40분

    📚 미리 알아야 할 것¶

    지난 장들에서 우리는 온도, 조도, CO₂ 등 교실 환경 데이터를 센서로 수집하고, 리스트에 저장하고, 평균이나 최댓값 같은 통계를 계산하는 방법을 배웠어요. 이번 장에서는 그 숫자들을 의미 있는 이야기로 바꾸는 마지막 단계를 다룹니다.

    📚 핵심 개념¶

    개념 1: 인사이트 — 숫자 속에 숨은 의미¶

    "인사이트는 마치 탐정이 단서에서 진실을 찾아내는 것과 같아요." 🔍

    범죄 현장에 지문, 발자국, CCTV 영상이 있다고 해볼게요. 이것들은 그냥 '단서(데이터)'일 뿐이에요. 탐정이 이 단서들을 연결해서 "범인은 오후 3시에 뒷문으로 들어왔다"라는 결론을 내리죠. 이 결론이 바로 인사이트입니다.

    인사이트(Insight): 데이터를 분석해서 발견한 의미 있는 패턴이나 결론. 단순한 숫자가 아니라 "그래서 어떻다"라는 해석이 담겨 있어요.

    예시로 확인해볼까요?

    데이터 (숫자) 인사이트 (이야기)
    오후 2시 CO₂: 1,200ppm "점심 후 환기 없이 수업하면 CO₂가 기준치를 초과해요"
    창가 조도: 800lux, 복도쪽: 200lux "복도쪽 학생들은 조명이 부족해 눈이 피로할 수 있어요"
    오전 9시 온도: 18°C "등교 직후 교실이 쌀쌀하니 미리 난방을 켜면 좋겠어요"

    숫자 자체는 이야기가 아니에요. "그래서 뭘 하면 좋을까?" 까지 이어져야 진짜 인사이트입니다.

    개념 2: 데이터 스토리텔링 — 숫자를 이야기로¶

    "데이터 스토리텔링은 마치 요리사가 재료를 맛있는 요리로 바꾸는 것과 같아요." 🍳

    좋은 재료(데이터)가 있어도 날것 그대로 내놓으면 아무도 맛있게 먹지 못해요. 누가 읽을지 생각하고, 핵심을 골라서, 순서대로 전달하는 것이 데이터 스토리텔링이에요.

    flowchart LR A["📊 데이터 수집"] --> B["🔍 패턴 발견"] B --> C["💡 인사이트 도출"] C --> D["📖 이야기로 전달"] style A fill:#e3f2fd,stroke:#1976d2 style B fill:#fff3e0,stroke:#f57c00 style C fill:#e8f5e9,stroke:#388e3c style D fill:#fce4ec,stroke:#c62828

    좋은 데이터 이야기에는 세 가지가 있어요:

    1. 현상: "무슨 일이 일어나고 있나?" → 오후 2시에 CO₂가 급증합니다
    2. 원인: "왜 그럴까?" → 점심 후 환기를 하지 않기 때문입니다
    3. 제안: "어떻게 하면 좋을까?" → 5교시 시작 전 5분 환기를 제안합니다

    💡 잠깐! 여기까지 이해가 잘 되셨나요? 핵심은 간단해요. 숫자 → 의미 → 행동으로 연결하는 거예요!

    🔨 따라하기: 교실 환경 보고서 만들기¶

    지금까지 수집했다고 가정한 교실 환경 데이터로 간단한 보고서를 자동 생성하는 프로그램을 만들어봐요.

    Step 1: 데이터 준비하기¶

    # 시간대별 교실 환경 데이터 (가상 데이터)
times = ["09:00", "10:00", "11:00", "12:00", "13:00", "14:00", "15:00"]
temp = [18, 20, 22, 23, 24, 26, 25]         # 온도(°C)
co2 = [450, 520, 680, 750, 950, 1200, 1050]  # CO₂(ppm)
light = [300, 450, 500, 520, 480, 400, 350]  # 조도(lux)

    실행 결과: 아직 출력은 없어요. 데이터를 변수에 담아둔 거예요.

    Step 2: 기본 통계 계산하기¶

    # 평균, 최대, 최소 계산
avg_temp = sum(temp) / len(temp)
max_co2 = max(co2)
max_co2_time = times[co2.index(max_co2)]
min_light = min(light)
min_light_time = times[light.index(min_light)]

print(f"평균 온도: {avg_temp:.1f}°C")
print(f"CO₂ 최고: {max_co2}ppm (시간: {max_co2_time})")
print(f"조도 최저: {min_light}lux (시간: {min_light_time})")

    실행 결과: 

    평균 온도: 22.6°C
CO₂ 최고: 1200ppm (시간: 14:00)
조도 최저: 300lux (시간: 09:00)

    ✅ 체크포인트: 숫자가 나왔죠? 하지만 이건 아직 '이야기'가 아니에요. 다음 단계에서 의미를 붙여볼게요!

    Step 3: 인사이트 도출 — 조건으로 판단하기¶

    # 기준값 설정
CO2_LIMIT = 1000    # ppm 이상이면 환기 필요
LIGHT_MIN = 400     # lux 미만이면 조명 부족
TEMP_HIGH = 25      # °C 이상이면 더움

# 문제 시간대 찾기
print("=== 🔍 발견한 문제 ===")

for i in range(len(times)):
    if co2[i] >= CO2_LIMIT:
        print(f"⚠️ {times[i]} - CO₂ {co2[i]}ppm → 환기가 필요해요!")
    if light[i] < LIGHT_MIN:
        print(f"💡 {times[i]} - 조도 {light[i]}lux → 조명이 부족해요!")
    if temp[i] >= TEMP_HIGH:
        print(f"🌡️ {times[i]} - 온도 {temp[i]}°C → 교실이 더워요!")

    실행 결과: 

    === 🔍 발견한 문제 ===
💡 09:00 - 조도 300lux → 조명이 부족해요!
⚠️ 14:00 - CO₂ 1200ppm → 환기가 필요해요!
🌡️ 14:00 - 온도 26°C → 교실이 더워요!
🌡️ 15:00 - 온도 25°C → 교실이 더워요!
💡 15:00 - 조도 350lux → 조명이 부족해요!
⚠️ 15:00 - CO₂ 1050ppm → 환기가 필요해요!

    숫자에 의미(판단)가 붙으니, 이제 이야기가 되기 시작했죠? 🎉

    Step 4: 보고서 자동 생성하기¶

    # 교실 환경 보고서 생성
print("=" * 40)
print("   📋 우리 교실 환경 보고서")
print("=" * 40)

print(f"\n📊 오늘의 요약")
print(f"  평균 온도: {avg_temp:.1f}°C")
print(f"  CO₂ 최고치: {max_co2}ppm ({max_co2_time})")
print(f"  조도 최저치: {min_light}lux ({min_light_time})")

print(f"\n💡 인사이트")
print(f"  1. 오후 2시~3시에 CO₂가 {CO2_LIMIT}ppm을 초과합니다.")
print(f"     → 점심 후 환기 없이 수업하면 공기가 탁해져요.")
print(f"  2. 오전 9시와 오후 3시에 조도가 {LIGHT_MIN}lux 미만입니다.")
print(f"     → 이 시간대에는 추가 조명이 필요해요.")

print(f"\n✅ 개선 제안")
print(f"  1. 5교시 시작 전 5분간 창문을 열어 환기하기")
print(f"  2. 아침 등교 시간과 오후에 보조 조명 켜기")
print(f"  3. 오후 수업 시 에어컨/선풍기 가동 검토")
print("=" * 40)

    실행 결과: 

    ========================================
   📋 우리 교실 환경 보고서
========================================

📊 오늘의 요약
  평균 온도: 22.6°C
  CO₂ 최고치: 1200ppm (14:00)
  조도 최저치: 300lux (09:00)

  2. 오전 9시와 오후 3시에 조도가 400lux 미만입니다.
     → 이 시간대에는 추가 조명이 필요해요.

✅ 개선 제안
  1. 5교시 시작 전 5분간 창문을 열어 환기하기
  2. 아침 등교 시간과 오후에 보조 조명 켜기
  3. 오후 수업 시 에어컨/선풍기 가동 검토
========================================

    💡 여기서 핵심! 같은 데이터인데, "1200ppm"이라고만 말하는 것보다 "환기가 필요하다"고 말하는 게 훨씬 강력하죠? 이것이 데이터 스토리텔링의 힘이에요!

    📝 전체 코드¶

    # === 교실 환경 보고서 생성 프로그램 ===

# 1. 데이터
times = ["09:00", "10:00", "11:00", "12:00", "13:00", "14:00", "15:00"]
temp = [18, 20, 22, 23, 24, 26, 25]
co2 = [450, 520, 680, 750, 950, 1200, 1050]
light = [300, 450, 500, 520, 480, 400, 350]

# 2. 통계 계산
avg_temp = sum(temp) / len(temp)
max_co2 = max(co2)
max_co2_time = times[co2.index(max_co2)]
min_light = min(light)
min_light_time = times[light.index(min_light)]

# 3. 기준값
CO2_LIMIT = 1000
LIGHT_MIN = 400
TEMP_HIGH = 25

# 4. 보고서 출력
print("=" * 40)
print("   📋 우리 교실 환경 보고서")
print("=" * 40)
print(f"\n📊 오늘의 요약")
print(f"  평균 온도: {avg_temp:.1f}°C")
print(f"  CO₂ 최고치: {max_co2}ppm ({max_co2_time})")
print(f"  조도 최저치: {min_light}lux ({min_light_time})")

print(f"\n🔍 문제 시간대")
for i in range(len(times)):
    if co2[i] >= CO2_LIMIT:
        print(f"  ⚠️ {times[i]} - CO₂ {co2[i]}ppm → 환기 필요")
    if light[i] < LIGHT_MIN:
        print(f"  💡 {times[i]} - 조도 {light[i]}lux → 조명 부족")

print(f"\n✅ 개선 제안")
print(f"  1. 5교시 전 5분 환기")
print(f"  2. 아침/오후 보조 조명 켜기")
print("=" * 40)

    ⚠️ 주의할 점¶

    1. 숫자만 나열하지 마세요: "CO₂: 1200"보다 "CO₂가 기준을 넘어서 환기가 필요합니다"가 훨씬 효과적이에요. 항상 "그래서?"라고 스스로에게 물어보세요.

    2. 기준값은 상황에 맞게 조정하세요: 위 코드의 CO2_LIMIT = 1000은 일반적인 권장 기준이에요. 여러분의 환경에 맞게 바꿔도 괜찮아요.

    ✅ 점검하기¶

    1. "인사이트"란 무엇인가요?

    정답 확인 데이터를 분석해서 발견한 의미 있는 패턴이나 결론이에요. 단순한 숫자가 아니라 "그래서 어떻다, 이렇게 하면 좋겠다"라는 해석이 담겨 있는 것입니다.

    2. 좋은 데이터 이야기의 세 가지 요소는?

    정답 확인 ① 현상 (무슨 일이 일어나고 있나) → ② 원인 (왜 그럴까) → ③ 제안 (어떻게 하면 좋을까)
