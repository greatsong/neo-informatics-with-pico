    챕터 28: 디버깅 - 버그 찾고 해결하기 🐛¶

    🎯 이 장의 학습 목표¶

    이 장을 마치면 다음을 할 수 있습니다:

    • [ ] 오류 메시지를 읽고 원인을 파악할 수 있다
    • [ ] print()를 활용해 버그를 찾아 해결할 수 있다

    예상 학습 시간: 약 40분

    📚 미리 알아야 할 것¶

    • 변수, 조건문, 반복문의 기본 사용법
    • 함수를 정의하고 호출하는 방법

    📚 핵심 개념¶

    개념 1: 버그와 오류 메시지 읽기¶

    "버그"는 마치 요리 레시피에 잘못된 단계가 끼어든 것과 같아요. 설탕을 넣어야 하는데 소금을 넣으면 결과물이 이상해지죠? 코드에서도 마찬가지입니다.

    다행히 파이썬은 문제가 생기면 오류 메시지를 보여줍니다. 이 메시지는 "여기가 문제예요!"라고 알려주는 친절한 안내판이에요.

    가장 자주 만나는 오류 3가지:

    • SyntaxError (문법 오류): 파이썬이 이해할 수 없는 문법을 썼을 때. 마치 "나는 학교 간다를"처럼 문장 구조가 틀린 경우예요.
    • NameError (이름 오류): 정의하지 않은 변수를 사용했을 때. 존재하지 않는 사람을 부르는 것과 같아요.
    • TypeError (타입 오류): 서로 맞지 않는 타입을 연산했을 때. 숫자와 문자를 더하려는 것처럼요.

    💡 핵심 포인트! 오류 메시지는 적이 아니라 친구예요. 메시지의 마지막 줄을 먼저 읽으면 무슨 오류인지 바로 알 수 있습니다!

    flowchart TD A["❌ 오류 발생!"] --> B["마지막 줄 확인"] B --> C{"오류 종류는?"} C -->|SyntaxError| D["괄호, 콜론, 따옴표 확인"] C -->|NameError| E["변수명 오타 확인"] C -->|TypeError| F["데이터 타입 확인"] D --> G["✅ 수정 후 다시 실행"] E --> G F --> G

    개념 2: print() 디버깅¶

    오류 메시지 없이 프로그램이 실행은 되지만 결과가 이상할 때가 있어요. 이때는 마치 탐정처럼 중간중간 단서를 남겨야 합니다.

    print()는 코드 중간에 넣어서 "지금 이 변수에 뭐가 들어있지?"를 확인하는 도구예요. X레이처럼 코드 내부를 들여다보는 거죠.

    # print() 디버깅 기본 패턴
print("=== 여기 도착 ===")        # 실행 흐름 확인
print(f"변수값: {변수이름}")        # 변수 내용 확인

    🔨 따라하기: 버그 사냥꾼 되기¶

    Step 1: SyntaxError 해결하기¶

    아래 코드에는 버그가 있어요. 먼저 실행해보세요.

    코드 (버그 있는 버전): 

    name = "파이썬"
print("안녕하세요, " + name

    실행 결과: 

    SyntaxError: unexpected EOF while parsing

    오류 메시지가 "예상치 못한 파일 끝"이라고 하네요. 괄호를 닫지 않았어요!

    수정된 코드: 

    name = "파이썬"
print("안녕하세요, " + name)  # 닫는 괄호 추가!

    실행 결과: 

    안녕하세요, 파이썬

    ✅ 체크포인트: SyntaxError가 사라지고 정상 출력되면 성공!

    Step 2: NameError 해결하기¶

    코드 (버그 있는 버전): 

    score = 85
print("당신의 점수는 " + str(scroe) + "점입니다")

    실행 결과: 

    NameError: name 'scroe' is not defined

    scroe라는 변수는 없다고 하네요. 자세히 보면 score를 scroe로 잘못 썼어요!

    수정된 코드: 

    score = 85
print("당신의 점수는 " + str(score) + "점입니다")

    💡 잠깐! 여기까지 이해가 잘 되셨나요? 오류 메시지의 마지막 줄만 읽으면 힌트를 얻을 수 있다는 감이 오시나요? 천천히 한 번 더 읽어봐도 괜찮아요!

    Step 3: print()로 논리 오류 찾기¶

    이번에는 오류 메시지가 안 뜨지만 결과가 틀린 경우예요. 1부터 5까지 합을 구하려는 코드입니다.

    코드 (버그 있는 버전): 

    total = 0
for i in range(5):
    total = i

print(f"1부터 5까지의 합: {total}")

    실행 결과: 

    1부터 5까지의 합: 4

    15가 나와야 하는데 4가 나왔어요! print()를 넣어서 원인을 찾아봅시다.

    디버깅용 코드: 

    total = 0
for i in range(5):
    total = i
    print(f"i={i}, total={total}")  # 디버깅용 print

print(f"1부터 5까지의 합: {total}")

    실행 결과: 

    i=0, total=0
i=1, total=1
i=2, total=2
i=3, total=3
i=4, total=4
1부터 5까지의 합: 4

    발견! total = i는 더하는 게 아니라 덮어쓰기를 하고 있었어요. 그리고 range(5)는 0부터 4까지이니 range(1, 6)으로 바꿔야 해요.

    수정된 코드: 

    total = 0
for i in range(1, 6):    # 1부터 5까지
    total = total + i     # 더하기로 수정!

print(f"1부터 5까지의 합: {total}")

    실행 결과: 

    1부터 5까지의 합: 15

    ✅ 체크포인트: 15가 출력되면 성공! 디버깅용 print는 문제를 찾은 후 삭제하면 됩니다.

    📝 전체 코드: 버그 찾기 도전!¶

    아래 코드에는 3개의 버그가 숨어있어요. 직접 찾아보세요!

    # 학생 성적 등급 계산기 (버그 3개 숨어있음!)
def get_grade(score)
    if score >= 90:
        grade = "A"
    elif score >= 80:
        grade = "B"
    elif score >= 70:
        grade = "C"
    else:
        grade = "F"
    return grade

student_score = "85"
result = get_grade(student_score)
pritn(f"성적: {result}")

    힌트: 1. 함수 정의 문법을 확인해보세요 (SyntaxError) 2. student_score의 타입이 뭔가요? (TypeError) 3. 마지막 줄을 잘 살펴보세요 (NameError)

    정답 확인 
    # 수정된 코드
def get_grade(score):          # 버그1: 콜론(:) 빠짐
    if score >= 90:
        grade = "A"
    elif score >= 80:
        grade = "B"
    elif score >= 70:
        grade = "C"
    else:
        grade = "F"
    return grade

student_score = 85             # 버그2: "85"(문자) → 85(숫자)
result = get_grade(student_score)
print(f"성적: {result}")        # 버그3: pritn → print

    ⚠️ 주의할 점¶

    • 오류 메시지를 무시하지 마세요! 당황하지 말고 마지막 줄부터 차분히 읽으면 답이 보입니다. 줄 번호도 함께 알려주니 해당 줄 근처를 먼저 확인하세요.
    • 디버깅용 print()는 반드시 나중에 지우세요! 문제를 해결한 뒤 남겨두면 불필요한 출력이 쏟아져 나옵니다.

    ✅ 점검하기¶

    1. 다음 오류 메시지가 뜨면 어디를 확인해야 할까요? 

    NameError: name 'mesage' is not defined

    정답 확인 `mesage`라는 변수가 정의되지 않았다는 뜻이에요. 아마 `message`를 `mesage`로 오타 낸 것! 변수명 철자를 확인하면 됩니다.

    2. 프로그램이 실행은 되지만 결과가 이상할 때, 어떻게 원인을 찾나요?

    정답 확인 의심되는 위치에 `print()`를 넣어 변수의 중간값을 확인합니다. 예상과 다른 값이 나오는 지점이 바로 버그의 원인입니다!

    3. SyntaxError가 발생하면 가장 먼저 확인할 것은?

    정답 확인 괄호 짝이 맞는지, 콜론(:)을 빼먹지 않았는지, 따옴표를 제대로 닫았는지 확인합니다. 오류 메시지가 가리키는 줄 번호 근처를 살펴보세요.
