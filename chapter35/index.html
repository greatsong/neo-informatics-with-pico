    대시보드 디자인과 CSS 기초¶

    🎯 이 장의 학습 목표¶

    • [ ] CSS가 무엇인지 이해하고, 웹페이지 스타일을 변경할 수 있다
    • [ ] AI에게 디자인 수정을 요청하여 대시보드를 꾸밀 수 있다

    예상 학습 시간: 약 40분

    📚 미리 알아야 할 것¶

    이전 장에서 Flask로 센서 데이터를 웹페이지에 표시하는 방법을 배웠어요. 지금 우리의 대시보드는 아마 이런 모습일 거예요 — 흰 배경에 검은 글씨만 나열된, 좀 밋밋한 페이지요. 이번 장에서는 이 페이지에 옷을 입혀 멋진 대시보드로 변신시켜 봅니다! 🎨

    📚 핵심 개념¶

    개념 1: CSS — 웹페이지의 옷¶

    HTML이 웹페이지의 뼈대(내용과 구조)라면, CSS는 웹페이지의 옷(색상, 크기, 배치)이에요.

    🏠 비유해볼게요. 집을 짓는다고 상상해보세요. - HTML = 벽, 지붕, 방 같은 구조물 - CSS = 벽지 색상, 가구 배치, 조명 같은 인테리어

    같은 구조의 집이라도 인테리어에 따라 완전히 다른 분위기가 되죠!

    CSS는 Cascading Style Sheets의 약자인데, 이름은 외울 필요 없어요. "스타일을 지정하는 도구"라고만 기억하세요.

    CSS의 기본 문법은 이렇게 생겼어요:

    선택자 {
    속성: 값;
}

    예를 들어, 페이지 배경을 어두운 색으로 바꾸고 싶다면:

    body {
    background-color: #1a1a2e;
    color: white;
}
    • body → 선택자: "body 태그를 꾸밀 거야"
    • background-color → 속성: "배경색을"
    • #1a1a2e → 값: "이 색상으로 바꿔"

    개념 2: 카드 디자인 — 정보를 보기 좋게 묶기¶

    대시보드에서 가장 많이 쓰이는 디자인 패턴이 바로 카드(Card) 에요. 센서값 하나하나를 깔끔한 상자 안에 넣는 방식이죠.

    flowchart LR A["밋밋한 텍스트 나열"] -->|CSS 카드 적용| B["📦 온도: 25°C\n📦 습도: 60%\n📦 조도: 850"] style A fill:#ffcdd2,stroke:#c62828 style B fill:#c8e6c9,stroke:#2e7d32

    카드 디자인의 핵심 CSS 속성 3가지만 기억하세요:

    • background-color — 카드 배경색
    • border-radius — 모서리를 둥글게
    • padding — 내용물과 테두리 사이의 여백 (카드 안쪽 공간)

    💡 잠깐! 여기까지 이해가 잘 되셨나요? CSS는 결국 "어디를(선택자) 어떻게(속성: 값) 꾸밀지" 알려주는 거예요. 이것만 기억하면 충분합니다!

    🔨 따라하기¶

    밋밋한 대시보드를 카드형 대시보드로 변신시켜 봅시다!

    Step 1: AI에게 디자인 요청하기¶

    Claude에게 이렇게 요청해보세요:

    Flask 대시보드의 HTML 템플릿을 만들어줘.
- 어두운 배경에 밝은 카드 형태로 센서값 표시
- 온도, 습도, 조도 3개의 카드를 가로로 배치
- 깔끔하고 현대적인 느낌으로
- CSS는 HTML 파일 안에 <style> 태그로 포함

    ✅ 포인트: AI에게 구체적으로 요청할수록 원하는 결과를 얻을 수 있어요. "예쁘게 해줘"보다 "어두운 배경, 밝은 카드"처럼 구체적으로!

    Step 2: AI가 만들어준 코드 확인하기¶

    AI가 대략 이런 형태의 코드를 만들어줄 거예요. templates/dashboard.html 파일로 저장하세요:

    <!DOCTYPE html>
<html>
<head>
    <title>내 센서 대시보드</title>
    <style>
        /* 전체 페이지 스타일 */
        body {
            background-color: #1a1a2e;
            color: white;
            font-family: sans-serif;
            display: flex;
            justify-content: center;
            padding: 40px;
        }

        /* 카드 컨테이너 */
        .card-container {
            display: flex;
            gap: 20px;
        }

        /* 개별 카드 */
        .card {
            background-color: #16213e;
            border-radius: 12px;
            padding: 30px;
            width: 200px;
            text-align: center;
        }

        .card h2 {
            font-size: 2em;
            margin: 10px 0;
            color: #00d2ff;
        }
    </style>
</head>
<body>
    <div class="card-container">
        <div class="card">
            <p>🌡️ 온도</p>
            <h2>{{ temperature }}°C</h2>
        </div>
        <div class="card">
            <p>💧 습도</p>
            <h2>{{ humidity }}%</h2>
        </div>
        <div class="card">
            <p>☀️ 조도</p>
            <h2>{{ light }}</h2>
        </div>
    </div>
</body>
</html>

    Step 3: Flask 코드에서 데이터 전달하기¶

    app.py를 다음과 같이 작성하세요:

    from flask import Flask, render_template

app = Flask(__name__)

@app.route('/')
def dashboard():
    # 테스트용 데이터 (나중에 실제 센서로 교체)
    return render_template('dashboard.html',
        temperature=25.3,
        humidity=62,
        light=850
    )

if __name__ == '__main__':
    app.run(debug=True)

    Step 4: 실행하고 확인하기¶

    터미널에서 실행합니다:

    python app.py

    브라우저에서 http://127.0.0.1:5000에 접속하면 어두운 배경 위에 카드 3개가 나란히 보일 거예요!

    ✅ 체크포인트: 어두운 배경에 파란빛 숫자가 적힌 카드 3개가 보이면 성공이에요!

    Step 5: 직접 스타일 수정해보기¶

    이제 CSS 값을 직접 바꿔보세요. <style> 안의 값만 수정하면 됩니다:

    /* 카드 배경색 바꿔보기 */
.card {
    background-color: #2d3436;  /* ← 다른 색으로 변경 */
    border-radius: 20px;        /* ← 숫자를 키우면 더 둥글게 */
    padding: 40px;              /* ← 숫자를 키우면 여백이 넓어짐 */
}

/* 숫자 색상 바꿔보기 */
.card h2 {
    color: #ff6b6b;  /* ← 빨간 계열로 변경 */
}

    저장 후 브라우저를 새로고침하면 바로 변경사항이 보여요!

    💡 팁: 색상 코드가 어렵다면 AI에게 "따뜻한 느낌의 색상 코드 추천해줘"라고 물어보세요. 또는 "색상을 초록 계열로 바꿔줘"라고 코드 수정을 요청할 수도 있어요.

    📝 전체 코드¶

    폴더 구조: 

    my_dashboard/
  ├── app.py
  └── templates/
      └── dashboard.html

    app.py와 dashboard.html은 Step 2, 3의 코드를 그대로 사용하시면 됩니다. 복사해서 바로 실행 가능해요!

    ⚠️ 주의할 점¶

    CSS 속성 뒤에 세미콜론(;)을 빼먹지 마세요!

    /* ❌ 세미콜론 누락 - 스타일이 깨져요 */
.card {
    background-color: #16213e
    padding: 30px
}

/* ✅ 올바른 작성 */
.card {
    background-color: #16213e;
    padding: 30px;
}

    세미콜론 하나 빠져도 그 아래 스타일이 전부 무시될 수 있으니, 꼭 확인하세요!

    ✅ 점검하기¶

    1. CSS의 역할은 무엇인가요?

    정답 확인 웹페이지의 **스타일(디자인)** 을 담당합니다. 색상, 크기, 배치, 여백 등 보이는 모습을 꾸미는 역할이에요. HTML이 구조라면, CSS는 그 구조에 입히는 옷입니다.

    2. AI에게 디자인을 요청할 때 더 좋은 결과를 얻으려면 어떻게 해야 하나요?

    정답 확인 "예쁘게 해줘"처럼 막연하게 요청하지 말고, **"어두운 배경, 카드 형태, 가로 배치"** 처럼 구체적인 디자인 요소를 설명해야 해요. 색상, 배치, 크기 등을 명확히 알려줄수록 좋습니다.

    3. border-radius: 12px;는 어떤 효과를 주나요?

    정답 확인 카드(상자)의 **모서리를 둥글게** 만들어 줍니다. 숫자가 클수록 더 둥글어지고, 0이면 각진 모서리가 됩니다.
