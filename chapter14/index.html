    Chapter 14. 여러 센서 데이터 비교 분석하기¶

    🎯 이 장의 학습 목표¶

    이 장을 마치면 다음을 할 수 있습니다:

    • [ ] 두 개의 센서 데이터를 동시에 수집하고 비교할 수 있다
    • [ ] 데이터 간의 상관관계를 발견하고 해석할 수 있다

    ⏱️ 예상 학습 시간: 약 40분

    📚 미리 알아야 할 것¶

    이전 장들에서 배운 내용을 간단히 복습할게요:

    • 센서 데이터 수집: 온도·조도 등 센서에서 값을 읽는 방법
    • 리스트에 데이터 저장: 여러 값을 append()로 모으는 방법
    • 반복문: for, while로 반복 작업하기

    위 내용이 기억나지 않으면 앞 장을 잠깐 훑어보고 오셔도 괜찮아요! 😊

    📚 핵심 개념¶

    개념 1: 동시 측정 — 같은 시간에 여러 값을 재야 비교할 수 있다¶

    비유로 시작할게요. 🏥

    병원에서 건강검진을 떠올려 보세요. 의사 선생님이 혈압만 재고 끝내지 않죠? 같은 날, 같은 시간에 혈압·혈당·체온을 함께 측정합니다. 그래야 "혈압이 높을 때 혈당도 높은가?"를 확인할 수 있으니까요.

    정확한 정의:

    동시 측정이란, 같은 시점에 두 개 이상의 서로 다른 값을 함께 기록하는 것을 말합니다.

    예시로 확인: | 시각 | 온도(°C) | 조도(lux) | |------|---------|----------| | 09:00 | 22 | 300 | | 10:00 | 25 | 650 | | 11:00 | 28 | 900 |

    이렇게 같은 시각에 측정한 두 값을 나란히 놓아야 비교가 가능합니다.

    개념 2: 상관관계 — "함께 움직이는가?"¶

    비유로 시작할게요. 🍦☀️

    여름에 기온이 올라가면 아이스크림 판매량도 올라가죠? 이처럼 하나가 변할 때 다른 하나도 함께 변하는 관계를 상관관계라고 합니다.

    정확한 정의:

    상관관계(Correlation) 란, 두 데이터가 함께 증가하거나 함께 감소하는 등의 경향성을 보이는 관계입니다.

    세 가지 유형:

    flowchart LR A["☀️ 조도 ↑<br>🌡️ 온도 ↑"] -->|"함께 증가"| B["📈 양의 상관관계"] C["🏃 운동량 ↑<br>⚖️ 체중 ↓"] -->|"반대로 변화"| D["📉 음의 상관관계"] E["👟 신발 크기 ↑<br>📊 수학 점수 ?"] -->|"관련 없음"| F["➖ 상관관계 없음"]

    💡 잠깐! 상관관계가 있다고 해서 반드시 "원인과 결과"는 아니에요. 아이스크림 판매량이 늘어도 아이스크림이 기온을 올리는 건 아니잖아요? 😄

    🔨 따라하기¶

    시나리오: "햇빛이 강해지면 온도도 올라갈까?" 라는 가설을 세우고, 데이터로 검증해 봅시다!

    실제 센서가 없어도 괜찮아요. 시뮬레이션 데이터로 똑같이 연습할 수 있습니다.

    Step 1: 센서 데이터 동시 수집하기¶

    먼저 같은 시각에 온도와 조도를 함께 기록하는 코드를 만들어 볼게요.

    코드: 

    import random

# 시간대별 데이터를 저장할 리스트
times = []
temperatures = []
lights = []

# 09시 ~ 17시까지 1시간 간격으로 측정 (시뮬레이션)
for hour in range(9, 18):
    base_light = 200 + (hour - 9) * 80 - abs(hour - 13) * 60
    light = max(100, base_light + random.randint(-30, 30))
    temp = 18 + light / 100 + random.uniform(-1, 1)

    times.append(f"{hour}:00")
    lights.append(round(light))
    temperatures.append(round(temp, 1))

# 수집한 데이터 출력
print("시각\t조도(lux)\t온도(°C)")
print("-" * 35)
for i in range(len(times)):
    print(f"{times[i]}\t{lights[i]}\t\t{temperatures[i]}")

    실행 결과 (예시): 

    시각  조도(lux) 온도(°C)
-----------------------------------

10:00   298     21.1

    ✅ 체크포인트: 시각·조도·온도가 표로 깔끔하게 출력되면 성공입니다!

    Step 2: 데이터 비교하여 상관관계 확인하기¶

    이제 두 데이터가 함께 움직이는지 간단한 계산으로 확인해 봅시다.

    코드: 

    # 함께 증가/감소하는 횟수 세기
same_direction = 0  # 같은 방향으로 변한 횟수
total_changes = 0   # 전체 변화 횟수

for i in range(1, len(times)):
    light_change = lights[i] - lights[i - 1]
    temp_change = temperatures[i] - temperatures[i - 1]

    if light_change != 0 and temp_change != 0:
        total_changes += 1
        # 둘 다 증가하거나 둘 다 감소하면 같은 방향
        if (light_change > 0 and temp_change > 0) or \
           (light_change < 0 and temp_change < 0):
            same_direction += 1

# 결과 해석
if total_changes > 0:
    ratio = same_direction / total_changes * 100
    print(f"\n전체 {total_changes}번의 변화 중 {same_direction}번 같은 방향")
    print(f"일치율: {ratio:.0f}%")

    if ratio >= 70:
        print("→ 📈 양의 상관관계가 있어 보입니다!")
        print("→ 가설 '햇빛이 강해지면 온도도 오른다' 지지됨 ✅")
    elif ratio <= 30:
        print("→ 📉 음의 상관관계가 있어 보입니다!")
    else:
        print("→ ➖ 뚜렷한 상관관계가 보이지 않습니다.")

    실행 결과 (예시): 

    전체 8번의 변화 중 8번 같은 방향
일치율: 100%

→ 가설 '햇빛이 강해지면 온도도 오른다' 지지됨 ✅

    💡 여기까지 잘 따라오셨나요? 핵심은 단순합니다 — 조도가 올라갈 때 온도도 올라가면 "같은 방향", 반대면 "다른 방향"으로 세는 거예요!

    📝 전체 코드¶

    import random

# === 1. 데이터 동시 수집 ===
times = []
temperatures = []
lights = []

for hour in range(9, 18):
    base_light = 200 + (hour - 9) * 80 - abs(hour - 13) * 60
    light = max(100, base_light + random.randint(-30, 30))
    temp = 18 + light / 100 + random.uniform(-1, 1)

    times.append(f"{hour}:00")
    lights.append(round(light))
    temperatures.append(round(temp, 1))

# === 2. 데이터 출력 ===

print("-" * 35)
for i in range(len(times)):
    print(f"{times[i]}\t{lights[i]}\t\t{temperatures[i]}")

# === 3. 상관관계 분석 ===
same_direction = 0
total_changes = 0

for i in range(1, len(times)):
    light_change = lights[i] - lights[i - 1]
    temp_change = temperatures[i] - temperatures[i - 1]

    if light_change != 0 and temp_change != 0:
        total_changes += 1
        if (light_change > 0 and temp_change > 0) or \
           (light_change < 0 and temp_change < 0):
            same_direction += 1

if total_changes > 0:
    ratio = same_direction / total_changes * 100
    print(f"\n일치율: {ratio:.0f}%")
    if ratio >= 70:
        print("→ 📈 양의 상관관계 — 가설 지지됨 ✅")
    elif ratio <= 30:
        print("→ 📉 음의 상관관계")
    else:
        print("→ ➖ 뚜렷한 상관관계 없음")

    ⚠️ 주의할 점¶

    1. 동시에 측정해야 합니다! 온도를 아침에, 조도를 저녁에 재면 비교가 무의미해요. 반드시 같은 시점에 함께 기록하세요.

    2. 상관관계 ≠ 인과관계 "함께 변한다"는 것이 "A가 B를 일으킨다"는 뜻은 아닙니다. 예를 들어, 아이스크림 판매량과 익사 사고 건수는 함께 증가하지만 아이스크림이 익사를 일으키는 건 아니에요. 둘 다 더운 날씨라는 공통 원인 때문이죠.

    ✅ 점검하기¶

    1. "동시 측정"은 왜 중요한가요?

    정답 확인 같은 시점에 측정해야 두 값 사이의 관계를 정확히 비교할 수 있기 때문입니다. 시간이 다르면 환경이 달라져 비교 자체가 의미 없어집니다.

    2. 조도가 올라갈 때 온도도 올라간다면, 이것은 어떤 상관관계인가요?

    정답 확인 양의 상관관계입니다. 두 값이 같은 방향(함께 증가)으로 움직이기 때문입니다.

    3. "상관관계가 있으면 반드시 인과관계도 있다" — 맞을까요?

    정답 확인 아닙니다! 상관관계는 "함께 변하는 경향"일 뿐, 하나가 다른 하나의 원인이라는 뜻은 아닙니다.
