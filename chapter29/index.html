    도전! 나만의 알고리즘 설계하기¶

    🎯 이 장의 학습 목표¶

    • [ ] 설계한 알고리즘을 의사코드와 파이썬 코드로 구현할 수 있다
    • 예상 학습 시간: 약 40분

    📚 미리 알아야 할 것¶

    • 순서도와 의사코드로 알고리즘을 표현하는 방법 (이전 장에서 학습)
    • 조건문(if), 반복문(for/while), 리스트 기본 사용법

    📚 핵심 개념¶

    개념 1: 알고리즘 설계 프로세스¶

    알고리즘 설계는 마치 요리 레시피를 직접 만드는 것과 같아요. 지금까지는 다른 사람이 만든 레시피를 따라했다면, 이제는 "이 재료로 어떤 요리를 만들까?"부터 스스로 결정하는 거예요.

    알고리즘 설계에는 정해진 4단계 프로세스가 있습니다.

    flowchart LR A["🔍 1단계\n문제 분석"] --> B["📝 2단계\n설계"] B --> C["💻 3단계\n구현"] C --> D["🧪 4단계\n테스트"] D -->|"문제 발견!"| B style A fill:#e3f2fd,stroke:#1976d2 style B fill:#fff3e0,stroke:#f57c00 style C fill:#e8f5e9,stroke:#388e3c style D fill:#fce4ec,stroke:#c62828
    • 1단계 문제 분석: 입력은 뭐지? 출력은 뭐지? 조건은?
    • 2단계 설계: 의사코드나 순서도로 풀이 과정을 정리
    • 3단계 구현: 설계를 실제 코드로 변환
    • 4단계 테스트: 여러 입력값으로 결과 확인, 문제가 있으면 2단계로 돌아가기

    개념 2: 같은 문제, 다른 해결책¶

    프로그래밍의 매력적인 점은 같은 문제라도 여러 가지 방법으로 풀 수 있다는 것입니다. 마치 집에서 학교까지 가는 길이 여러 개인 것처럼요.

    어떤 방법이 더 좋은지는 상황에 따라 달라집니다. 코드가 짧은 게 좋을 수도, 이해하기 쉬운 게 좋을 수도 있어요. 중요한 건 "내가 이해하고, 정확하게 동작하는 알고리즘"을 만드는 것입니다!

    🔨 따라하기: 도전 과제¶

    아래 3가지 중 하나를 선택해서 직접 알고리즘을 설계해봅시다. 이 실습에서는 "최대공약수 구하기"를 예시로 함께 풀어볼게요. 나머지 두 문제는 여러분이 도전해보세요!

    • 도전 A: 두 수의 최대공약수 구하기 ⬅️ 함께 풀어봐요!
    • 도전 B: 문자열에서 가장 많이 등장하는 글자 찾기
    • 도전 C: 숫자 리스트에서 두 번째로 큰 수 찾기

    Step 1: 문제 분석하기 🔍¶

    먼저 문제를 꼼꼼히 분석합니다. 세 가지 질문에 답해보세요.

    • 입력: 두 개의 자연수 (예: 12, 8)
    • 출력: 두 수의 최대공약수 (예: 4)
    • 조건: 두 수 모두 1 이상의 자연수

    💡 잠깐! 최대공약수(GCD)란 두 수를 동시에 나눌 수 있는 가장 큰 수예요. 12와 8을 동시에 나눌 수 있는 수는 1, 2, 4인데, 가장 큰 건 4이죠!

    Step 2: 의사코드로 설계하기 📝¶

    코드를 바로 쓰지 않고, 우리말로 풀이 과정을 먼저 적어봅니다.

    [방법 1: 하나씩 확인하기]
1. 두 수 a, b를 입력받는다
2. 둘 중 작은 수를 찾는다 → min_val
3. min_val부터 1까지 거꾸로 반복한다:
   4. 만약 a를 i로 나눈 나머지가 0이고,
      b를 i로 나눈 나머지도 0이면:
      5. i가 최대공약수! → 출력하고 멈춘다

    ✅ 체크포인트: 의사코드는 정해진 형식이 없어요. 내가 이해할 수 있으면 충분합니다!

    Step 3: 파이썬 코드로 구현하기 💻¶

    의사코드를 한 줄씩 코드로 바꿔봅시다.

    # 1. 두 수 입력받기
a = int(input("첫 번째 수: "))
b = int(input("두 번째 수: "))

# 2. 둘 중 작은 수 찾기
min_val = min(a, b)

# 3. 작은 수부터 1까지 거꾸로 확인
for i in range(min_val, 0, -1):
    # 4. 두 수 모두 나누어떨어지면?
    if a % i == 0 and b % i == 0:
        # 5. 최대공약수 발견!
        print(f"{a}와 {b}의 최대공약수: {i}")
        break  # 찾았으니 반복 종료

    실행 결과: 

    첫 번째 수: 12
두 번째 수: 8
12와 8의 최대공약수: 4

    Step 4: 테스트하기 🧪¶

    여러 값을 넣어서 확인해봅시다.

    • 12, 8 → 4 ✅
    • 15, 10 → 5 ✅
    • 7, 3 → 1 ✅ (서로소인 경우)
    • 9, 9 → 9 ✅ (같은 수인 경우)

    Step 5: 다른 방법으로도 풀어보기 🔄¶

    같은 문제를 유클리드 호제법으로도 풀 수 있어요.

    # 유클리드 호제법: 나머지가 0이 될 때까지 나누기 반복
a = int(input("첫 번째 수: "))
b = int(input("두 번째 수: "))

x, y = a, b  # 원래 값 보관
while b != 0:
    a, b = b, a % b  # 핵심: b와 나머지를 교체

print(f"{x}와 {y}의 최대공약수: {a}")

    실행 결과: 

    첫 번째 수: 12
두 번째 수: 8
12와 8의 최대공약수: 4

    💡 두 방법 모두 정답이에요! 방법 1은 직관적이고, 방법 2는 큰 수에서 훨씬 빠릅니다. 이것이 바로 "같은 문제, 다른 해결책"이에요!

    📝 전체 코드¶

    # === 나만의 알고리즘: 최대공약수 구하기 ===

# --- 방법 1: 하나씩 확인하기 ---
def gcd_simple(a, b):
    min_val = min(a, b)
    for i in range(min_val, 0, -1):
        if a % i == 0 and b % i == 0:
            return i

# --- 방법 2: 유클리드 호제법 ---
def gcd_euclid(a, b):
    while b != 0:
        a, b = b, a % b
    return a

# 실행
num1 = int(input("첫 번째 수: "))
num2 = int(input("두 번째 수: "))

print(f"방법1 결과: {gcd_simple(num1, num2)}")
print(f"방법2 결과: {gcd_euclid(num1, num2)}")

    ⚠️ 주의할 점¶

    • 바로 코딩하지 마세요! 의사코드든 메모장이든, 먼저 풀이 과정을 글로 적는 습관이 중요합니다. 설계 없이 코딩하면 중간에 길을 잃기 쉬워요.
    • 테스트를 꼭 하세요! 정상적인 값뿐 아니라, 같은 수끼리, 1이 포함된 경우 등 경계값도 확인해보세요.

    ✅ 점검하기¶

    1. 알고리즘 설계의 4단계를 순서대로 말할 수 있나요?

    정답 확인 문제 분석 → 설계(의사코드/순서도) → 구현(코딩) → 테스트

    2. 도전 B(가장 많이 등장하는 글자 찾기)의 문제 분석을 해본다면, 입력과 출력은 무엇일까요?

    정답 확인 입력: 문자열 (예: "hello world"), 출력: 가장 많이 등장하는 글자와 횟수 (예: "l", 3회). 공백을 포함할지 말지는 본인이 조건으로 정하면 됩니다!

    3. 같은 문제를 다른 방법으로 풀었을 때, 어떤 기준으로 비교할 수 있을까요?

    정답 확인 코드의 간결함, 실행 속도(효율성), 이해하기 쉬운 정도(가독성) 등으로 비교할 수 있습니다.
