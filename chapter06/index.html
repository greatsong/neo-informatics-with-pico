    Chapter 06: PWM으로 LED 밝기 조절하기¶

    🎯 이 장의 학습 목표¶

    이 장을 마치면 다음을 할 수 있습니다:

    • [ ] PWM의 원리와 duty cycle 개념을 이해한다
    • [ ] 코드로 LED 밝기를 단계별로 조절할 수 있다
    • [ ] 반복문을 활용하여 LED 페이드 효과를 구현할 수 있다

    예상 학습 시간: 약 50분

    📚 미리 알아야 할 것¶

    이전 장에서 배운 내용을 간단히 떠올려 볼까요?

    • Pin 객체로 LED를 켜고 끄는 방법 (value(1), value(0))
    • time 모듈의 sleep() 함수 사용법
    • Thonny에서 코드를 작성하고 실행하는 방법

    📚 핵심 개념¶

    개념 1: PWM — 빠르게 깜빡여서 눈을 속이는 마법 ✨¶

    지금까지 LED는 켜짐(1) 아니면 꺼짐(0), 두 가지 상태뿐이었어요. 그런데 우리가 원하는 건 "반만 밝게", "살짝 어둡게" 같은 중간 밝기잖아요?

    🤔 디지털 신호는 1 아니면 0인데, 어떻게 중간값을 만들 수 있을까요?

    비유로 설명하면 이렇습니다:

    PWM은 형광등 스위치를 아주 빠르게 껐다 켜는 것과 같아요. 1초에 수천 번 깜빡이면, 우리 눈은 그걸 하나하나 인식하지 못하고 "어, 좀 어둡네?" 라고 느낍니다.

    이것이 바로 PWM(Pulse Width Modulation, 펄스 폭 변조) 입니다.

    • 켜져 있는 시간이 길면 → 밝게 보임 💡
    • 켜져 있는 시간이 짧으면 → 어둡게 보임 🔅

    개념 2: Duty Cycle — "켜져 있는 비율"¶

    PWM에서 가장 중요한 개념이 Duty Cycle(듀티 사이클) 이에요.

    Duty Cycle = 한 주기 중에서 신호가 켜져 있는 비율(%) 입니다.

    Duty Cycle 의미 LED 상태
    0% 항상 꺼짐 ⚫
    25% 1/4만 켜짐 🔅
    50% 반반 💡
    100% 항상 켜짐 🔆

    MicroPython에서는 duty_u16() 함수로 듀티 사이클을 설정해요. u16은 16비트 숫자를 뜻하며, 값의 범위는 0 ~ 65535 입니다.

    원하는 밝기 duty_u16 값
    0% (꺼짐) 0
    50% (중간) 32768
    100% (최대) 65535

    💡 잠깐! 왜 65535일까요? 2의 16승 = 65536이고, 0부터 세니까 최대값이 65535가 됩니다. 외울 필요 없어요. "0이면 꺼짐, 65535면 최대 밝기"만 기억하세요!

    🔨 따라하기¶

    Step 1: PWM 객체 만들기¶

    먼저 LED를 PWM 모드로 설정해 볼게요. 피코 내장 LED(GP25)를 사용합니다.

    코드: 

    from machine import Pin, PWM

# 내장 LED를 PWM 모드로 설정
led_pwm = PWM(Pin(25))

# PWM 주파수 설정 (1000Hz = 1초에 1000번 깜빡임)
led_pwm.freq(1000)

    📌 freq(1000)은 1초에 1000번 깜빡이라는 뜻이에요. 이 정도면 사람 눈에는 깜빡임이 전혀 보이지 않습니다.

    Step 2: 밝기 단계별로 바꿔보기¶

    이제 듀티 사이클 값을 바꿔서 밝기를 직접 확인해 봅시다.

    코드: 

    from machine import Pin, PWM
import time

led_pwm = PWM(Pin(25))
led_pwm.freq(1000)

# 어둡게
led_pwm.duty_u16(3000)
time.sleep(2)

# 중간 밝기
led_pwm.duty_u16(32000)
time.sleep(2)

# 최대 밝기
led_pwm.duty_u16(65535)
time.sleep(2)

# 끄기
led_pwm.duty_u16(0)

    실행 결과: 

    LED가 어둡게 → 중간 → 밝게 → 꺼짐 순서로 변합니다

    ✅ 체크포인트: LED 밝기가 3단계로 변하는 게 보이셨나요? 값을 바꿔가며 실험해 보세요!

    Step 3: for 반복문으로 부드러운 페이드 효과 만들기¶

    이제 진짜 멋진 걸 해볼게요. LED가 서서히 밝아졌다가 서서히 어두워지는 페이드(fade) 효과입니다.

    여기서 for 반복문과 range() 함수를 사용합니다.

    # range(0, 65535, 256) → 0부터 65535까지 256씩 증가
for brightness in range(0, 65536, 256):
    # brightness는 0, 256, 512, ... 65280 순서로 변함

    💡 range(시작, 끝, 간격) — 시작 값부터 끝 값 직전까지, 간격만큼 건너뛰며 숫자를 만들어 줍니다.

    Step 4: 페이드 인/아웃 완성하기¶

    코드: 

    from machine import Pin, PWM
import time

led_pwm = PWM(Pin(25))
led_pwm.freq(1000)

# 서서히 밝아지기 (페이드 인)
for brightness in range(0, 65536, 256):
    led_pwm.duty_u16(brightness)
    time.sleep(0.005)

# 서서히 어두워지기 (페이드 아웃)
for brightness in range(65535, -1, -256):
    led_pwm.duty_u16(brightness)
    time.sleep(0.005)

led_pwm.duty_u16(0)

    실행 결과: 

    LED가 천천히 밝아졌다가 천천히 어두워집니다 🌅

    💡 잠깐! range(65535, -1, -256)에서 -256은 "256씩 줄여라"라는 뜻이에요. 숫자가 거꾸로 줄어듭니다!

    Step 5: 계속 반복하는 숨쉬기 효과¶

    while True:로 감싸면 LED가 마치 숨을 쉬는 것처럼 계속 반복해요.

    코드: 

    from machine import Pin, PWM
import time

led_pwm = PWM(Pin(25))
led_pwm.freq(1000)

while True:
    # 페이드 인
    for brightness in range(0, 65536, 256):
        led_pwm.duty_u16(brightness)
        time.sleep(0.005)

    # 페이드 아웃
    for brightness in range(65535, -1, -256):
        led_pwm.duty_u16(brightness)
        time.sleep(0.005)

    실행 결과: 

    LED가 숨쉬듯 밝아졌다 어두워지기를 무한 반복합니다 🫁

    ✅ 체크포인트: time.sleep(0.005) 값을 0.001이나 0.02로 바꿔보세요. 숨쉬기 속도가 달라집니다!

    📝 전체 코드¶

    from machine import Pin, PWM
import time

# PWM 설정
led_pwm = PWM(Pin(25))
led_pwm.freq(1000)

# 숨쉬기 효과 무한 반복
while True:
    # 서서히 밝아지기
    for brightness in range(0, 65536, 256):
        led_pwm.duty_u16(brightness)
        time.sleep(0.005)

    # 서서히 어두워지기
    for brightness in range(65535, -1, -256):
        led_pwm.duty_u16(brightness)
        time.sleep(0.005)

    ⚠️ 주의할 점¶

    1. duty_u16 값의 범위는 0~65535입니다. 이 범위를 벗어나면 에러가 발생해요. range()의 숫자를 수정할 때 주의하세요.

    2. 프로그램 멈추기: while True로 무한 반복 중일 때는 Thonny의 빨간 정지 버튼(Stop) 을 눌러서 멈출 수 있어요.

    ✅ 점검하기¶

    1. PWM으로 LED 밝기를 조절할 수 있는 원리는 무엇인가요?

    정답 확인 아주 빠르게 켜고 끄기를 반복하면, 사람의 눈은 그 깜빡임을 인식하지 못하고 **중간 밝기**로 느낍니다. 켜져 있는 시간의 비율(Duty Cycle)이 높을수록 밝게 보여요.

    2. duty_u16(32768)로 설정하면 LED 밝기는 약 몇 %일까요?

    정답 확인 약 **50%** 입니다. 32768은 최대값 65535의 약 절반이에요.

    3. 페이드 효과의 속도를 더 느리게 하려면 코드에서 어떤 값을 바꿔야 할까요?

    정답 확인 `time.sleep(0.005)`의 값을 더 크게 하면 됩니다. 예: `time.sleep(0.02)` → 각 단계에서 더 오래 머무르므로 전체 페이드가 느려져요.
